仅索引封面恢复与文件大小展示

创建日期：2026-10-16 · 所属模块：booksvr / app · 状态：ACTIVE

原始诉求

“为什么导入的所有书都没有封面图了？除了txt，别的都应该有啊”“还有每本书应该显示文件大小”。

目标与边界

修复仅索引漏提取封面，补齐已入库书籍；列表、详情显示每个格式的字节大小。保持仅索引，不复制正文，不写源目录，不改变书号、账号和配置，保护正在导入的任务。grill skill 不可用；用户已明确存储和导入约束，无需新增产品决策。

方案

按书号保存独立、压缩且限制尺寸的 JPEG 封面到 library/.talebook-covers；兼容旧封面且不覆盖已有封面。索引时使用已取得的物理文件提取，ZIP 临时文件释放前完成。修复命令先读取候选 ID 并关闭查询游标，默认两个并发读者，仅短暂更新 has_cover，SQLite 忙时退让重试。可重复运行，跳过已有封面；max_completed_id 仅为诊断，不作为并发任务安全断点，重跑不带 after 参数。删除外部索引同时清理独立封面，内置图书的封面随书移入回收站。原文件没有嵌入封面时保留占位图，PDF 使用首张页面。大小批量读取 data.uncompressed_size，避免逐书访问源磁盘和 ZIP 解压。封面由无到有时图片 URL 增加 cover=1，避免继续命中旧占位图缓存；响应要求重新验证。前端共享格式大小组件，在列表和详情复用。真实补全发现 630255304 字节 MOBI 被整文件读取上限拒绝，因此 EPUB 改为 ZIP ReaderAt、MOBI 改为只读 PDB 索引、首记录和目标图片；支持大于 512 MiB 的普通原地源，仍限制单张图片 32 MiB。补充稀疏大文件回归，避免为了封面加载正文。首轮 9929 个候选完成后，核查剩余文件发现 14 个 EPUB 未声明封面但首个 spine 是无正文的单图片封面页，因此增加显式 guide 与纯图片首页回退（HTML img / SVG image），不把正文插图当作封面；MOBI 首图片索引为 0 的旧文件从索引开始只检查记录魔数，兼容空封面偏移哨兵。影响规格：spec/书库.md。
