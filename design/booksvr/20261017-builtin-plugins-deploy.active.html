原始诉求与目标

合入 39 个 Go 内置插件和插件配置写回功能；保持现有仅索引、多目录、封面、文件大小、配置热加载及阅读器转换行为。

设计决策与边界

副本真实大书库的工具选书搜索仅返回 7 条却耗时 13.19 秒。改为轻量标题/作者筛选、批量可见性过滤、分页后仅载入最多 100 本的完整元数据；保留 Unicode 大小写比较、作者顺序、时间排序、总数与权限。首轮相关子查询虽降至 5.281 秒，仍有逐书查作者的额外开销，最终改为两次批量扫描标题/时间和作者，避免相关子查询。新增回归用不可解析的页外元数据证明没有载入整个书库，最终全量、Unicode 作者搜索、混合时间排序、批量可见性与页外损坏元数据用例通过；同一近 9 万本副本单次搜索 2.434 秒。

PR 基于 f3a21e1，当前分支为 1d87681。三处合并冲突保留当前分支的配置快照路由结构和阅读器转换测试，把 SaveExtraSettings 和共享插件注册表移到当前 newServeDispatcher。补齐当前分支新增的 newBookWiring 调用。

保持 /data、/books、/books1、端口、账号和原 Calibre 数据库位置；不复制正文，不清空书库。测试书籍工具使用临时书库；不改真实图书正文。外部元数据和设备服务无凭据时只验证配置、鉴权和失败语义。

先测试构建，再备份数据库和配置、停止旧容器并复用原 Docker 配置启动新镜像；旧镜像和容器保留用于回滚。只在全量测试及真实页面/API 验证后推送合并提交。

影响范围与规格

涉及 booksvr 启动、插件、配置快照接线；界面 full 审查发现分支中俄语 ZIP 仅索引说明仍写成永久缓存（Introduced / Writing / MEDIUM），修正为按需解压、用完回收、共享 512 MiB 上限，并增加三语文案一致性测试；重新生成前端资产。沿用已有 spec/插件 规格，无新增领域行为，仅使 PR 所述插件在 Go 服务中可用。原插件方案位于 design/booksvr/20261016-booksvr-builtin-plugins.active.html。
