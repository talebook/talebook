配置、导入与阅读修复

创建日期：2026-10-16 · 所属模块：booksvr · 状态：ACTIVE

原始诉求与目标

来源：用户要求修复重复安装、阅读器转圈、导入目录无法保存或生效，并验证所有配置、页面接口后提交。用户明确允许多个宿主机目录挂载；内置书库及 Calibre 数据库保持 /data/books/library 不变。沿用现有容器及挂载，原地更新程序。

验收目标：配置保存、刷新和重启一致；任意可读绝对目录、多目录及三种导入方式可用；大目录请求不超时；导入后可阅读。

方案与根因

现场故障实现
安装判断和业务接口使用启动时配置安装状态实时读取；配置文件变化时原子替换不可变路由快照。保留数据库与后台服务实例。
导入保存未接线却返回成功；字符串列表被写成错误字符串接入持久化，未接线明确报错；修复列表、转义和带引号字符串往返，串行原子写入。通用表单仅提交本页改动，避免覆盖其他页面的新设置。
实际仍扫描空的 /data/books/imports统一保存和读取多目录列表；移除白名单与重复默认目录输入。当前实例保存 /books、/books1 。
首批 500 个普通 ZIP 被当漫画校验，真正电子书没有进入批次先扫描明确的电子书/漫画格式，再检查普通压缩包。普通小说 ZIP 需先解压，不伪装成可阅读漫画。
扫描/导入阻塞 HTTP 并触发 504串行后台队列和显式运行/失败状态；前端等待本轮任务，不因未选择的待导入记录永久轮询。自动监控与手工任务共享写锁。
导入文件位置错误移除 supervisor 的 /books 存储覆盖参数；复制/移动落在内置书库；索引保留源路径。写入失败标为失败，不遗留“导入中”。
EPUB 未登录跳转被长期缓存抽取资源及失败响应 no-store，新增 /read/extract 别名避开旧缓存；保留权限与 MIME。
TXT 初始化被当上传接口，缺少目录与编码支持恢复 GET 初始化与目录契约，支持 UTF-8、GB18030、UTF-16；章节按规范化文本偏移读取，HTML 转义。验证码授权适用于全部格式。
图书详情/编辑计算属性生成临时对象，修改丢失等待初始请求并同步到稳定可编辑副本。

配置范围：通用保存链路、读取快照、六个人机验证场景、邀请和注册开关、WebDAV/在线保存/笔记服务实时配置。数据库连接、Cookie 签名密钥仍为进程启动项。第三方 SMTP、OAuth、Turnstile/极验及外部插件服务连接不以保存成功代替实际连通性。

追加现场发现

真实编辑页面把空值标记 __DELETE__ 写成丛书和标签；同时发现出版社、ISBN、语言、评分、出版日期及别名未接入写入。先统一兼容空值标记，再补齐表单字段写入、清空与读取验证，保持缺省字段不变。

影响范围

booksvr HTTP、scan、importdir、library、命令接线；Nuxt 导入/设置/图书页面；Docker 启动和 Nginx；Python 兼容目录接口；规格检查器读取 Go 新增路由。

规格更新：spec/书库.md、spec/系统设置.md、spec/阅读器.md、spec/元数据.md 。没有迁移宿主机书籍或数据库。
