MOBI 书名、阅读转换与仅索引重建

创建日期：2026-10-16 · 所属模块：booksvr · 状态：ACTIVE

需求来源：用户要求修复 MOBI 书名与阅读超时，随后要求默认仅索引，清空旧书库、阅读和导入数据并重建镜像重新导入；明确保留账号和站点设置。

原始诉求与最终目标

最初要求恢复 426 本误导入书名，并保持运行中的导入不中断；追加 MOBI 阅读转换超时修复。之后用户发现复制占用磁盘，明确要求默认仅索引，并授权停止任务、清空书库与阅读/扫描记录、删除已复制副本，从空库重新导入。

对“数据库都清掉”的必要澄清已得到答复：保留账号和站点设置，清空书库、阅读记录及导入数据。该答复取代早期保留旧任务的约束。grill skill 未提供；边界由用户明确指令和这次澄清确定。

根因与方案

问题根因实现
MOBI 书名变成内部标识fullname 偏移和长度错误地从 MOBI 子头读取，比记录 0 起点偏移多了 16 字节。旧测试构造器重复了同一错误。使用记录 0 的 0x54/0x58 字段；保留 EXTH 503、fullname、PalmDB 名的优先级。独立固定字节测试复现 PGVF05UTWV 与真实书名。
已转换仍报告超时等待页遗漏 engine=readest 参数，持续收到 400；又检查真实协议没有返回的 epub_ready 字段。ConvertAll 还同步占用阅读请求。使用真实启动协议；完成后重新进入阅读入口并保留阅读器选择。后台单队列去重并等待批量转换，失败和服务不可用返回明确错误。移除固定六分钟假超时，避免重叠轮询；提供返回详情的原生链接。
默认复制消耗空间Go 配置、扫描服务、Python 兼容层及前端多个回退均为 copy。统一缺省/无效配置为 index。有效已保存模式和显式 copy/move 仍可使用。本机持久设置已改 index，新任务从空库按此模式运行。

仅索引时普通文件直接登记源路径。ZIP 内成员仍需要持久解压缓存，MOBI 在线阅读需要生成 EPUB；这两类是阅读所需产物，界面已说明 ZIP 缓存规则，不能将“仅索引”解释为完全没有磁盘写入。

在线恢复与随后重建的执行记录

  1. 先使用 SQLite 在线备份保存原书库，恢复命令默认只读预览；确认 426 条均满足当前书名仍为旧错误结果、原文件 fullname 有效、旧偏移无效且无 EXTH 覆盖的严格条件。
  2. 逐条短事务比较书名、作者和作品引用，写入前持久记录 intent，提交后记录 applied。同步归一化键和作品引用，保留共享作品其他成员，不合并或删除书籍。原进程 PID 659、启动标识 26205122 保持；用有限生命周期校正进程处理旧程序后续结果。
  3. 426 本全部恢复并核对，示例 6784 为“九州·魅生05：十师卷”。书籍 ID、原格式路径和无关字段未改变；备份、预览、修改日志与验证报告留存。Nginx 窄范围过滤经真实代理回归后平滑重载，旧进程也能正确完成等待页跳转。
  4. 用户随后明确要求清理并从头索引。停止 talebook:booksvr，保存用户库 155168768 字节及恢复后的书库备份；构造空 Calibre 库和空用户业务表，保留 readers、账号认证/设备/站点/插件配置相关表的记录，清掉书籍记录及 reader.extra 的历史项。
  5. 新库 quick_check 通过，账号认证字段逐项相等。删除前核对 /data/books 下精确清理范围、无符号链接跳出、后端已停止且备份可读。清理 library、extract、convert、progress、import-cache 中的旧副本与派生产物；保留 library 目录，避免启动时回填示例库。替换数据库后再次核对空库、账号、设置及源挂载。
  6. 实际释放 33471688704 字节（约 31.2 GiB）。/books 和 /books1 对应的原书目录未修改。数据库和内置书库位置保持 /data/books/library，用户库仍为 /data/books/calibre-webserver.db。
  7. 以现有运行时底座叠加已验证的 Go 二进制、完整前端产物与当前启动配置构建镜像；复制原容器的挂载、端口、环境及运行参数创建新容器。旧容器已移除。新服务自检 permission/nginx_config/syncdb/migrate/update_config 全部通过，账号保持登录，没有返回安装页。
  8. 在真实页面点击“全部导入”，后台从空库处理 /books、/books1。观察索引 500 → 1500 → 3339 本，失败 0；登记的普通文件路径指向 /books，复制目录格式数为 0，Talebook Imports 目录不存在。任务继续运行，无需重复点击或保持页面打开。
