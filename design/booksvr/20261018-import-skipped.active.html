导入重复记录归入已跳过

创建日期：2026-10-18 · 模块：booksvr · 状态：ACTIVE

原始诉求

重复的扫描记录归到“已跳过”，不再计入“待处理”；测试通过后部署、提交并推送。

目标

列表与统计使用一致分类；既有重复记录立即重新分类，无需重扫或修改扫描状态，已跳过记录不参与导入。

方案

保留 drop 状态，新增 summary.skipped 和 filter=skipped，待处理排除 drop；Go 后端与旧 Python 兼容实现保持一致。前端新增“已跳过”标签和数量，切换分类重置页码及选择；已跳过标签内勾选记录仅用于记录管理，不显示“导入选中书籍”；所有三种语言更新标签和提示。drop 也用于源文件消失，状态文字统一为“已跳过”，不把每个 drop 误说成重复。已有 exist/已存在仍按既有完成分类，避免改变其他状态含义。无需数据库迁移，不删除扫描记录或源文件。影响 spec/书库.md 中扫描状态、分类计数和接口；书籍、外部访问行为不变。
