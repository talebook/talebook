全部内置插件逐项验收与 OPDS 修复

创建日期：2026-10-17 · 所属模块：booksvr · 状态：ACTIVE

来源：Open Library 搜索 EOF；用户要求逐个测试全部插件，并反馈静读天下显示 XML、大书库 OPDS 可能超时。

原始诉求与目标

39 个插件全部建立逐项记录，区分受控功能验证、真实服务验证和缺少账号、设备、下载器等实际条件。不得将注册成功、自检静态文案或空结果当作功能通过。保护生产账号、设置、导入任务与书籍正文，默认仅索引原文件。

方案与实现

  1. HTTP 连接错误区分中断与超时，隐藏 URL 查询与凭据。只读失败可以安全重试，写入中断不自动重试；运行时脱敏保留重试属性。
  2. Open Library 搜索、作品/版本详情、作者与封面加载形成完整路径。封面只允许 HTTPS Open Library 入口以及 Internet Archive 的受限公共 HTTPS 存储跳转，不放宽其他请求的默认同源策略。
  3. 修复 BRS 中文评论截断越界、通用 CSV/JSON 评分字段、WebDAV 绝对地址、番茄下载器重复创建任务与 EPUB 根文件解析。
  4. 规范化运行时分页、书籍详情和正文的值/指针边界，同时接受指针入参，防止真实插件返回值被 HTTP 接口拒绝。
  5. 修复外部书源保存遗漏注册表、目录库和账号库混用、二进制字节/章节结果丢失。新下载文件使用独立文件名；登记真实大小；创建私有归属记录。
  6. Watch Folder 可选择任意可读目录；读取限制在选定目录内，取得本地书籍返回原路径并仅索引，绝不复制正文。
  7. OPDS 先加载轻量排序字段，再只读取当前页完整元数据；批量过滤权限；修正稳定降序、末页起点、导航关系与响应类型。Nginx 使用相对跳转，避免丢失对外端口；部署前缀配置避免重复指令。
  8. Venera 从固定提交的原始文件地址加载脚本，保留 SHA-256 校验，避免 GitHub API 403 配额限制。Calibre 与 Kindle 的服务缺失必须在自检/执行时明确失败。

规格同步：spec/外部访问.md、spec/插件/插件平台.md、外部书库源.md、元数据源.md、评价源.md、发送到设备.md、Venera.md。

测试结果

Go 全量 42 个有测试的包通过；2 个需要非 root 权限的失败场景另以 UID 911 通过；go vet 与二进制构建通过。Python 部署前缀与 Nginx 模板测试 32 例通过。初期探索中的旧版本失败保留在日志中，最终统一源码回归以 coherent 日志为准。

受控测试覆盖 39 个插件的适用路径；番茄下载器只验证请求、失败处理与校验组件，完整二进制进程链没有运行。真实服务审计：10 个通过、6 个未通过、6 个本地功能通过、17 个缺少账号/配置/设备/下载器或接线条件。

Open Library 已从 leonFN 以“西游记”实测返回 20 条候选，加载 /works/OL21004525W 详情，并下载 52,756 字节封面（5.68 秒完整测试）。Venera 真实浏览返回 20 条，Internet Archive 29 条、Project Gutenberg 113 条、Standard Ebooks 15 条；条目数不等于不同图书数量。

不向真实外部账号、邮箱或设备发送内容；微信读书的个人书架/笔记/扩展操作、BRS 推送/删除/投票、真实硬件接收、所有漫画章节与图片均未实连，不能从受控测试推断这些集成可用。

部署与保护

副本启动时，因为源书目录只读挂载，标准 bootstrap 的写入自检失败；随后在隔离副本中直接启动 Go 与 Nginx 完成验收。正式部署使用原有挂载和标准 bootstrap，实际全部自检通过，bootstrap 以预期状态 0 退出，booksvr 与 Nginx 正常运行。

生产镜像 sha256:6ecb7054dfc86936b18a6196fb3e1dfd1ee04f5bc79639c11c38e00d9c49cdca；二进制 SHA-256 a24dbd1179602470660b9a5bbe247597dbea49312171413a2547643457c19df5。生产副本保护目录为 /vol1/1000/talebook/books/repairs/20261017-plugin-audit/。生产浏览器复测 /admin/settings/plugins 展示 39 个插件，/read/3 显示实际 EPUB 正文，未再次进入安装页。手机上的静读天下仍待用户复测。

候选镜像沿用已部署前端，只替换经过验证的 Go 二进制与 Nginx 配置；先用隔离数据库副本启动并测 OPDS，再切换生产。保留三个挂载、端口、账号、站点设置、书库位置和仅索引配置；确认没有正在导入的记录后才切换。保留旧镜像与数据库快照用于回退；验收后删除旧容器和临时容器，不删除任何卷。
