Candle Reader 笔记语义与选区反馈

TB-199 后续反馈；Candle #18 与 Talebook #1036 同步实施。

WIP2026-09-28app / webserver

原始诉求与目标

设置中的三项笔记开关沿用其他配置行的布局。选区工具栏顺序为复制、划线、写想法、看想法。取消成功划线提示；仅写入成功后渲染永久标记。写想法打开文本编辑与公开范围下拉框，默认公开。工具栏及编辑弹窗期间，原文选区保持可见且 CFI 可用。

划线与文字想法统一为笔记；沿用 annotation_type、content、quote_text、cfi、is_private 字段。公开的章评仍由既有服务端类型表示，不迁移旧数据。公网 demo 访问故障不纳入本次代码改动。

方案

  1. Candle Reader 在选区时保存稳定 CFI 与引文，并在宿主页面绘制临时蓝色选区预览；焦点移到工具栏或编辑框时保留预览，取消或成功后移除。预览不进入笔记列表和本地存储。
  2. 保存回调完成后更新笔记列表和 epub.js 标记；失败时保留选区与工具栏、显示错误，不生成永久划线。划线成功不弹“划线已保存”。
  3. 工具栏将看想法指向当前 CFI 的统一笔记面板，可切回全部笔记。文字笔记编辑使用公开/私密下拉框，默认公开；本地模式注明只保存在浏览器。旧 localStorage key、已有笔记字段、load/save callback 契约不变。
  4. Talebook 仅同步 Candle 实际 ES/UMD/CSS bundle 和缓存标识，继续沿用已存在的 annotations API 适配器。后端现有数据模型已支持所需字段，无 schema 迁移。
选区预览只表示当前选择，不是已保存标记。旧笔记的类型和私密属性原样读回。
