导入设置与自动监控实现方案

在现有管理后台导入页上扩展设置入口、目录检测、导入模式和异步监控能力，优先复用现有 ScanFile 与 ScanService。

状态：Active 创建日期：2026-08-12 所属模块：app 影响范围：app/pages/admin/imports.vue、webserver/handlers/scan.py、webserver/services/scan.py 需求来源：TB-20 / TB-21

1. 原始诉求

talebook 的导入图书页面需要新增“导入设置”按钮和浮窗，支持设定服务器导入目录、三种导入模式，以及“自动监控并导入新书籍”。目录选择要通过服务器目录选择对话框完成；自动监控要异步处理大量文件；导入模式包含仅索引、复制到书库、剪切到书库，并在界面解释逻辑。

2. 目标与边界

本次实现

  • 新增导入设置 API、目录检测 API、目录浏览 API。
  • 保存 scan_upload_path、import_mode、import_auto_watch_enabled 并刷新页面摘要。
  • 手动导入和自动导入使用任务开始时的导入模式快照。
  • 剪切模式仅在导入成功后删除源文件，删除失败写入可见状态。
  • 自动监控用后台线程周期扫描和入队，避免阻塞 Web 请求。

技术边界

  • Calibre 外部文件引用能力不可在当前环境验证；仅索引模式以扫描索引和状态留痕落地，避免假装完成不可读的外链书库。
  • 文件系统事件在 Docker/NAS 上不稳定，本期采用定时补偿扫描，后续可接入事件监听。
  • 重试队列先提供失败项可见和批量重试入口，复杂退避可在后续服务化队列表中扩展。

3. 方案

读取设置

导入页加载 /api/admin/import/settings，得到目录、模式、监控和状态摘要。

检测目录

保存前规范化路径，校验允许根、存在性、读写权限、软链接和候选文件数量。

扫描入队

手动扫描或监控轮询调用现有扫描服务，跳过隐藏项和软链接，并限制单轮候选数。

导入执行

复制、剪切、仅索引统一从保存设置生成任务快照，状态回写到 ScanFile。

接口用途关键行为
GET/POST /api/admin/import/settings读取和保存导入设置复用配置持久化；首次开启监控触发一次异步扫描。
POST /api/admin/import/directory/check目录检测返回 readable、writable、in_allowed_roots、supported_file_count、warning/error。
GET /api/admin/import/directory/list目录选择器只列出允许根内目录；不跟随软链接。
POST /api/admin/import/run导入执行兼容旧 delete_after，新参数 import_mode 优先。

4. 影响与风险

  • 新增配置键需要默认值，老实例升级后自动监控默认关闭，导入模式默认复制。
  • 导入页移除旧的“导入后删除源文件”复选框，由“剪切到书库”替代。
  • 目录白名单默认限制为 /data/books/imports/，测试环境允许复写。
  • 仅索引模式以“已索引”状态可见，后续若确认 Calibre 外部引用能力，再扩展为真正可阅读记录。
