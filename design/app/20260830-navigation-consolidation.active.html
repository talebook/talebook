用路径型页签整合导航与访问入口

减少侧栏中的同类入口，把书库、个人阅读和管理员设置分别收拢为稳定的路径型页签；同时以紧凑帮助菜单承接版本、用户数和项目链接。

状态：ACTIVE 创建日期：2026-08-30 所属模块：app 影响范围：app 路由、导航、页面壳；webserver 状态响应 需求来源：会话内导航整合需求

1. 原始诉求

“本地书库、网络书库、OPDS 介绍、WebDAV 介绍合并为‘书库浏览’；我的书架和已读书目整合为‘我的阅读’；插件中心和主题管理以 Tab 形式整合到系统设置；最下方 Logo、版本、用户数整合为小问号菜单，参考 Multica。”

后续确认使用路径而非查询参数：/library/network、/me/shelf、/admin/settings/plugins。旧地址保留兼容跳转；网络书库入口常驻；App 访问介绍允许游客浏览，登录后才展示连接信息。

2. 目标与边界

目标

  • 侧栏只保留“书库浏览”“我的阅读”“系统设置”三个聚合入口。
  • 每个聚合入口使用可分享、可刷新、支持前进后退的路径型页签。
  • 网络书库能区分未启用插件、未配置书源和已有可用书源。
  • 默认头部与五套内置主题共享同一份导航模型和帮助菜单语义。

非目标

  • 不重写本地书库、网络搜索、用户资料、插件中心或主题管理的领域逻辑。
  • 不改变 OPDS 与 WebDAV 协议本身、认证方式或地址。
  • 不把个人插件设置并入“我的阅读”；现有 /plugins 入口继续独立存在。
  • 不删除旧路由，避免书签、历史链接和外部引用失效。

4. 现状、根因与证据

观察权威证据结论
同一任务散落为多个侧栏项app/components/AppHeader.vue 与 app/components/themes/BuiltinThemeHeader.vue 各自拼装本地书库、网络书库、书架、已读、插件和主题入口。需要共享导航模型，否则默认头部与内置主题会再次漂移。
网络书库无法解释“为什么没有书源”GET /api/book-sources 只返回当前可用 bindings；空数组不区分插件未启用与插件已启用但未配置。响应需增加不泄露凭据的 availability 摘要。
OPDS / WebDAV 介绍读取管理员接口app/pages/opds-readme.vue 与 webdav-readme.vue 调用 /admin/settings，普通用户无法可靠判断服务状态。服务开关应进入所有访客已能读取的 /api/user/info 系统摘要。
底部信息占用多行且主题实现不一致两个 Header 分别把版本、用户数、OPDS、WebDAV 和可配置 Logo 渲染为普通列表项。抽取共享帮助菜单组件和共享导航 composable。
事实与验证：Moke 的官方仓库与 Talebook README 已确认其可直接连接 Talebook；聚焦后端测试与浏览器夹具已验证“插件未启用”“插件已启用但未配置”和“存在可用书源”三种状态能够稳定区分。

5. 方案

方案结论：新增共享的路由页签壳和导航模型，现有领域页面改为可嵌入内容组件；旧页面只负责重定向。后端仅补充只读状态摘要，不搬迁业务数据。失败和空状态由聚合页解释，并提供与角色匹配的下一步。
Route路径决定活动页签

页签点击使用 Nuxt 路由；刷新和历史导航不依赖组件内状态。

Guard角色与服务状态分流

/me 要求登录，管理设置要求管理员，App 介绍允许游客。

Content复用既有领域内容

本地书库、网络书库、账户、插件和主题不复制 API 与状态逻辑。

Fallback旧地址与空状态可行动

旧 URL 跳新路径；空网络书库明确指出启用插件或配置书源。

6. 影响范围、风险与回滚

影响范围

app/components/AppHeader.vue、内置主题 Header、路由页面、共享 composable 与内容组件、i18n、E2E mock；后端 UserInfo 和网络书源目录只读响应；相关前后端测试。

保持不变

数据库结构、书源配置事实表、插件启停事实表、OPDS/WebDAV 协议、用户权限判断、领域页面 API、插件工作台和个人插件设置路径保持不变。

主要风险：路由环路或丢失旧 query、嵌入长页面后的滚动/吸顶冲突、默认与内置主题导航漂移、普通用户误见管理员操作。通过路由矩阵 E2E、两套 Header 契约测试、权限 API 测试以及桌面/手机实际渲染缓解。
回滚：本次无数据迁移；可整体回滚前端路由与共享组件及后端两个附加响应字段。旧业务接口和事实表不需清理。

8. 决策记录

  1. 2026-08-30：用户确认不使用 query 参数页签，改为 /library/network、/me/shelf、/admin/settings/plugins 等路径。
  2. 2026-08-30：/me/* 未登录统一跳登录并在成功后返回原目标。
  3. 2026-08-30：网络书库入口常驻，废弃旧 show_network_library 对导航可见性的控制；为避免无效设置误导管理员，系统设置页不再展示该开关，后端字段仅作历史配置兼容；空状态按角色区分行动。
  4. 2026-08-30：真实浏览器验收发现帮助菜单向侧栏外展开会被抽屉裁切，浮层锚点调整为向内侧对齐，保证完整菜单始终落在侧栏宽度内。
  5. 2026-08-30：App 访问介绍对游客可见，登录后才显示当前实例地址和启用状态。
  6. 2026-08-30：主页签吸附顶部，移动端横向滚动；问号菜单去掉“文档”，Logo 固定在菜单最底部。
