02 / 已确认决策

版本先生成，发布后切换

决策约束结果
修订不覆盖当前发布版编辑时复制剧本形成候选版本；生成完成前线上仍指向旧版。试听、Podcast 与阅读器不会读到半成品。
发布采用原子切换候选版完整可用后，由管理员明确点击“替换当前版本”。候选版变为 published，旧版变为 historical。
历史备份默认保留 3 个全站管理员配置；仅显式点击清理按钮时执行。最近 N 个 historical 保留，当前发布版、候选版、运行中任务不删除。
局部与整本返工分流只改对白可重生成当前章；删章、重排、重命名等结构变化必须整本生成。避免把旧 manifest 与新章节结构错误拼接。

03 / 剧本规范化

先把输入整理成可审查的剧本

章节标题恢复

对 index_split_000、UUID、纯文件名等技术标题，从首个有效正文段提取“第十八章”等自然标题；无法识别时显示“第 N 章”，不把内部文件名暴露给用户。

非正文剔除

过滤明确的 CSS/style 内容；若 titlepage、cover 等技术章节清理后没有可朗读正文，则整章移除。普通正文中谈论 CSS 的句子不会因关键词命中而删除。

约 50 字切片

先按句末标点切句；同角色、同定位范围内的短句合并到约 50 字。目标 50 字、软下限 28 字、硬上限 80 字；超长单句优先在逗号、分号处分开。

定位信息同步

拆分或合并后同步更新 locator 的字符范围、文本哈希、出现序号和章节编号，保证 candle-reader 的音文高亮仍能定位。

规范化时机与幂等性

  • 新任务：Voicebook inspect 产出后、进入人工审查或生成前执行。
  • 旧任务：从已完成版本创建修订版时执行一次，使历史坏剧本可以进入新工作台修复。
  • 脚本记录规范化版本；同一版本重复执行不得继续拆分、改名或漂移 locator。
  • 输出规范化报告：删掉的章节/行、改名章节、拆分前后段数、是否发生结构变化。

05 / 数据与接口

复用 Edition 作为剧本版本，不新增数据库列

每个 AudiobookEdition 已有独立 script_path、配置、章节清单与状态，直接作为剧本/音频版本。版本关系写入现有 JSON 配置，避免为已部署数据库新增迁移风险。

数据写入位置用途
revision_of_edition_id候选 Edition.config指向复制来源，显示版本链并合并未修改章节。
revision_number候选 Edition.config稳定显示 V1/V2/V3，不依赖数据库 id。
normalizationJob.data记录规则版本、变更章节、结构变化与统计。
AUDIOBOOK_BACKUP_RETENTION系统设置全站备份保留数，默认 3，允许 0–20。

接口增量

GET  /api/audio-job/:job_id/workspace
     completed / ready / historical 可读；只有 awaiting_review 修订任务可写

POST /api/audio/:edition_id/revisions
     复制版本并返回 advanced + awaiting_review 修订任务

POST /api/audio-job/:job_id/confirm
     { "scope": "chapter", "chapter_number": 18 }
     或 { "scope": "book" }

DELETE /api/book/:book_id/audio-backups
     按 AUDIOBOOK_BACKUP_RETENTION 删除最旧 historical 版本

所有新增接口继续使用 @js 与 @auth/@is_admin；前端继续统一通过 backend() 调用。

06 / 单章合并与发布安全

局部生成也必须得到完整候选版

  1. 创建修订版时复制基线 script、locator、manifest、未修改章节音频与 timeline。
  2. 编辑当前章后只让 Voicebook 生成该章；保留 segment cache，未改片段可命中缓存。
  3. Talebook 将新章记录替换进基线 manifest，重新计算全书时长、大小、哈希与章节数。
  4. 校验每章音频、timeline、source key 和章节编号完整后，候选版进入 ready。
  5. 发布动作在同一事务中切换状态；失败时旧版仍为 published。

必须整本生成

移除 titlepage、章节重编号、source key 集合变化、脚本规范化首次应用导致多章变化，或用户主动选择整本。

允许单章生成

章节结构与角色表未变，且文本修改只发生在当前章；未修改章节直接复制并校验。角色或音色调整影响跨章配音，必须整本生成。

07 / 前端体验

任务页是工作台，书籍页是版本管理台

位置新增体验关键状态
任务列表完成任务显示“查看剧本”；等待审查显示“编辑剧本”。只读工作台不展示保存/生成按钮。
剧本工作台展示规范化报告、版本来源、每章字数/片段数；提供“保存”“重生成本章”“整本重新生成”。结构变化时禁用单章按钮并解释原因。
书籍有声版已发布版显示“创建修订版”；ready 候选显示“替换当前版本”；历史版支持回滚。创建修订版后直接进入剧本工作台。
备份管理显示“历史备份 X / 保留 N”，提供带二次确认的“清理旧备份”。预览将删除版本、释放空间和不可恢复提示。
系统设置有声书设置中增加“历史备份保留数”，默认 3。限制 0–20；保存后不自动清理。

08 / 清理、兼容与回滚

清理可预期，旧数据可进入新流程

  • 清理只选择当前书最旧且超出保留数的 historical；逐个删除章节、进度、书签、播放会话、终态任务及版本目录。
  • 当前发布版、ready/partial/draft 候选版、存在活动任务的版本始终排除。
  • 旧完成任务若 script 仍存在，可以只读查看并创建修订版；script 缺失时明确提示无法修订，不伪造剧本。
  • 旧剧本创建修订版时应用规范化；旧已发布音频不原地修改，因此升级本身不改变正在播放的内容。
  • 回滚代码时，新增 JSON 字段可被旧代码忽略；已创建候选仍是普通 edition，历史发布版仍可回滚。
