有声书创建向导方案

把“有声书”主入口从任务监控语义中解耦，新增可发现、可校验、可提交的创建向导，让用户从有声书中心完成选书、配置、提交和查看进度的闭环。

状态：ACTIVE 创建日期：2026-08-12 所属模块：app 需求来源：TB-18 影响范围：Nuxt 页面 / E2E / mock API

1. 原始诉求

“有声书页面没有【创建】按钮。点击【有声书】按钮后会直接进入任务页面，导致没有办法创建有声书。希望提供可用的有声书创建入口。”

后续产品和交互补充要求：有声书主入口应是有声书中心；制作任务页只做进度和返工管理；创建应进入选书向导，并明确展示可创建、已有任务、已有版本、需转换和无权限等状态。

2. 目标与边界

目标

  • /audios 首屏和空状态都能直接进入“创建有声书”。
  • 新增 /audios/create，完成选书、格式校验、生成配置和任务提交。
  • 单书有声页识别已有活跃任务，避免重复创建。
  • 不支持格式走现有 /book/:id?convert=epub 转换入口。

边界

  • 不改 Voicebook 生成协议，不新增批量任务。
  • 不在向导内重做文件转换，只复用既有转换弹窗。
  • 全局普通读者隐藏创建入口仍受当前用户信息字段限制；书籍级权限由 generation.permitted 拦截。

3. 路径关系

/audios

有声书中心，展示续听、已发布版本、Podcast 和创建入口。

/audios/create

创建向导，读取书库列表并对选中书籍做有声书资格校验。

/audio-job/:id

创建成功后进入任务详情；高级模式待审查时打开工作台。

/book/:id/audios

单书上下文，支持直接创建、查看任务、收听或创建修订版。

4. 状态机

状态判断来源页面表现主操作
可创建generation.can_generate显示快捷/高级模式、引擎、语速、章节和主角音色配置。加入制作队列或开始识别
已有活跃任务/audio-jobs 中同书籍 queued/inspecting/awaiting_review/generating/finalizing隐藏重复创建按钮，提示已有任务。查看制作进度或继续审查
已有发布版本editions.status === published提示已有版本，同时允许创建修订版。创建新任务或打开单书页
格式不支持generation.reason === format.not_supported 或非 EPUB/TXT禁用生成配置，说明需先转换。转换为 EPUB 后创建
权限/容量/开关限制generation.reason、capacity、health展示具体原因，不提交任务。登录、联系管理员或等待容量恢复

5. 实现落点

  • app/pages/audios/index.vue：新增主创建入口和空状态创建入口。
  • app/pages/audios/create.vue：新增创建向导，复用 $backend_stream('/library')、/book/:id/audios、/audio-jobs 和 POST /book/:id/audio-jobs。
  • app/pages/book/[bid]/audios.vue：加入活跃任务优先级、格式转换入口和 ?create=1 自动打开弹窗。
  • app/components/AudioJobsPage.vue：任务页顶部和空状态回流到创建向导。
  • app/pages/book/[bid]/index.vue：支持 ?convert=epub 自动打开既有转换弹窗。
  • app/test/mock-server.js 和 app/test/e2e/audiobooks.spec.ts：补齐不同格式、活跃任务和向导提交的测试数据与覆盖。

6. 风险与兼容性

  • 创建向导对选中书籍逐本调用 /book/:id/audios 做准确校验；列表未选中项先用书库格式做轻量状态提示。
  • 当前 /user/info 没有全局 can_create_audiobook 字段，因此全局入口无法完全表达“管理员或获准所有者”。最终提交仍由后端书籍级权限校验保证。
  • 任务页继续是管理员/创建者可见的生产监控台，不作为普通读者收听入口。
