原始诉求 / Evidence

用户报告的两个现象来自同一处主题分支

Issue 描述：仅浅灰主题中，顶部左侧按钮图标显示异常；点击后侧栏只能收回一半。截图显示标题栏左侧为放大的头像轮廓，页面左缘仍保留窄抽屉及被截断的导航内容。

SYMPTOM A按钮语义错误导航开关展示用户头像，而不是各主题通用的菜单图标。
SYMPTOM B侧栏没有关闭点击只将 240px 抽屉切为 64px rail，主内容仍被布局占位。
CAUSE浅灰专属分支isLightGray 同时控制头像、rail 属性和 miniVariant 状态。
240px · 展开完整导航内容
64px 残留
目标 · 0px关闭后释放全部主内容空间；再次点击恢复 240px。
Grill / Boundary decisions

逐项澄清后的范围

统一导航开关

浅灰主题改用 mdi-menu，与其他四套内置主题保持一致；按钮继续负责打开和关闭抽屉。

完整切换抽屉

桌面和移动端均只切换 sidebar 布尔状态，不保留 rail 中间态。

不调整主题视觉体系

保留浅灰明暗配色、抽屉宽度、搜索分类、导航项目与页面卡片样式。

不引入状态持久化

本次不把开关状态写入 cookie 或 localStorage，沿用组件挂载时按断点初始化的行为。

Implementation / State contract

删除特例，让现有状态模型重新成为单一事实源
