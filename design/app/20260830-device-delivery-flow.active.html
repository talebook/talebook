统一发送到设备与书籍页插件能力

让默认启用策略、设备发送流程和原生划线笔记共同服从清晰的本地优先模型；外部插件只负责可选同步，不拥有本地阅读能力。

状态：ACTIVE创建日期：2026-08-30所属模块：app影响范围：app、webserver、tests需求来源：当前连续体验反馈与 PR #1022 评审

1. 原始诉求

“brs 默认启用。推送设备也默认全部启用。”
“推送设备 → 发送到设备。”
“书籍页面，推送设备的弹窗……先选择设备类型，然后再针对性弹出其他设置框。”
“转换书籍 → 转换格式。”
“关闭了微信读书插件后，书籍页面里仍然还有微信读书笔记与高亮的框？”
“划线笔记是本次插件版本引入的功能……candle-reader 选中文字后出现划线和笔记工具栏；笔记记录在 Talebook 本地，开启 BRS 后同步；详情页有公开动态和我的笔记两个 tab；阅读器加载章节笔记并渲染划线、章评数量。”

最新反馈澄清了所有权：划线笔记是 Talebook 原生能力，微信读书仅是导入来源，BRS 仅是可选同步端。因此不能以微信读书启停控制整个笔记面板。

PR #1022 评审追加四项要求：公共写接口不得信任客户端作者名；详情页的空数据显隐不能影响阅读器独立面板；同一次选区必须使用稳定幂等键并阻止重复提交；完成仓库指定的 interface-review full 与真实浏览器验收前，方案不得保持 ACTIVE。

2. 目标与边界

目标

  • BRS 与所有发送设备插件首次建库默认启用。
  • 发送弹窗先选类型，再显示 Kindle 邮箱或局域网地址字段。
  • candle-reader 选区可创建本地划线/笔记，并渲染当前章节可见批注。
  • 书籍详情仅在有数据时显示“公开动态 / 我的笔记”双视图。
  • 公开本地笔记在 BRS 连接启用时经插件协议同步。
  • 统一“发送到设备”“转换格式”用户文案。

非目标

  • 不覆盖管理员已有启停选择。
  • 不迁移或删除历史笔记与设备。
  • 不改变 /send_to_device 请求契约。
  • 不让微信读书或 BRS 决定本地笔记是否可用。
  • 不在本轮实现远端删除回滚。

4. 方案

结论：provider 负责首次默认状态；Talebook 的 Annotation 表是划线、笔记和本地章评的权威存储；微信读书只导入，BRS 只同步公开记录。设备发送在同一弹窗内渐进展开，不新增嵌套弹窗。
1. 选择类型

弹窗打开后不预选，也不展示目标字段。

2. 选择或填写目标

有同类型保存设备时可复用；Kindle 显示邮箱，其他设备显示 IP 与端口。

3. 发送

校验类型专属字段，沿用现有后端请求体。

本地批注链路

candle-reader wrapper 监听 EPUB.js 的 selected 与章节变化事件。每次选区创建一次稳定 client_id；保存开始即同步隐藏工具栏并设置 in-flight 锁，重入请求直接返回。写入 /api/book/{id}/annotations 后立即渲染 CFI 高亮。公共 POST 始终从已认证 Reader 生成作者名，不接受客户端作者身份。章节变化按 chapter 查询可见批注并去重渲染。详情组件从同一接口得到“其他用户公开 + 自己全部”的安全集合，再在前端切成“公开动态”和“我的笔记”。仅书籍详情调用点启用“空数据隐藏”；阅读器 iframe 与 TXT 抽屉始终保留加载、空态、刷新和操作反馈。

BRS 同步

公开记录由既有 AnnotationSyncService 查找当前用户已启用的 annotations.push 连接。BRS provider 用独立会话登录配置的服务，根据书名解析远端书籍后写入章评；私有记录不进入同步队列。远端失败只更新来源同步状态，不回滚本地保存。BRS 当前写接口是追加式能力，没有远端更新、删除或幂等键，因此本地笔记后续编辑可能形成新的远端章评，本轮不把它描述为双向同步。

5. 影响、风险与回滚

影响范围

插件 provider 默认值、书籍详情页、双语文案、mock API 与针对性测试。

保持不变

数据库结构、插件 ID、设备推送 API、已存在安装状态及历史笔记数据。

风险：设备切换残留字段会误发，必须切换时清空并按同类型预填。阅读器重复章节事件会重复添加 EPUB.js 标注，必须按 annotation id 去重；同一选区的重复保存必须复用 client id 并由前端提交锁和后端唯一约束共同兜底。公共 HTTP 写入不得把来源字段升级为可信作者身份。BRS 登录 cookie 不得跨用户共享，每次同步使用独立安全 HTTP 会话。CFI 无效时跳过单条渲染，不能阻断章节正文。BRS 远端仅支持追加写入；本地编辑/删除不会覆盖或删除已经同步的章评。

回滚：代码级回滚即可，不涉及数据迁移。

7. 决策记录

  1. 2026-08-30：同一弹窗渐进披露，不用嵌套弹窗。
  2. 2026-08-30：默认启用只作用于首次创建安装记录，尊重管理员之后的关闭选择。
  3. 2026-08-30：撤销“微信读书停用即隐藏笔记面板”的方向；原生批注不依附外部插件，详情空数据才隐藏。
  4. 2026-08-30：Talebook 本地库是权威源，BRS 只接收公开记录的可选同步，失败不影响本地保存。
  5. 2026-08-30：GitHub 评审确认此前验收记录无效：interface-review 实际存在，且真实浏览器门禁未完成；方案退回 WIP。
  6. 2026-08-30：公共批注写入的作者身份归服务端登录态所有；来源同步若需保留远端作者，应继续走内部 writer 服务而非信任公共请求体。
