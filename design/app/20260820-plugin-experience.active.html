插件体验优化

把面向运行时开发者的目录和 JSON 配置，收敛为普通管理员能识别、配置和验证的产品界面。

状态：ACTIVE创建日期：2026-08-20所属模块：app需求来源：TB-66

1. 原始诉求

优化插件卡片层级与操作位置；为 Talebook 元数据建立独立配置页；补充 Open Library 指导；隐藏嵌入文件元数据和 Calibre Bridge 等系统内部能力；按 candle-reader 方案提供 BRS 登录注册；把评价连接器从原始 JSON 改成表单；提供可直接体验的免费开放书源；修复微信读书 API Key 配置后网关请求失败。

2. 目标与边界

目标

  • 卡片首屏即可理解名称、状态、能力标签和主操作。
  • 所有目录内连接器无需填写整段公开配置 JSON。
  • 系统内建解析和发现桥接不伪装成第三方插件。
  • 体验环境内的开放书源与微信读书可以真实访问外部服务。

边界

  • 保留统一插件运行时、连接记录、权限、预览与回滚协议。
  • 评价连接器仍只生成来源候选，不自动覆盖书籍数据。
  • 公共书源遵守来源权利声明，不把“可下载”泛化为全球公版。
  • 不在日志、运行记录或界面回显 API Key、密码和文件正文。

3. 交互方案

识别

名称旁显示状态；名称下方显示业务标签。

行动

启用、配置、打开工作台等主操作固定在右上。

配置

按字段类型渲染输入、选择、标签列表和映射行。

验证

详情页集中测试、预览、执行、停用和查看历史。

连接器呈现决策

对象目录行为配置体验
Talebook 元数据保留为可管理系统能力进入独立页面选择来源、自动补全、封面保留与来源参数。
Open Library / 评价来源展示业务能力标签查询项使用逐项输入/标签列表；来源 ID 有明确提示，不再暴露整段 JSON。
嵌入文件元数据隐藏继续由上传/导入流程自动调用。
Calibre Provider Bridge隐藏在元数据页解释为“自动发现 Calibre Provider 的内部桥接层”。
talebook-brs展示章评连接服务地址 + 邮箱登录/快速注册；映射使用每行“远端=本地”格式。
文件评价展示导入能力来源、格式选择 + 文件内容输入；字段映射折叠为可选高级项。

4. 微信读书故障与修复

在体验容器复现到请求耗时约 30 秒后失败；宿主机同一地址立即返回认证响应，根因是 Mihomo TUN 接管自定义 Docker bridge 后，容器无法到达宿主机代理。部署现通过仅监听 172.23.0.1:35146 的 systemd socket 转发到本机代理，并仅放行 172.23.0.0/16；容器内真实网关请求已在 1 秒内返回预期的未认证 HTTP 401，证明链路恢复。代码同时把超时、DNS/连接异常与认证失败拆分为可操作提示，避免统一显示 WeRead gateway request failed。

5. 数据与兼容性

  • 不新增数据库表；继续使用现有 definition、installation、connection、secret 和 run 数据。
  • manifest 的 ui.hidden 仅改变目录呈现，不删除既有定义、连接或运行记录。
  • schema 表单提交的仍是现有 config / credentials 对象；旧连接可继续读取并被表单编辑。
  • 系统设置保存接口支持部分字段更新；独立元数据页只提交元数据字段，不覆盖其他设置。

6. 验证结果

自动化

  • 后端定向回归 69 passed：书源安全策略、隐藏系统能力、BRS 登录注册、微信读书网络错误。
  • 插件 Playwright E2E 12 passed：卡片、独立元数据页、schema 表单、Open Library 指导、BRS、公开书源、焦点与 320 px 回流。
  • 变更 Vue 文件 ESLint 通过；Nuxt SPA 生产构建通过。
  • 中英文新增命名空间键一致。

实际渲染与外部服务

  • Chromium 1280×900、375×812、320×640 均检查；修复了窄屏插件名截断和操作挤压。
  • Project Gutenberg 真实发现 32 个 EPUB 条目；Internet Archive 真实发现 25 个候选。
  • Standard Ebooks OPDS 当前要求 Patrons Circle 邮箱，因此不标记为“免费公开”。
  • 微信读书容器链路恢复并返回预期认证响应。

Interface review（full）

范围为基于 origin/feat/plugins@882fff2f 的 14 个工作区变更文件（排除 Playwright 产物）。覆盖 accessibility、layout、writing、typography、colors、UI；检查了删除侧信号、桌面/移动实际渲染、键盘切换 BRS 登录注册和焦点恢复。初审发现的两个 MEDIUM（窄屏标题截断、BRS 登录/注册字段混杂）已修复并复验，最终 verdict：Approve。

7. 风险与回滚

  • 远端服务可用性和 schema 会变化；测试连接保留明确错误并不推进游标。
  • BRS 服务版本可能不支持注册；界面将错误原样收敛为表单提示，不把失败当成功。
  • 回滚前端和 manifest 改动即可恢复旧目录；隐藏不删除数据，独立设置页复用原保存逻辑，无迁移回滚。
