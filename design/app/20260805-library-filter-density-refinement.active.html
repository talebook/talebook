Talebook / App / PR #934

让筛选像目录索引，而不是一排按钮

搜索与分页逻辑保持不变，再把标签从“控件尺寸”降到“索引尺寸”，让高密度元数据更适合扫读。

状态：ACTIVE创建日期：2026-08-05所属模块：app需求来源：PR #934 用户追加反馈

1. 原始诉求

“还是太大了。”

上一版已经将筛选标签缩到 13px / 32px，但用户仍认为视觉体量过大。本轮只收紧筛选密度，不改变浮窗搜索、分页、单选与主页面前 10 项策略。

2. 密度决策

降到 12px / 28px / 4px。文字、控件高度和标签间距同时缩小，避免只缩字号却仍保留大按钮轮廓；标题列与面板留白同步收紧。
12px标签与筛选标题字号
28px标签与“显示更多”高度
4px标签横纵间距
主页面面板 8px 内边距，筛选行 6px 间距，标题列缩至约 68px。
浮窗标签同样使用 12px / 28px / 4px；搜索框仍保持 40px，确保输入可用。
保留搜索、结果数、空状态、分页、键盘操作、选中项回显及明暗主题。
不做不改变书卡、全局导航、API、排序或数据库；不继续缩到低于 12px。

3. 实际比例

视觉签名仍是图书馆目录卡，但标签从按钮感较强的 chip 调整为更接近索引签的紧凑矩形。

标签：
全部小说历史中国文学中国文学外国文学书籍文化显示更多（10935）

4. 可用性与边界

  • 12px 是本轮下限，继续缩小会明显损害中英文混排和低分辨率屏幕的辨识度。
  • 28px 标签适合高密度扫读；保留 4px 间隔、明显选中色与键盘焦点，避免相邻项混淆。
  • 搜索框、关闭按钮和分页按钮不跟随标签缩到 28px，保持核心导航与输入操作的稳定性。
  • 长标签继续省略并通过 title 暴露全文；手机浮窗仍全屏，标签区独立滚动。
