原始诉求与目标

用户要求从 AGENTS.md 中移除“创建 WIP 方案时必须使用项目的 frontend-design skill”这一要求，并将修改独立提交 PR。

  • 删除对特定 skill 的强制调用与自检绑定。
  • 不改变方案适用范围、WIP/ACTIVE 生命周期、单文件 HTML、内容完整性、图表价值、测试回写和合并门禁。
  • frontend-design 仍可在任务本身需要视觉设计时按 skill 触发规则使用，只是不再由 WIP 文档类型自动强制。

规范变化

BEFORE / PROCESS-BOUND

每份 WIP 都必须调用同一 skill

文档类型直接决定工具流程，即使方案内容只是后端、CI 或工程治理，也要执行完整视觉设计与自检。

→
AFTER / OUTCOME-BOUND

保留质量标准，解除工具绑定

作者继续对信息层级、离线可读、必要图表和响应式布局负责，但可以选择与任务相称的方法。

最小变更：只删除 AGENTS.md 中两行独立段落，不改写相邻方案质量规则，不修改 skill 文件或检查脚本。

  • 兼容性：不影响现有 ACTIVE/SUPERSEDED 方案，也不改变 make check-design。
