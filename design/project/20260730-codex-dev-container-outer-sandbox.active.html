ENVIRONMENT

TESTABILITY

CONTAINMENT

非 root 阻断 Docker socket

GitHub runner 会强制挂载 Docker socket，因此必须用无附加组的非 root UID、默认 seccomp、零 capabilities 与 no-new-privileges 阻止连接。

EVID已确认事实

证据实际结果结论
失败 job 与同镜像复现 当前 --user root --security-opt seccomp=unconfined 下，codex sandbox -- /bin/true 返回 SeccompInstall(EINVAL)。 工具缺失不是根因；nested sandbox 与 job container 不兼容。
增加 capability 分别增加 SYS_ADMIN，以及 SYS_ADMIN + SYS_PTRACE，仍返回同一 EINVAL。 不能用 capability 堆叠修复；拒绝继续扩大权限。
Dev image 完整工具链 Calibre 8.5.0、Python 3.13.5、pytest 7.4.4、ruff 0.16.0、Codex 0.144.6 均可用，import calibre 指向 /usr/lib/calibre。 该镜像确实承载了不能由裸 runner 等价替换的项目环境。
GitHub job container 系统挂载 官方 actions/runner 源码 src/Runner.Worker/Container/ContainerInfo.cs 对所有 Linux job container 执行 MountVolumes.Add("/var/run/docker.sock", ...)；本地 act 也实际注入该 socket。 --user root 会让模型进程获得宿主 Docker 控制权；“root 且无 socket”的原方案前提不成立。
非 root 外层容器候选 UID/GID 1001:1001、CapEff=0、NoNewPrivs=1、Seccomp=2；socket 为 root:root 0660，连接返回 EACCES (13)。 无附加组的非 root 身份配合 no-new-privileges，可把 runner 强制挂载的 socket 变为不可用资源。
非 root 完整测试候选 为 CI 测试数据提供 UID 1001 可写的 /data tmpfs，并设置 USER/LOGNAME 后，Calibre、Codex、依赖同步均可用；候选快照全量测试 697 passed、1 skipped。 不需要 root 也能保留完整 dev image 功能；/data 仅在一次性 CI job 内存续。
Codex 无内层 sandbox 模式 sandbox_mode="danger-full-access" 与 approval_policy="never" 在加固容器内成功执行 /bin/true。 可以绕开已证伪的 nested bwrap，同时保留完整镜像环境。

用户已重新确认的修正：继续以“Codex 直接处于完整项目环境”为优先目标，但把 job 用户从 root 改为 1001:1001，并为测试所需的 /data 提供一次性 tmpfs。原因是 GitHub runner 强制挂载 Docker socket，原先批准的 root 前提会导致宿主失守。

必须公开的剩余风险：模型命令与 Codex 进程处于同一容器，因此不能再宣称 shell 无法读取容器内其他路径或 Codex 凭据。shell environment policy 继续过滤 token 类环境变量，但它是纵深措施，不替代文件系统 sandbox。

DEC候选方案与决定

候选决定依据
非 root dev job container + 不可访问的 Docker socket + Codex danger-full-access 采用 满足完整项目环境；非 root 候选的全量 pytest 已通过，socket 连接被内核权限拒绝；符合 Codex 对“外部 sandbox”模式的定位。
root dev job container 拒绝 GitHub runner 强制挂载宿主 Docker socket；root 即使没有 capabilities，仍可通过 Docker API 创建高权限 sibling container 并控制宿主。
裸 hosted runner + pip 安装测试依赖 拒绝 没有 Calibre runtime、插件、资源、动态库和镜像路径，不能代表 Talebook 完整环境。
privileged / 增加全部 capabilities 拒绝 扩大宿主攻击面；较窄 capability 已证明不能解决 EINVAL。
宿主 Codex + Docker/SSH 命令转发 拒绝 Codex 并非直接处于项目环境，命令语义、路径和工具发现需要额外 wrapper，不符合用户硬约束。
