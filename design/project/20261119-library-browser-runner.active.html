固定书库浏览器测试的 Ubuntu 版本

状态：ACTIVE 创建日期：2026-11-19 所属模块：project 需求来源：PR #1102 CI

1. 原始诉求

“CI红灯了”。书库浏览器回归在安装 Chromium 时退出。

2. 目标与影响范围

恢复 Chromium 安装和书库浏览器回归。改动限于 GitHub Actions 的 test-library-browser 作业，影响测试基础设施，无界面影响或产品规则变化，无对应的 spec/ 篇目。

3. 方案

失败日志显示 ubuntu-latest 分配了 Ubuntu 26.04，锁定的 Playwright 1.58.0 缺少此版本的 Chromium 依赖清单。将该作业固定到受支持的 ubuntu-24.04，执行原有依赖安装、构建和浏览器测试步骤。

Claude 审查在会话启动后退出，重试仍缺少结构化输出。11 月 16 日的另一条 PR 运行也发生同样的错误。重试日志 · 历史日志

4. 测试结果

使用 act 0.2.82 在 Ubuntu 24.04 x64 本地容器执行真实工作流。事件为 pull_request 的 synchronize，使用临时事件文件和空 GitHub token。

act pull_request -W .github/workflows/ci.yml -j test-library-browser \
  -e /private/tmp/talebook-nginx2root-pr-event.json --pull=false \
  --container-architecture linux/amd64 \
  -P ubuntu-24.04=ghcr.io/catthehacker/ubuntu:act-24.04 \
  --secret-file /dev/null -s GITHUB_TOKEN= --env-file /dev/null \
  --var-file /dev/null --input-file /dev/null --container-daemon-socket - \
  --action-cache-path /private/tmp/talebook-nginx2root-act-cache \
  --cache-server-path /private/tmp/talebook-nginx2root-act-job-cache \
  --artifact-server-path /private/tmp/talebook-nginx2root-act-artifacts
  • 本地检出、Node 20 安装、npm ci、Playwright 系统依赖及 Chromium 安装、Nuxt 构建均完成。15 项组件测试、25 项 Chromium 测试全部通过。临时 runner 使用 Ubuntu 软件仓库镜像并预下载了同版本 Chromium，以缩短本地下载时间。
  • 制品步骤找到了 3 个结果文件，连接本地模拟制品服务时收到 ECONNRESET，act 整体退出码为 1。实际制品上传以及浏览器作业最终状态由 GitHub 托管检查确认，检查通过前不宜合并。
  • make check-design、make check-spec 和 git diff --check 通过。
