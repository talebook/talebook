Talebook Audio CLI 独立客户端

在 Talebook 仓库内新增可独立安装的 Python 命令行包，通过现有账号密码接口登录、浏览已发布有声书并以 mpv 播放。

状态：ACTIVE创建日期：2026-08-28所属模块：packages需求来源：HOU-20

1. 原始诉求

实现独立可安装、可运行的 Talebook 有声书命令行客户端；用户配置服务地址和账号后，以密码登录，浏览账号可访问的已生成有声书，选择章节播放，并支持暂停、继续、上一段、下一段、进度和可靠退出。

2. 目标与边界

目标非目标
独立 Python 包；兼容现有 Talebook API；密码不落盘；会话文件权限为 0600；mpv 前台受控播放；错误信息可行动。不修改服务端接口；不生成有声书；不提供 GUI；首版不实现跨设备播放进度回写和 Windows 命名管道。

3. 现状证据与接口

  • POST /api/user/sign_in 接受表单 username/password 并设置安全 Cookie。
  • GET /api/audios 返回当前访问者可见的 published edition。
  • GET /api/audio/{edition_id} 返回有序章节、时长和相对音频 URL。
  • GET /media/audio/{edition_id}/chapter/{number}.mp3 支持 Range，且私有书依赖同一登录 Cookie。
  • neteasecli 使用 mpv IPC 实现播放、暂停、切换、进度与退出控制，本实现沿用这一边界但保持前台进程归属。

4. 方案

配置
仅保存规范化服务地址和用户名。
登录
getpass 或 stdin 读取密码，持久化 0600 CookieJar。
浏览
解析 books/edition/chapters，提供列表和交互选择。
播放
临时 mpv IPC socket；Cookie 文件供媒体请求；退出总是终止子进程。

包路径为 packages/talebook-audio-cli，命令名为 talebook-audio。CLI 子命令包括 configure、login、logout、books、chapters 和 play。未显式给出 book/chapter 时进入编号选择；播放循环支持暂停/继续、上一章、下一章、状态和退出。

5. 安全、兼容性与风险

  • 密码不进入命令行参数、日志、配置、Cookie 文件或异常文本；登录错误只展示服务端安全消息。
  • 配置目录遵循 XDG，写入时使用原子替换和 0600 权限；服务 URL 拒绝凭据、查询和片段。
  • Cookie 通过 mpv 的 cookies-file 读取，进程参数不含 Cookie 值；临时 IPC 目录退出即清理。
  • 风险：启用登录验证码的部署无法仅靠账号密码完成登录，CLI 会明确报告服务端 captcha 错误。

  • 通过：PYTHONPATH=packages/talebook-audio-cli/src python3 -m pytest -q packages/talebook-audio-cli/tests，21 个配置、登录响应、列表/manifest 解析、URL、mpv 缺失、播放器清理和 CLI 测试通过。
  • 通过：ruff check packages/talebook-audio-cli 与 ruff format --check packages/talebook-audio-cli。
  • 通过：make lint-py-fix 和 make lint-py；既有 102 个服务端 Python 文件无需修改。
  • 通过：使用本机 setuptools 以 pip wheel --no-build-isolation --no-deps 构建 talebook_audio_cli-0.1.0-py3-none-any.whl，随后安装到隔离临时目录并执行 python3 -m talebook_audio_cli.cli --help。
  • 环境受限：make pytest 在收集既有服务端测试时因本机缺少 Calibre 出现 6 个 import error；错误发生在与本包无关的测试模块，未伪报为通过。
  • 界面审查：按 interface-review full 审查相对 origin/master 的全部 13 个未跟踪文件。首轮发现中英文混用、空状态无下一步、非 TTY 选择无法退出和窄终端 CJK 进度截断；全部修复后复审结论为 Approve，无 HIGH 或 MEDIUM 问题。无颜色、动画或 Web 页面变更。
  • 未验证：运行环境没有 mpv，也没有可登录的目标 Talebook 实例，因此未做真实音频渲染；风险由缺失依赖测试、IPC/清理单测、API 形状测试和使用文档覆盖，仍建议合并前在真实部署上做一次播放冒烟测试。

7. 决策记录

  • 选择 Python 3.11 标准库，避免给 Talebook 服务端增加运行时依赖，包仍可独立发布安装。
  • 不保存密码；“配置密码”由安全的交互式登录步骤承担，会话复用满足非浏览器 Cookie 导入要求。
  • 不让 mpv detached/unref；客户端拥有播放器生命周期，SIGINT、正常退出和异常退出都回收进程。
