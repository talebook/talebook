大响应完整性与分类列表分页

2026-09-12 · docker · ACTIVE · Issue #1045 / TB-214

原始诉求与证据

约四万本书的书库访问 /api/tag 及其他接口时响应截断，建议分页。三张原始截图包含浏览器网络错误、JSON.parse end of data / bad Unicode escape，以及响应尾部停止于 Unicode 转义中途。这是真实响应不完整，不是 DevTools 仅折叠展示。没有报告者的服务器日志、原始响应头或数据库，不能断言其部署中的唯一根因。

MetaList 的热门项过滤会让 items 少于 total，但始终返回完整 JSON；默认筛选不是严格 300 条上限。分页能降低部分负载，却不能修复其他大响应的代理传输故障。

新增需求：千条分类列表分页

2026-09-12：开发者明确将 1000 条及以上分类列表分页纳入本次交付，先前仅针对代理修复的 QA 结论不覆盖分页。PR #1046 尚未合并，保持同一份 ACTIVE 方案，原代理修复与传输回归保留。

调用范围：MetaList 的 tag / author / publisher / series / rating / format 六个接口与独立页面，以及 LocalLibraryContent 使用的四个元数据筛选入口。MetaBooks 和书库书籍列表已有 start/size 分页，不改动书籍协议；新增分页针对分类条目。

接口：page 从 1 起、page_size 默认 100 且范围 1–1000、q 为名称包含搜索。先完成作者别名聚合和搜索，再稳定排序（数量降序、名称大小写归一化、原名称、id；评分按评分降序），最后在服务端切页。未传分页参数且匹配条目少于 1000 时可返回完整小列表；达到 1000 或显式传入 page/page_size 时分页。返回 err/meta/title/items/total/unfiltered_total/page/page_size/pages/paginated。空列表 pages=1；越界页返回空 items；非法参数返回 params.pagination.invalid。show=all 仍兼容但不能绕过页上限。用可遍历的完整分类列表替代过去隐式热门项过滤，避免翻遍所有页仍遗漏低频条目；不再需要“显示全部”请求。

前端：分类页使用 100 条服务端页面、搜索、结果总量、翻页、加载/空/失败重试状态。书库筛选初始只请求前 10 项，弹窗搜索及翻页每次请求 100 项，保留选中条目；离线传入 items 的旧组件用法保持兼容。页/搜索/分类切换丢弃过期响应，搜索切换回第一页，不拉全量拼接。

分页减少响应体与 DOM，聚合和排序仍在服务端完成，未声称数据库常量时间分页。数据在两次请求之间改变可能移动页边界，不提供快照一致性。原慢客户端容量、真实书库与代理日志缺口继续保留。

新增分页验证完成：真实 Tornado HTTP 测试覆盖 999/1000/1001、空/末页/越界/非法参数、4 万条稳定遍历、搜索与别名聚合（最小后端 21 passed）；完整 make pytest 为 1327 passed、22 skipped、78 warnings，202.45s。前端 4 文件 9 tests passed，补充清理代码变更后相关单文件测试通过；npm run lint、npm run build、make lint-py-fix / lint-py 通过。Chrome DevTools MCP 1.9.0 验证生产 Nuxt 构建与真实 Nginx/Calibre：1035 条初始 100 条，搜索“分页”命中 1001 条，第 11 页 1 条；断网重试恢复；书库初始 4×10 项、弹窗 100 项/页，选择后书籍从 start=0 请求。320px 中文深色和 1280px 浅色页面已截图，正常控制台无错误。full interface-review 裁决 Approve：修复窄屏页码拥挤、旧统计误导与弹窗焦点恢复；原深色主题 primary 对比度约 4.07:1 为基线已有问题，未改主题，不计入本次裁决。屏幕阅读器/iOS/所有外部主题/200% 浏览器缩放未验证。最终 SHA 的完整 CI 按会话要求在本轮前台收集，终态证据见 PR 与议题附件。

原代理修复方案（保留）

验证代理临时文件不可写时是否重现同型截断。故障注入已成立。在 SPA、SSR、dev 共用的 nginx.conf 的 http 层设置 proxy_max_temp_file_size 0，保留默认内存缓冲和背压，使非缓存代理响应不再依赖磁盘临时文件。这一原始传输修复保持接口内容；新增分页协议和热门过滤调整见上节，分页现已属于交付范围。

影响范围：公共 Nginx 配置、大响应传输回归测试。临时磁盘不可用时使用流式传输，慢客户端会更长时间占用上游连接；不扩大内存缓冲。不涉及代理缓存（当前配置没有 proxy_cache）。部署需更新镜像/配置并重启 Nginx；回滚为还原配置。

设计决策核对

grill 技能在会话技能目录及本机搜索中未找到；按现有授权自行核对边界：先复现、保留 API 兼容、覆盖三种部署、以慢客户端触发落盘、同时验证可写与不可写临时目录及 root/非 root。不以增大缓冲、关闭 JSON 错误检查或强制 root 权限处理问题。

原始代理修复没有界面影响；本次新增分页改变前端契约和交互，因此执行 full interface-review，不再豁免。剩余风险是原报告环境未采集日志，若问题来自外层代理或上游退出仍需单独排查。
