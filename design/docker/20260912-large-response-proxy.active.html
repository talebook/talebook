大响应代理完整性

2026-09-12 · docker · ACTIVE · Issue #1045 / TB-214

原始诉求与证据

约四万本书的书库访问 /api/tag 及其他接口时响应截断，建议分页。三张原始截图包含浏览器网络错误、JSON.parse end of data / bad Unicode escape，以及响应尾部停止于 Unicode 转义中途。这是真实响应不完整，不是 DevTools 仅折叠展示。没有报告者的服务器日志、原始响应头或数据库，不能断言其部署中的唯一根因。

MetaList 的热门项过滤会让 items 少于 total，但始终返回完整 JSON；默认筛选不是严格 300 条上限。分页能降低部分负载，却不能修复其他大响应的代理传输故障。

目标与方案

验证代理临时文件不可写时是否重现同型截断。故障注入已成立。在 SPA、SSR、dev 共用的 nginx.conf 的 http 层设置 proxy_max_temp_file_size 0，保留默认内存缓冲和背压，使非缓存代理响应不再依赖磁盘临时文件。接口内容、热门筛选、show=all 与客户端行为保持兼容。本次不做分页或性能优化；没有证据证明分页是传输修复前提。

影响范围：公共 Nginx 配置、大响应传输回归测试。临时磁盘不可用时使用流式传输，慢客户端会更长时间占用上游连接；不扩大内存缓冲。不涉及代理缓存（当前配置没有 proxy_cache）。部署需更新镜像/配置并重启 Nginx；回滚为还原配置。

设计决策核对

grill 技能在会话技能目录及本机搜索中未找到；按现有授权自行核对边界：先复现、保留 API 兼容、覆盖三种部署、以慢客户端触发落盘、同时验证可写与不可写临时目录及 root/非 root。不以增大缓冲、关闭 JSON 错误检查或强制 root 权限处理问题。

无界面影响：没有页面、布局、文案、交互或前端契约变化，仅恢复完整响应，interface-review 豁免。剩余风险是原报告环境未采集日志，若问题来自外层代理或上游退出仍需单独排查。

QA 修订：临时目录隔离

2026-09-12：QA 拒绝当前验收，CI 的 Calibre 临时父目录为 0700，导致 UID 911 无法读取配置，root 主进程的降权 worker 也不能使用声称可写的临时目录。此前普通 /tmp 下的验证不足。此 PR 尚未合并，已在同一份方案中记录修订与重新验证结果。

夹具在固定 /tmp 下用 TemporaryDirectory 创建唯一目录，不依赖 TMPDIR 或 tempfile.tempdir 缓存；仅对自建目录/文件调整权限，不修改 /tmp、Calibre 目录或其他父目录。新增受限 TMPDIR 测试类，设置 0700 的自建模拟父目录并同时覆盖环境和 Python tempfile 缓存，继承完整的正反对照矩阵。正向结果同时断言 Nginx 错误日志没有 Permission denied。验证结束检查受限父目录的属主与权限未被改动。

修订验证：docker run --rm --network none --entrypoint python3 -v "$PWD:/workspace:ro" -w /workspace talebook/talebook:master -m unittest tests.test_nginx_large_response -v：6 tests 通过（9.670s），普通和受限 TMPDIR 各运行 12 个正向子场景及原配置正反对照。父目录属主/权限未变，所有正向日志无 Permission denied。随后在含 Calibre 且已安装当前 requirements.txt / requirements-test.txt 的隔离容器执行完整 make pytest：1319 passed、22 skipped、78 warnings，131.84s，退出 0。命令：docker run --rm --network host --entrypoint sh -v "$PWD:/source:ro" talebook:tb214-revision-tests -c 'cp -a /source /opt/tb214-tests && cd /opt/tb214-tests && make pytest'。镜像 sha256:4961bdb282a970f4fa6a6670ce22a769f22c33af763c92066070a908f14700ed；仅容器内副本可写，不挂载实际书库。ruff check / format、make lint-py-fix / lint-py 通过。修订最终代码重新运行下述 DeepSec 命令：527 文件、L1/L2、退出 2、122 项既有发现；新增测试单文件复扫 1 文件、退出 0、0 findings。生产 .conf 的覆盖边界不变。完整 CI 将在推送最终提交后于同轮前台收齐，最终 SHA 对应的结果随 PR/议题附件交付。
