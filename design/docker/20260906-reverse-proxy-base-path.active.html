子路径反向代理支持

创建日期：2026-09-06 · 模块：docker / app / webserver · 状态：ACTIVE

来源：开发者希望将 Readest 测试环境挂载到 miu.rexliao.cn/readest-test。

原始诉求与目标

为 Talebook 增加可配置子路径，覆盖页面、静态资源、API、登录、下载、阅读器与客户端入口。默认根路径行为兼容。主干为实现基线，Readest PR #977 为集成验证对象。

设计决策与边界

已检查根路径假设、Nuxt 静态构建、Tornado URL 输出及 Nginx 转发。未找到独立 grill 技能，按仓库要求逐项核对设计决策，并依据既有场景确定选择。

  • 显式 TALEBOOK_BASE_PATH 配置默认空前缀，支持 /readest-test 或多级 ASCII 路径；拒绝协议、查询、片段、编码绕过及点路径。
  • 路径在前端构建时固定；Docker build arg 注入前后端。改变路径需重建镜像，不改写生成的 JavaScript。
  • 外部代理移除路径前缀。内部路由保持根路径；应用生成带前缀的对外 URL 与 cookie，不信任 X-Forwarded-Prefix。
  • Vue 路由由 Nuxt baseURL 处理；网络请求及非路由 URL 使用统一路径函数。外部 URL 与 data/blob 地址保持原样。
  • 不改变数据库与鉴权；按开发者授权仅映射独立测试环境。子路径不构成独立 origin 隔离。
  • Readest 未合入主干，集成验证其静态资源、宿主协议及 service worker 范围。

方案

浏览器 /readest-test/... → 外部反代去前缀 → 容器根路径 → 原 Tornado 路由。响应 URL 与 Location 加前缀，cookie 限定子路径。提供 Caddy/Nginx 示例。
