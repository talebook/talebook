部署闭环

生成随机 Token
  → 写入仅限本机的 .env
  → docker compose up -d
  → 检查 /api/welcome
  → 配置 TALEBOOK_MCP_URL 与 Token
  → talebook_mcp.py check

参考文档必须说明 Token 与管理员身份的关系、默认关闭行为、不得提交密钥，以及变更 Token 后重建容器。
