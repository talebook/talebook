Original request

原始诉求

在仓库中提供一个面向最终用户的 Talebook Agent Skill，让用户通过自然语言操作自托管实例，而不是得到开发指导。Skill 使用 Talebook 现有 HTTP API，覆盖公开访问、可选账号认证、普通用户和管理员操作，并提供 Docker Compose 部署参考。

最终命令面还需支持服务端更新提醒、多步工作流纪律，以及主干已发布有声书的列出、查看和整本下载。一个 PR 只保留本方案，本文直接描述最终有效设计，不记录阶段性实现过程。

Goals and boundaries

目标与边界

纳入

自包含 skills/talebook/；单体 Python CLI；guest 与 Basic Auth；查询、常规写入、管理员操作和部署参考；风险预览；敏感设置输出脱敏；流式原子下载；更新提醒；已发布有声书消费接口。

不纳入

不新增或修改 Talebook 后端 API；不提供任意 raw HTTP、MCP 服务或 CLI 部署命令；不保存凭据；不绕过验证码和权限；不封装仍快速变化的有声书生成管理接口。

Control rail

每次请求走同一条控制轨道

  1. 01
    预检确认站点、身份与权限
  2. 02
    定址搜索并解析唯一资源 ID
  3. 03
    门禁展示目标、数量与影响
  4. 04
    执行通过 CLI 调用原有 API
  5. 05
    核验重新查询、检查文件或保留 task ID
Command surface

按领域组织命令，不留任意请求逃生口

me status | update | devices ...
books list | search | show | upload | download | edit | delete
books favorite ... | shelf ... | reading ... | send ...
audios list [--keyword] | show --book-id | download --book-id --output
remote sources ... | search ... | explore ... | books ... | library ...
admin users ... | books ... | imports ... | booksources ...
admin opds ... | settings ... | trash ... | ssl ... | themes ... | logs ...
GUEST FIRST

最少配置

站点地址必填；用户名和密码成对可选。未提供凭据时不发送 Authorization。

UNIQUE TARGET

先找真实 ID

通过列表与详情解析 book、source、task 等 ID；结果不唯一时交给用户选择。

NO BLIND RETRY

写失败不重试

先报告服务端错误和可能的副作用；组合写入明确返回已完成与失败步骤，再读取状态，不自动重复写入。

Risk model

权限与风险门禁

等级代表操作执行规则
只读搜索、详情、列表、状态直接执行，保留后续步骤需要的 ID。
常规写入上传、收藏、书架、阅读状态用户原请求已授权即可执行；完成后重查。
外部副作用发送邮箱或设备展示书籍与目标，明确确认后添加 --confirmed。
管理写入用户、设置、书源、主题先验证管理员身份，再展示字段和影响。
破坏性删除、清空、数据库迁移展示精确目标、数量和不可逆影响；确认变化后重新预览。
Published audio

有声书只跟随稳定消费面

命令接口契约
audios listGET /api/audios列出当前身份可见的已发布有声书，可按书名或作者过滤。
audios show/api/book/{id}/audios + /api/audio/{edition}使用 book ID 解析当前 published edition，只输出书籍与章节 manifest。
audios download/media/audio/{edition}/chapter/{number}.mp3按章节号流式下载整本；目标目录必须不存在；逐章临时文件和整本临时目录全部成功后才原子落位。

章节文件使用至少三位数字前缀并净化标题，如 001-科学边界.mp3。响应按固定大小分块写入，不把完整 MP3 缓存在内存；任一章节失败时清理临时内容，不把半本书报告为完成。生成任务、工作区、发布回滚、播放会话、Podcast 和统计不属于本次命令面。

Non-blocking update notice

先完成用户任务，再提醒更新

管理员命令成功后，CLI 尽力读取服务端 GET /api/admin/update 缓存；有新版本时把精简信息附加到 _notice.update。提醒失败不得改变原命令结果，guest、普通用户和业务失败不附加提醒。

Skill 只在交付末尾简短展示当前版本、最新版本和发布页，不自动升级实例。稳定脚本可设置 TALEBOOK_NO_UPDATE_NOTIFIER=1；用户明确要求更新时再读取 Docker Compose 参考并确认部署目录。

File architecture

Skill 自包含结构

文件职责加载时机
SKILL.md预检、风险门禁、执行、核验、更新提醒与部署分支。Skill 每次触发。

agents/openai.yamlSkill 展示名称、短描述和默认提示。宿主加载。

Risk and rollback

风险与回滚

风险控制
后端接口继续变化命令只封装已核实接口；细节集中在 CLI 与 API 参考，并用 mock HTTP 契约测试固定。
凭据或更新信息泄露优先环境变量；预览脱敏；更新提醒只读服务端缓存且不自动升级。
管理员设置进入 Agent 上下文在 CLI stdout 边界递归隐藏密码、secret、token、API key、访问码和 URL 凭据，不依赖 Agent 事后摘要。
高风险误操作CLI 强制确认参数，Skill 先展示目标与影响，服务端权限仍是最终边界。
有声书下载耗尽内存或留下半成品固定分块流式写入、净化文件名、拒绝覆盖、逐章临时文件、整本临时目录和原子落位。

整个 Skill 可以从 skills/talebook/ 独立移除，不影响 Talebook 后端数据、API 或前端。核心命令或安全模型以后发生变化时，应直接创建新的替代方案，不在本 ACTIVE 文件中追加过程记录。
