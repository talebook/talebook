AI 标签整理：高效表格审阅、预览与安全撤销

为长期书库提供高密度、可批量操作、可解释的标签整理工作台；任何写入仍必须经过精确预览和二次确认。

状态：ACTIVE创建日期：2026-08-16本轮迭代：2026-08-17所属模块：webserver影响范围：webserver、app、tests需求来源：TB-59

1. 原始诉求

长期书库存在同义、繁简、大小写、全半角、错别字、低使用率和粒度不一致标签。系统应先用确定性规则归一格式，再通过统一 AgentRuntime 提供语义建议；用户可修改目标、排除书籍、预览、确认、部分重试和整体撤销，且不得越权、跨库或覆盖后续人工修改。

2026-08-17 交互反馈

原卡片式建议审阅和逐书预览信息密度低，多条建议下需频繁滚动，也缺少搜索、批量选择和集中确认。本轮改为以表格为主的紧凑工作台，将高频操作固定在工具栏，单书排除收进行内弹窗，预览按书籍行对比。

2. 目标与边界

目标

  • 建议包含动作、源/目标、理由、置信度、冲突和影响书籍。
  • 保存用户选择但不写库；预览时重算准确变更集。
  • 确认时重查 ACL 与版本，幂等执行并保存前后快照。
  • 撤销只恢复仍处于本任务写入后状态的书籍，冲突显式跳过。

非目标

  • 不自动生成全库新标签或构建多层本体。
  • 不把正文或无关书籍元数据发给模型。
  • 不支持未经确认的自动执行。
  • 不跨 Calibre 书库合并同名标签。

3. 方案与数据流

分析读取可编辑书籍的标签和最小标题标识，记录基线版本。
建议确定性格式规则先产出；其余标签交给 Codex app-server。
调整用户接受、忽略、改目标或排除单书，不产生写入。
预览/执行服务端重查权限和版本，展示后再使用幂等键确认。
撤销按任务快照恢复；检测后续人工修改并跳过冲突。

接口

接口语义写库
POST /api/ai/tag_organizer/tasks创建分析任务；scope 支持全部可编辑书籍、book_ids 或 tags。仅任务库
PATCH .../tasks/:id保存选择、目标和排除书籍。仅任务库
POST .../:id/preview重查 ACL/版本并生成精确逐书变更。仅任务库
POST .../:id/execute要求 preview token 和 idempotency key；逐书版本检查后应用。Calibre + 快照
POST .../:id/retry只重试失败或冲突后重新满足条件的变更。Calibre + 快照
POST .../:id/undo要求 idempotency key；恢复未被后续修改的成功变更。Calibre + 撤销结果

4. 权限、并发和失败语义

  • 入口要求登录、Reader.can_edit()，并对每本书要求管理员或收藏者所有权；无权书籍不进入建议、预览或执行。
  • 分析只发送标签名称、使用量和匿名化对象编号；标题仅在本地影响列表展示，不进入 Agent prompt。
  • Runtime 非终态、协议错误或 schema 校验失败只将任务标为 failed，不生成可预览建议。
  • 预览 token 绑定规范化调整、可编辑书籍及其标签版本；确认阶段任何变化都成为显式冲突。
  • Calibre 写入置于库锁内；每本书持久化 before/after snapshot 和结果，中途异常作为可重试的部分失败显式报告。

6. 决策记录

日期决策理由
2026-08-16使用独立标签整理任务模型，不扩展书籍章节型 AITask。范围、版本、预览、执行和撤销状态与章节生成字段不同，避免大量空字段和错误耦合。
2026-08-16格式等价建议确定性生成，语义建议由 Runtime 补充。降低成本、保持可复现；模型不拥有写入权限。
2026-08-16采用逐书快照与补偿回滚。Calibre API 是写入权威且不与 Talebook SQLAlchemy session 共享事务。
