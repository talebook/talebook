兼容微信读书升级提示

创建日期：2026-11-23 所属模块：webserver 状态：ACTIVE 需求来源：Issue #1097

原始诉求与目标

读者在绑定微信读书时遇到 Skill 升级提示。按腾讯 Skill 1.0.6 处理通知，不让带有效业务数据的通知挡住绑定和导入。反馈没有安装版本或实际回包，不能确认这是该实例的唯一原因。

方案

网关上报 1.0.6。先处理既有 HTTP 与非零 errcode 错误，通知不能覆盖这些错误。笔记本必须有 books 数组，空数组是成功；通知随划线或点评分页返回时，要求对应业务数组，防止假空页或提前结束。其他既有接口的带通知回包也必须有实际业务字段。通知伴随有效结果时不重发请求；绑定沿用已有健康信息字段告知，业务回包原样保留，不自动打开或采纳上游通知中的链接。

影响范围、风险与回滚

仅影响内置微信读书 Provider、测试和 微信读书 规格；没有页面、布局或交互改动。既有鉴权、密钥归属、重试策略、请求参数名单和搜索推荐的隐私边界不变。回滚为还原方案对应代码，无库表迁移。

  • 改动 Python 文件的 ruff check 和 ruff format --check，以及 git diff --check 均通过。
