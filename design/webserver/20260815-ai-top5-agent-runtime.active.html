总结鸭 TOP5 与 Codex app-server AgentRuntime

在 EPUB 当前章节内生成恰好五组可核验问答，并以无工具、无书库访问的短生命周期运行时隔离模型执行。

状态：ACTIVE创建日期：2026-08-15所属模块：webserver / reader 需求来源：TB-53基线：master（远端无 feat/ai_1.0）

1. 原始诉求

用户在 EPUB 当前章节主动触发“总结鸭”，得到结构化 TOP5 问答；事实性答案必须带章节内引用，并支持回跳、编辑、保存、删除、整组重生成、取消、重试和 Markdown 导出。首版模型执行只允许经 Codex app-server，不直接调用 OpenAI API 或 SDK。

2. 目标与边界

目标明确不做
运行时稳定接口、Codex stdio 适配器、结果/引用双重校验、创建者隔离、任务状态与安全阅读器 UI。Claude Code 与 Trae 真实适配器、PDF/OCR、跨书研究、角色卡、前情提要、公开分享及全书后台扫描。

3. 核心流程

权限与输入
后端再次校验书籍可见性；仅接收裁剪后的当前章节文本、标题和 locator 范围。
隔离运行
临时空目录启动 codex app-server --listen stdio://，禁止审批、网络和写入。
终态校验
仅接受 turn/completed；业务层重验 schema、Markdown 和章节内引用。
成果交付
按创建者保存 AI 原稿与用户修订稿；前端可编辑、回跳、导出、重试或删除。

4. AgentRuntime 契约

能力位至少包含 native_output_schema、resume、cancel、usage、model_selection。一次生成发布启动、进度和唯一终态事件；错误只暴露分类和脱敏消息。Codex 适配器按官方协议执行 initialize / initialized / thread/start / turn/start.outputSchema / turn/completed / thread/delete，取消时发送 turn/interrupt 并清理进程组。

固定验证版本范围为 >=0.147.0,<0.148.0；不匹配、缺失、未登录、额度、崩溃、握手/首进度/静默/总时长超时均失败关闭。

5. 数据、权限与安全

  • 保存创建者、book id/version、章节 href/title/hash/长度、五问五答及 locator、AI 原稿、用户稿、schema/prompt 版本、状态、用量与时间。
  • 列表、详情、编辑、删除、取消与导出均限定创建者，同时每次读取重新校验书籍权限和版本。
  • 不持久化章节正文或完整提示；任务目录为空且只读，无 MCP、动态工具、网络或书库目录。
  • Markdown 仅支持纯文本与 **/__ 强调；所有 HTML、style、script 和危险 URL 作为文本处理。

6. API 与界面

/api/ai/top5 创建/列表，/api/ai/top5/:id 查询/编辑/删除，附加 cancel 与 export 操作。阅读器浮动入口打开侧栏，状态依次为待处理、生成中、成功、失败或已取消；引用按钮向宿主派发 locator 回跳事件。

亮暗主题均使用橙红 token，结构顺序固定为编号、问题、答案、原文引用。键盘焦点、状态提示和窄屏布局纳入验收。

7. 风险与关闭策略

  • 阅读器当前没有稳定章节抽取 API：提供显式桥接事件，并仅在同源 EPUB iframe 可读时自动采集；不可读时提示用户重试。
  • Codex 协议随 CLI 版本变化：版本门禁、保存 fixture、未知消息容忍、缺终态失败。
  • 进程泄漏与取消竞态：单任务进程组、幂等取消、唯一终态锁和 finally 清理。

  • 后端完整测试：837 passed, 20 skipped, 7 subtests passed；TOP5 定向测试：14 passed。

9. 界面 Full Review

范围为相对 origin/master 的全部未提交变更；直接审阅阅读器入口、空态、加载、成功、失败、取消、编辑、窄屏、亮暗主题和键盘路径。快照、fixture、测试结果和二进制图片不作为源码审阅对象，但检查了引用它们的 E2E 与真实 Chromium 渲染。

首轮发现并修复三个引入问题：弹窗焦点可逃逸/背景未 inert、编辑文本域缺少程序化标签、绝对定位 footer 在 320px/缩放时可能遮挡内容。同时补齐稳定 live region、背景滚动隔离、焦点恢复、保存失败保留草稿和可缩放 viewport。复查无剩余 HIGH 或 MEDIUM；Accessibility、Layout、Writing、Typography、Colors、UI 六个领域 verdict 为 Approve。

刻意保留的设计决策：引用使用描边按钮而非静态引文以明确回跳能力；问题标题继续使用橙红色，因为这是 TB-53 的明确视觉语义，并已通过亮暗对比度测试；生成 spinner 在 reduced-motion 下减速而非取消，属于功能性进度反馈。
