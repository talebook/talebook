恢复 Calibre 和 NeoDB 元数据候选的详情查询

创建日期 2026-11-21 · 模块 webserver · 状态 ACTIVE · 来源 GitHub #1089

原始诉求

从互联网更新信息时，选中部分来源的候选后提示未获取到所选记录。

目标与边界

保留 Calibre 与 NeoDB 候选重查时需要的查询条件，区分 Calibre 的多条候选。豆瓣 V2 的修复由 #1096 跟踪。

方案

Calibre 用原查询重新定位来源与条目，避免返回其他候选。NeoDB 仍通过搜索匹配所选条目的 URL，避免将外部引用用作新网络目标。使用各来源独有的版本化候选引用。合法版本引用必须精确匹配原条目，查不到就要求重新搜索，绝不退回第一条。对以版本前缀开头、但不符合引用结构的旧标题，按原文查询并要求返回书名完全相同；不套用近似书名。影响规格：插件／元数据源。
