让“猜你喜欢”可解释、可纠偏且不越权

在用户当前可访问的书库中确定性召回候选，复用统一 Agent Runtime 排序与生成非剧透理由；所有失败都回落到透明的确定性推荐。

状态：ACTIVE创建日期：2026-08-16所属模块：webserver影响范围：webserver、app、tests需求来源：TB-61

1. 原始诉求

“只从用户已有且当前可访问的书库推荐；服务端确定性召回，Agent 仅负责候选排序与理由；支持冷启动、反馈撤销、隐私开关、缓存刷新与确定性降级；Runtime 前后双重 ACL 校验。”

现有 feat/ai_1.0 已有统一 AgentRuntime 与 Codex app-server 适配器，但还没有书库级推荐、独立反馈和推荐界面。

2. 目标与边界

目标

  • 登录用户在首页获得 10–12 本当前可读书籍及可追溯、非剧透理由；书库不足时返回全部合格项。
  • 收藏、想读、在读、完读、最近阅读、全局书籍评分和显式反馈影响后续排序。
  • 冷启动可选主题、长度、难度与种子书；信号不足时明确显示低置信度。
  • 关闭行为个性化后只使用本次显式偏好；反馈可清空、单步撤销。

非目标

  • 不推荐书库外资源、购买链接、广告或付费排序。
  • 不使用其他成员的阅读状态或反馈，不建立敏感人格标签。
  • 不发送全文、完整阅读历史或任何书库文件给 Runtime。
  • 不让前端或业务层依赖 Codex 专有事件。

4. 数据与执行流

1. ACL 召回

用 get_books 获取当前可见藏书，排除无文件、已明确不喜欢和删除项。

2. 确定性评分

基于元数据重合、阅读状态、新近信号、显式选择和少量探索生成候选。

3. Runtime 重排

仅发送候选 ID、书名、作者、标签、简介摘要与聚合信号，要求结构化输出。

4. 二次校验

校验 schema、候选集合、理由依据、去重和实时 ACL；异常则确定性降级。

持久化

  • recommendation_preferences：用户开关与显式冷启动选项。
  • recommendation_feedback：独立的逐书反馈记录，可软撤销并清空。
  • recommendation_snapshots：短期结果、输入摘要哈希、模式和过期时间；不保存提示词或完整历史。

API

  • GET /api/ai/recommendations：读取缓存或生成；refresh=1 手动刷新，batch 换一批。
  • GET/PATCH /api/ai/recommendations/preferences：读取或更新显式选择和行为个性化开关。
  • POST /api/ai/recommendations/feedback 与 DELETE .../feedback/:id：写入与撤销；DELETE .../feedback 清空。

5. 排序、解释与隐私约束

  • 确定性分数可复算：主题/作者重合、种子相似、书籍评分、收藏/想读/阅读信号与稳定哈希探索；同分按稳定哈希与 ID 排序。
  • not_interested 直接排除该书；less_like 降低其作者/标签相似项；read 排除该书但保留其正向主题信号。
  • Runtime 理由必须引用输入中存在的作者、主题、种子或阅读信号；服务端拒绝未知依据、未知书 ID、重复项、超长文本和额外字段。
  • 生成前后均调用等价于 can_view_book 的权限逻辑；缓存命中仍实时复核，删除或权限变化立即剔除。
  • 未开启行为个性化时，候选和 prompt 不读取 ReadingState 或历史；仅用当前显式偏好和一般书籍元数据。

6. 风险与兼容性

权限或删除后的陈旧缓存

响应前逐书实时复核；不足数量时返回剩余安全项，不回填未校验内容。

Runtime 慢或不可用

复用现有探测、超时、取消与 schema 门禁；失败不阻断页面，以 deterministic 模式和非敏感原因提示。

信息茧房

稳定保留约 15% 探索位，并提供换一批、减少此类和显式主题控制。

历史产品缺少用户评分

现有 Calibre rating 仅作为书籍质量元数据；不误称为用户评分，后续若增加个人评分再扩展信号接口。

8. 决策记录

  1. 复用统一 AgentRuntime，不增加 OpenAI API/SDK；Claude Code 与 Trae 继续保持适配器边界。
  2. HTTP 使用独立推荐资源 API，不把推荐伪装成以单书章节为中心的 AITask。
  3. Codex 只重排候选和撰写理由；召回、权限、排除、缓存和最终验证全部由服务端掌控。
  4. 2026-08-17 产品反馈将主要入口由侧栏独立页改为首页模块，每批展示 10–12 本；高级页保留为首页低干扰设置入口，不再占用侧栏。
  5. 首页的隐蔽选项先提供“历史阅读”和“大家喜欢”：后者严格映射到书库评分，不读取其他成员行为；“你的笔记”在缺少通用笔记索引时只说明能力边界，不伪造信号。
