插件安全与数据保护收口

在最新主干上重新落实 TB-51 的三条安全不变量，同时适配已经完成的插件领域模型重构，不回退插件中心现有能力。

原始诉求目标边界根因方案风险测试决策

1. 原始诉求

“基于最新 master 重新实现或无损重放 TB-51 三项已复验修复：管理员不得执行、枚举或读取用户私有 Run；用户手工修改或删除来源批注后同步与 rollback 不得覆盖；BRS 等可配置 HTTP endpoint 拒绝本机、link-local、私网地址与私网重定向，并限制响应大小。”

旧提交 611e90dd 位于冲突的 Draft PR #1006，且不在当前主干历史中。之后主干重构了插件 handler、实体 writer 与 provider 目录，不能直接以旧文件形态合并。

2. 目标与边界

目标

  • 管理员运行入口只接收 instance-owned connection，列表和详情只暴露对应 Run。
  • Annotation API 的手工更新、删除同步标记物化来源记录；运行时在同步和回滚前再依据业务行兜底检测。
  • 任意用户可配 endpoint 只走 SafeHttpClient，且用户配置不能自助放行非公网地址。
  • 以当前架构补足定向测试，并完成 Docker 定向与全量回归。

非目标

  • 不引入 AI、Calibre Content Server、Calibre-Web 或 TB-46。
  • 不改变普通用户对本人连接与 Run 的访问能力。
  • 不迁移库表，不重做插件中心页面。
  • 不把旧提交整体 cherry-pick 后保留过时模块名。

3. 现状、根因与证据

观察当前证据结论
管理员越权webserver/handlers/plugins.py 的 action 只判断连接存在；runs 查询直接从 PluginRun 开始；detail 不核对连接所有者。管理员可触发并读取用户私有连接的运行数据。
本地修改保护失联Annotation PUT 只更新 user_modified_at，DELETE 直接删业务行；PluginSourceRecord.local_modified 未联动。运行时仅相信该布尔值。下次远程同步可覆盖本地编辑；回滚可误删业务行或把已手工删除的记录标成成功。
出网策略存在绕过BRS、动态 OPDS 与 WebDAV 已使用 SafeHttpClient，但 schema 暴露 allowed_hosts 并直接传给策略层。用户可把任意私网 endpoint 自行加入白名单，等价于绕过私网拒绝。

4. 方案

方案结论：把权限过滤放在管理员 API 的查询边界；把“业务行是否仍等于插件物化结果”作为 writer 契约；把 endpoint 私网例外限制在平台代码持有的固定可信主机，不接受连接 config 传入的白名单。
Admin API先限定 owner

action 校验 instance；list join connection；detail 不泄露用户 Run 是否存在。

Annotation API主动标脏

手工 PUT/DELETE 在同一事务把关联 source record 标为 local modified。

Runtime兜底检测

实体 writer 在 upsert 与 rollback 前检查业务行缺失、来源解绑或修改时间分叉。

Network逐跳验证

连接配置不再传私网白名单；每次请求和跳转校验公网地址并检查响应大小。

关键决策

决策选择理由不采用
本地修改检测归属扩展通用 EntityWriter.is_locally_modified() 钩子，AnnotationWriter 实现。保持运行时不认识具体实体，符合当前解耦架构。恢复旧提交中运行时对 weread 模块的函数内 import。
删除后的关联记录先标记 source record，再删除 Annotation；运行时看到业务行缺失仍判为本地修改。来源记录是保护用户删除意图的持久事实。级联删除 source record，导致后续同步重新创建。
私网白名单从用户连接 schema 与调用链移除；固定官方 host 的代码级白名单能力保留。满足可配置 endpoint 必须拒绝非公网目标，同时不破坏可信静态 provider 的 DNS 策略。继续信任用户传入 allowed_hosts。

5. 影响范围、风险与回滚

影响范围

仅后端 handler、实体 writer、Annotation API、BRS/OPDS/WebDAV 配置声明与定向测试；无库表迁移、无前端页面结构变化。

保持不变

普通用户 API、固定公网插件、run 状态机、已有数据结构与密钥存储方式不变。纯后端安全边界，不影响界面，因此豁免 interface-review。

主要风险：依赖私网 BRS/OPDS/WebDAV 的存量连接将被拒绝；这是安全收紧的预期兼容变化。回归测试需证明公网路径不受影响、私网重定向和大响应均失败。
回滚：全部为代码与 schema 声明改动，可按单 PR revert；无数据迁移或清理步骤。
