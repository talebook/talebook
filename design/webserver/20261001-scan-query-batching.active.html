扫描与导入性能、缓存和任务控制

按批读写、复用稳定文件的解析结果，以有界流水线处理自动导入。

状态：ACTIVE创建日期：2026-10-01所属模块：webserver / app需求来源：开发者直接会话 · PR #1065

1. 原始诉求与目标

优化大量书籍扫描与导入，把历史应用层优化中尚缺的缓存、批量事务、取消、事件合并、流水线和进度统计加入同一 PR。保留完整 SHA-256、手动扫描预览、权限和移动模式的源文件保护。同一 PR 只维护本方案，统一记录实现边界与验证结果。

2. 决策与边界审查

仓库要求的 grill 未在可用技能和 .agents/skills 中找到；已手动检查缓存失效、事务失败、线程隔离、取消恢复、文件事件丢失、内存与接口兼容性。使用仓库 interface-review 及六项领域技能完成 full 模式审查。

决策实现与边界
完整指纹完整 SHA-256，以 1 MiB 块读取；取消可在读块间检查。不使用抽样内容判重，不按整目录跳过新增文件。
元数据复用进程内 LRU 最多 128 项、估算 32 MiB。保留元数据及封面字节，返回独立副本；过大条目不缓存。文件设备号、inode、大小、mtime_ns、ctime_ns 全部匹配才复用。解析前后再校验指纹，扫描预览后改变的文件返回新发现状态，要求重新扫描。
跨重启哈希复用ScanFile.data 保存完整内容 hash 和文件签名，签名不匹配重新读盘。元数据不反序列化可执行对象，不持久化到数据库；重启或 LRU 淘汰后重新解析。大量手动扫描后再导入可能无法命中元数据缓存，不承诺所有文件只解析一次。
数据库候选路径最多 500 个一批查重，扫描与导入按 ID 游标分页；路径及任务状态索引在独立事务中创建，复用等效索引。统计用 GROUP BY。处理结果每 20 项提交，每文件独立 SAVEPOINT；SQLite 显式开始外层事务，避免 RELEASE SAVEPOINT 实际逐项提交。
跨库一致性Calibre 与应用库没有跨库原子事务。失败重试仍校验同名同作者及格式；移动模式先提交应用记录，再确认目标文件存在后删除源文件。失败保存点中的删除意图会丢弃；不触碰 Calibre 内部补丁。
自动流水线单个文件解析生产者，队列最多 8 项；消费者逐项扫描判重并入库，批次最多 20 项。仅传递路径与解析结果，ORM、书库操作和应用库写入均由同一消费者完成。退出或取消时结束生产者，收集结果并 join。
目录事件Linux 使用 inotify 的关闭写入及移动进入事件，按路径合并并防抖 1 秒；最多保留 4096 个路径。目录变化、溢出和监控丢失触发完整检查；不支持事件的平台按原间隔完整扫描。保留周期检查作为漏事件兜底。
取消与进度串行化扫描和导入消费者；GET /api/admin/import/task 从内存读取任务状态，DELETE 请求协作式停止。均要求管理员登录。文件边界取消，不强杀正在进行的 Calibre 操作。自动任务停止后需重新启用监控；界面说明已完成结果保留并支持再次扫描。

3. 流程与兼容性

手动流程：分批登记候选 → 完整哈希判重 → 格式校验、元数据与封面 → 扫描预览 → 管理员确认 → 批量导入。自动流程：初始/周期遍历或合并文件事件 → 有界文件解析队列 → 单线程数据库判重与入库 → 批次提交 → 复核原文件签名 → 移动源文件清理。

保留原扫描、导入与统计接口响应结构。新任务接口供导入页轮询，任务结束后保留完成或失败提示，并刷新记录列表与汇总，避免任务进行中重复查询汇总。元数据对象使用 Calibre 自身 deepcopy 方法，避免普通深拷贝不兼容。已有 Item 按 book_id 复用，防止重复关联失败阻塞移动清理。

索引创建可能占用启动时间及数据库空间；失败会记录并在下次启动重试。MySQL 验证到 DDL 编译，未做真实服务压力测试。已完成路径仍保持历史跳过规则，文件事件用于发现尚未完成的新增候选，不提供已入库内容变更同步。批次内崩溃最多回滚该批的应用库变更，书库已完成副作用依赖重试查重恢复。缓存与实时任务状态是单服务进程内状态，重启后从扫描记录恢复；不是分布式任务协调器。

4. 影响范围

全量测试发现同步扫描窗口用例在外部删除记录后保留了服务会话，造成旧 identity map 与 SQLite 重用 ID 冲突；用例显式关闭其拥有的服务会话，保持生产队列任务结束时的会话生命周期。最终边界检查：解析前后校验文件签名和完整指纹一致；发生替换时回滚该文件的应用库变更并保留失败原因。自动流水线遇到无效格式时先记录完整指纹与失败状态，避免该文件反复占用周期扫描额度。已入库的内容重复文件在手动扫描中先判重，跳过昂贵解析。

webserver/services/scan.py、scan_runtime.py、handlers/scan.py、models.py、migrate_db.py；app/pages/admin/imports.vue 与中英文词条；扫描/运行时测试、独立 Playwright 配置、性能基准脚本。产品规则更新 spec/书库.md。没有修改 Calibre 内部代码或数据库结构字段；文件签名使用已有 JSON 数据字段。移动模式延后清理前再次核对导入时的文件签名，批次期间源文件被替换时保留源文件并记录删除失败。
