人物同款思维 Agent

从书中任意角色或真实人物的证据中提炼思维模式、决策原则、解题步骤和盲区，创建一个帮助用户分析现实问题的私有思考伙伴。

状态：ACTIVE创建：2026-08-16修订：2026-08-17模块：webserver / app来源：TB-62

原始诉求与反馈修订

初版按“防剧透主角陪伴”实现。2026-08-17 用户明确纠偏：不要让防剧透、版权引用和角色范围成为额外限制；核心是帮助用户借用人物的思维方式解决问题，而且创建对象不限主角，必须支持系统推荐或用户自由输入。修订版据此移除截止章节、剧透确认、续写/仿写阻断、短引预算和引用反馈，保留私有 ACL、运行时脱敏与删除清理。

目标与边界

  • 创建时可选择“AI 推荐”或“自己指定”，目标人物可以是主角、配角、历史人物或非虚构作品中的真实人物。
  • manifest 聚焦思维模式、决策原则、解题步骤与思维盲区；对话先理解用户问题，再给出可执行的分析和下一步。
  • 书籍证据只在创建思维模型时进入运行时；聊天只使用抽象 manifest 与会话历史，不反复注入整本正文。
  • manifest、会话、消息、反馈均按创建者私有；每次读写重新检查书籍权限和版本。
  • 不做公共分享或对外知识库；不承诺人物思维模型绝对准确，也不把单一人物视角包装成唯一答案。

方案

1. 选择用户选择 AI 推荐或自由输入任意人物。
2. 提炼服务端解析 EPUB，异步生成版本化思维 manifest。
3. 预览展示思维模式、决策原则、解题步骤、盲区与证据范围。
4. 解题聊天只带 manifest 与历史，用人物视角拆解用户的现实问题。
5. 清理删除、撤权或书籍版本变化时拒绝访问并清理派生数据。

数据模型

实体保留内容隐私/生命周期

HTTP 契约

/api/ai/protagonist/previews 创建/轮询预览；/api/ai/protagonist/agents 确认、列表、改边界和删除；/api/ai/protagonist/conversations 创建/读取会话；消息子资源提供生成、取消、重试和反馈。所有接口使用 @js + @auth，终态为 succeeded / failed / cancelled。

约束策略

  • 移除续写/仿写意图拦截、剧透边界、短引预算和逐字引用验证，避免限制用户如何使用人物视角。
  • 保留创建输入长度、结构化 schema 与运行时终态，防止协议错误破坏产品状态。
  • 创建提示把正文标成不可信数据且不给工具；聊天阶段不携带书籍正文，只携带抽象 manifest。
  • 运行时异常、超时、取消和协议错误只落安全错误码与脱敏消息。

影响与风险

风险控制剩余风险
越权访问检索前 ACL、每次访问复核、书籍版本校验管理员主动撤权时依赖下一次请求触发拒绝
人物思维失真展示证据范围和盲区，提供“不像他的思路”反馈模型提炼仍是主观解释，不承诺完全复刻
建议不可用提示要求具体下一步和适用性反思，提供“不够实用/太空泛”反馈用户仍需自行判断建议是否适合真实情境
并发/取消消息级 UUID、幂等终态、AgentRuntime.cancel进程被强杀时依赖超时和下次访问恢复失败态
