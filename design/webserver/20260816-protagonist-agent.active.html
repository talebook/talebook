防剧透的“主角同款 Agent”

从读者已获授权且不晚于阅读截止位置的正文中提炼抽象人格证据，创建私有、可撤销、持续标注 AI 衍生的阅读陪伴 Agent。

状态：ACTIVE创建：2026-08-16模块：webserver / app来源：TB-62

原始诉求

实现候选或手输主角、预览确认、多轮对话、停止/重试/重生成、边界升降、短引、反馈与删除；服务端强制 ACL 和防剧透边界，禁止原作续写、大段复述、作者风格模仿和身份冒充。统一使用 AgentRuntime 与 Codex app-server，不使用 OpenAI API/SDK。

目标与边界

  • 所有证据由服务端从 EPUB spine 读取，并在进入运行时前按截止 href 裁剪；客户端不能提交正文作为知识源。
  • manifest、会话、消息、反馈均按创建者私有；每次读写重新检查书籍权限和版本。
  • manifest 只保留抽象特征、原则、关系/表达边界和最小来源 locator，不保存整段正文。
  • 输出必须通过 schema、截止 href、短引、长段近似原文和续写/仿写意图校验；失败即安全拒绝。
  • 非目标：公共分享、通用角色卡、作者仿写、原作续写、对外知识库或完全复刻角色。

方案

1. 提取服务端解析 EPUB container/OPF/spine，仅保留截止前的限长文本。
2. 预览异步运行时生成版本化 manifest，严格校验抽象字段和来源。
3. 确认复制校验后的 manifest 为创建者私有 Agent，并记录当前截止位置。
4. 对话新会话快照边界；消息异步生成并支持取消、重试和反馈。
5. 清理删除、撤权、书籍版本变化均拒绝访问；删书级联清除派生数据。

数据模型

实体保留内容隐私/生命周期
ProtagonistAgent书籍版本、manifest、当前 cutoff、schema/prompt 版本创建者私有；删除时级联会话与反馈

HTTP 契约

/api/ai/protagonist/previews 创建/轮询预览；/api/ai/protagonist/agents 确认、列表、改边界和删除；/api/ai/protagonist/conversations 创建/读取会话；消息子资源提供生成、取消、重试和反馈。所有接口使用 @js + @auth，终态为 succeeded / failed / cancelled。

安全策略

  • 输入层拒绝大段复述、续写和作者风格模仿；提示层明确“AI 衍生、非角色本人”，把正文标成不可信数据且不给工具。
  • 输出引用逐字匹配截止内正文，每条不超过 120 字、合计不超过 240 字；检测超过阈值的连续原文复现。
  • 提高边界要求显式 spoiler_confirmed；降低后旧会话保留只读快照，新会话立即采用更严格边界。
  • 运行时异常、超时、取消、协议、schema 和引用错误只落安全错误码与脱敏消息。

影响与风险

风险控制剩余风险
剧透或越权检索前 ACL + spine 截断 + 每次访问复核 + 红队测试模型可能从训练记忆联想；输出要求仅基于证据并可转安全概述
版权复现短引预算、连续匹配检测、拒绝续写/仿写非连续改写难以机械判定，保留反馈与拒绝优先策略
角色失真展示抽象特征和来源范围、提供“不像角色”反馈首版不承诺完全复刻
并发/取消消息级 UUID、幂等终态、AgentRuntime.cancel进程被强杀时依赖超时和下次访问恢复失败态
