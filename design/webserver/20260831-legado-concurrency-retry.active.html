Legado 并发与失败重试优化

让管理员在 Legado 书源工作台控制结果上限、搜索并发、保存并发与私网地址保护，并把分章保存改为有界并发、失败判定和排队重试。

状态：ACTIVE创建日期：2026-08-31所属模块：webserver影响范围：webserver、app、tests需求来源：TB-196
原始诉求目标边界现状根因方案风险回滚测试决策

1. 原始诉求

“Legado 插件全局配置增加：每个书源搜索结果数（默认 5）、搜索并发数（默认 20）、保存书籍并发数（默认 10）、是否开启防内网穿透检测；关闭时不拦截 ‘Endpoint resolves to a non-public address’。保存书籍到本地时进行错误判断和排队重试。”

2. 目标与边界

目标

  • 四项配置由管理员在 Legado 工作台读取、校验、保存，旧安装缺项时使用需求默认值。
  • 网络搜索与元数据搜索按单书源裁剪结果；网络搜索线程池按全局并发配置运行。
  • 分章下载保持章节原序，以有界线程池并发；异常、缺失或空正文进入下一轮重试队列。
  • 私网保护默认开启；关闭仅跳过非公网 IP 拒绝，仍校验协议、URL 凭据、跨域重定向和响应大小。

非目标

  • 不允许单个导入书源自行关闭安全策略，开关只属于管理员实例连接。
  • 不改变保存任务 API、后台任务定位键、TXT/EPUB 导入和去重契约。
  • 不新增数据库字段或迁移；配置继续存入现有 PluginConnection.config。
  • 不承诺所有章节最终成功；重试耗尽时保留其他成功章节，全部失败则终止导入。

3. 现状、根因与证据

观察证据结论
配置不可调webserver/plugins/source/legado.py 的 config_schema 为空；工作台只有书源 CRUD。需求中的四项没有插件级持久入口。
搜索并发配置不能热切换SearchTaskService.configure() 只改数字，已经创建的 executor 不会重建。即使保存配置，进程首次搜索后也可能继续使用旧并发。
保存串行且吞错assemble_from_chapters() 顺序请求；任一异常直接写空正文且不重试。长篇保存慢，瞬时错误造成不可恢复的缺章；全部失败仍可能导入空书。
私网拦截无实例开关SafeHttpClient 每跳固定调用公网地址校验。代理把目标解析为私网 IP 时无法按管理员意图放行。

4. 方案

方案结论：配置所有权放在 Legado 的 instance connection；运行时从同一连接读取并发、裁剪与安全开关。保存阶段先并发抓取，失败项按轮次重新入队，成功正文最后按目录顺序组装。
准备解析详情与目录，生成不持有 SQLAlchemy session 的章节 reader。
首轮并发最多按保存并发数请求，每项校验结构与非空正文。
排队重试仅失败项进入下一轮，最多追加两轮，并记录最终失败。
顺序组装按目录索引写文件；部分成功可导入，全部失败明确报错。

配置契约

键类型 / 默认消费位置边界
search_result_limitinteger / 5Legado 网络搜索与元数据单源结果1–100
search_concurrencyinteger / 20网络搜索共享线程池；元数据查询 worker1–100

private_network_protectionboolean / trueLegado SafeHttpClient仅关闭 ip.is_global 拒绝

安全边界

该开关是对 design/webserver/20260831-plugin-security-closure.active.html 默认安全策略的显式、管理员级例外。它不会进入导入的 Legado JSON，也不接受书源 URL 自助 allowlist。关闭后仍解析 DNS、拒绝非法 IP、非 HTTP(S)、URL 内凭据、跨 origin 重定向、重定向过多和响应过大。

5. 影响范围、风险与回滚

影响范围

插件 manifest/config 校验、网络搜索 executor、Legado HTTP 客户端、元数据结果裁剪、保存抓取与工作台配置区；无数据迁移。

保持不变

默认仍阻止非公网地址；章节输出顺序、保存 API 和进度结构不变；重试耗尽后的单章仍按历史兼容写标题与空正文。

主要风险：管理员关闭保护后，恶意或失陷书源可访问本机及内网 HTTP 服务。界面必须直接说明风险，默认开启，后端只允许管理员实例连接保存此值。并发提高也可能触发网站限流，因此设置范围受控且可回调。
回滚：可整体 revert 代码；现有连接中的新增 config 键在旧版本中会被忽略，无数据库清理。若只需紧急止损，可把保护重新开启并把并发降为 1。

7. 决策记录

  1. 2026-08-31：在没有 grill 工具的运行环境中按原始需求明确边界：失败重试采用总计三次的分轮队列；部分失败保持兼容，全部失败终止。
  2. 2026-08-31：安全开关只控制非公网地址拒绝，不关闭其余 URL、重定向与大小防护；这是满足代理劫持场景的最小放宽。
  3. 2026-08-31：配置继续复用插件 instance connection，不复制到全局 settings 或书源 JSON。
  4. 2026-09-01：完整界面审查发现移动端 persistent hint 会压到下一字段，且 Vuetify warning tonal 的橙色正文对比不足；改为字段外自然流提示，并仅把 warning 内容与图标切到 on-surface 色，保留 warning 背景。复验后结论为 Approve。
