TaleAgent：人物思维伙伴

从书中任意角色或真实人物的有限证据提炼思维模式、决策原则、解题步骤和盲区，创建帮助读者分析现实问题的私有 Agent。

状态：ACTIVE创建日期：2026-08-16最近修订：2026-09-01所属模块：webserver / app需求来源：TB-62 / TB-52

1. 原始诉求与统一迭代

初始诉求是创建具备作品主角抽象思维方式的私有交互 Agent。成员随后明确：产品不应只限主角，也不要用防剧透、版权引用和仿写拦截限制用户；核心是让用户借用人物思维解决自己的问题。创建对象必须支持 AI 推荐和自由输入。

同一未合并工作继续收到三轮约束：产品和代码统一命名为 TaleAgent；删除独立消息表，由单条 TaleAgentConversation.messages JSON 保存完整会话；目录产物使用不超过 80 行的标准 AGENTS.md，复杂内容拆到 references/ 多文档。本文是 TB-62 唯一方案，直接吸收这些反馈，不保留同一工作的过程方案。

2. 目标与边界

目标非目标
  • 从 EPUB 全书证据中推荐人物，或由用户指定主角、配角、历史人物及书中讨论的真实人物。
  • 创建前预览介绍、思维模式、决策原则、解题步骤、盲区和来源；聊天给出具体下一步和适用性反思。
  • Agent、会话和反馈默认创建者私有；每次访问重新校验创建者、书籍权限和书籍版本。
  • 统一使用 AgentRuntime 与 Codex app-server，保留取消、超时、结构校验和脱敏错误。
  • 目录是 Agent 内容权威来源；数据库只保存索引、相对路径、摘要和状态。
  • 不做公共分享、角色本人声明、通用角色卡或对外知识库。
  • 不保存 EPUB 正文、运行时 prompt 或完整进程输出到 Agent 目录和日志。
  • 不保留旧 Protagonist API、独立消息表、manifest.json、版本目录或回滚接口；当前 PR 尚未生产落地。
  • 不承诺思维提炼绝对准确，也不把单一人物视角包装成唯一答案。

3. 产品与交互流程

1. 选择AI 推荐，或自由输入任意人物。
2. 提炼服务端解析 EPUB 并异步生成结构化思维模型。
3. 预览展示模型、盲区、来源与 AI 衍生声明。
4. 解题多轮聊天使用抽象模型和会话历史分析现实问题。
5. 管理停止、重试、反馈、重建模型和级联删除。

界面状态

  • 书籍详情页只对已登录且具有 EPUB 的书籍展示 TaleAgent 入口；窄屏时入口收为带可访问名称的图标按钮，避免增加工具栏溢出。
  • 创建页覆盖加载、失败、自选人物校验、生成中停止、成功预览、重新生成和确认创建。
  • 聊天页覆盖空态、生成进度、停止、失败重试、反馈和删除确认；发送失败时保留用户草稿，避免输入丢失。
  • 亮色主题使用深赭色强调文字，暗色主题改用浅赭色；白字气泡继续使用深色填充，分别满足文本对比。

4. 数据、API 与运行时

数据模型

TaleAgent
  id / creator_id / book_id / book_version / display_name
  manifest_path / manifest_sha256 / artifact_status / cutoff index

TaleAgentConversation
  id / tale_agent_id / creator_id / cutoff index
  messages = { "items": [
    { "id", "user_content", "assistant_content", "status",
      "feedback", "runtime", "usage", "error", "timestamps" }
  ] }

深层消息更新复制并重新赋值完整 JSON，确保 ORM 检测变化。同一会话只允许一个 queued/running 消息，避免整包并发覆盖。取消、重试和反馈仍通过逻辑消息 UUID 定位 JSON 项。

HTTP 契约

/api/ai/tale-agent/previews 创建和轮询预览；/agents 确认、列表、重建模型和删除；/conversations 创建、读取和删除会话；消息子资源负责生成、NDJSON 流、取消、重试和反馈。JSON 接口使用 @js + @auth；流接口同样由 @js 处理未登录 JSON，再在登录后写 NDJSON。

重建模型时，身份校验比较新预览产物中的 display_name 与现有 Agent，而不是比较用户原始输入；因此 AI 推荐模式的空名称可以正常重建，同时阻止借重建入口切换人物。

5. 目录权威 Agent 产物

books/ai/{workspace}/agents/
  {agent-id}/
    AGENTS.md                 # 标准入口，≤ 80 行
    references/
      profile.md              # 名称与介绍
      thinking.md             # 思维、原则、步骤与盲点
      sources.md              # 证据来源
  previews/{task-id}/
    AGENTS.md
    references/
      profile.md
      thinking.md
      sources.md
  • workspace 由内部 reader id 确定性派生，不暴露邮箱、用户名或连续 id；“不透明”只描述目录名，Markdown 内容保持可读。
  • AGENTS.md 列出必须读取的 references 文档和简短工作方法；写入与测试硬限制不超过 80 行。
  • 摘要覆盖入口与全部受控 references；缺失、多出、篡改、路径越界或跨 workspace 均失败关闭。
  • 新目录在同级临时目录写入并 fsync；只有旧目录已成功移到备份后，回滚才允许删除新目录并恢复备份。准备阶段失败不得删除仍在线的旧目录。
  • 删除预览、Agent 或书籍同步清理整个受控目录；数据库不保存 manifest 正文。

6. 风险与控制

风险控制剩余风险
越权或撤权后访问检索前 ACL、每次访问复核、书籍版本校验、创建者 workspace 限制。撤权后的清理由下一次请求或书籍删除触发。
人物思维失真显示 AI 衍生、来源与盲区，提供“不像他的思路”反馈。模型仍是主观提炼，用户需判断适用性。
会话 JSON 增长或覆盖单会话串行生成、输入输出长度限制、完整 JSON 重赋值。达到容量阈值后需另行设计归档。
文件与数据库不一致目录原子替换、全目录 SHA、数据库失败恢复、读取失败关闭。进程在文件切换与数据库提交间被强杀时会留下可检测的不一致。
移动端入口拥挤新增入口在 960px 以下缩为 40px 图标按钮，并保留明确可访问名称。书籍详情既有工具栏仍需在整体重构中统一收纳。
