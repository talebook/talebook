把自托管目录、合法开放内容与文件目录统一接入 plugin connection/run，同时让“发现、审阅、取得”保持清晰边界。

1. 原始诉求

增加 Kavita、Komga、BookLore 预设，接入 Project Gutenberg、Standard Ebooks、Internet Archive、WebDAV 与本地 Watch Folder；取得前显示格式、来源、许可和目标书库，复用 preview/run/retry/rollback，并通过 SSRF、路径白名单、去重、权限和合规测试。明确排除 Calibre Content Server 与 Calibre-Web。评审反馈要求把 Settings 中既有的 Talebook OPDS 服务开关迁移到插件窗口。

2. 目标与边界

本次交付

  • 真实 manifest 区分 browse、search、acquire。
  • 各适配器把候选书籍规范化为 book_source item。
  • preview 只展示；run 只写入可回滚的待审来源记录。
  • 运行详情展示格式、来源、访问/许可与目标书库。

明确不做

  • 不自动复制整个远端或本地目录。
  • 不绕过 DRM、借阅、登录或付费限制。
  • 不把只有网页详情链接的条目标记为可下载。
  • 不接入 Calibre Content Server 或 Calibre-Web。

3. 能力目录

来源browsesearchacquire实现
Kavita / Komga / BookLore是是是带认证的 OPDS 1/2 连接预设；endpoint 必须通过安全策略。

WebDAV是否是PROPFIND 深度 1、扩展名过滤、ETag/游标增量发现。
Watch Folder是否是受白名单约束的本地扫描、mtime/size 游标与 SHA-256 内容 hash。

4. 统一流程

连接endpoint/path、认证、格式与目标书库
测试安全校验并探测协议
预览列候选、合规条件和重复原因
待审run 写来源记录，不复制文件
治理失败项重试、来源追踪和回滚

Provider 的 test 不返回候选；preview 返回候选但不写来源；run 仅把候选保存为 review_status=pending。取得动作必须由后续显式确认触发，因此当前阶段不会隐式下载。

5. SSRF 与路径安全

  • HTTP(S) endpoint 解析后拒绝环回、私网、链路本地、保留、多播与未指定地址；自托管来源只有主机命中显式 allowlist 才允许私网地址。
  • 每次重定向重新解析和校验，限制跳转次数；禁止凭据进入 URL 或公开 config。
  • WebDAV 复用同一安全客户端；相对链接先归一到已验证 origin。
  • Watch Folder 的真实路径必须位于平台 import_allowed_roots 或 scan_upload_path 下；拒绝 ..、越界绝对路径和经 symlink 逃逸。

6. 格式、增量与去重

允许格式集中维护为 EPUB、PDF、MOBI、AZW/AZW3、TXT、FB2、CBZ/CBR。远端使用稳定 ID 与更新时间/ETag 推进游标；Watch Folder 使用路径、mtime_ns、size 做增量候选，读取候选后计算 SHA-256。

preview 与 run 都以“规范 ISBN + 格式”或“内容 hash + 格式”查询已有 active 来源记录，并在同批次内去重。重复项以 status=skipped、operation=duplicate 展示且不写新来源记录。

7. 界面影响

插件管理页沿用现有安装、连接、测试和运行记录。运行详情表新增格式、来源、访问条件、许可、目标书库列；窄屏允许表格横向滚动，字段缺失显示短横线。连接表单按 manifest schema 渲染公开配置与 write-only 凭据，避免为各预设复制表单。

Generic OPDS 详情中新增“Talebook OPDS 服务”开关，直接读写既有 OPDS_ENABLED，保留升级前的配置值；外部 OPDS 目录导入与本机 OPDS 发布服务保持独立开关。Settings 删除旧 OPDS 卡片和导航项，避免同一配置出现两个入口。

本轮迁移已验证：插件 API 保留并持久化既有 OPDS_ENABLED，拒绝非布尔值；Settings 旧入口已移除；插件详情开关通过桌面/320px Chromium 渲染、键盘 Space 操作与无横向溢出检查。完整界面复审修正保存期间重复触发和迁移实现文案后结论为 Approve。

剩余风险

公共服务的远端 schema 可能变化；适配器解析器会对缺失字段降级为不可取得，并用结构化失败暴露不兼容。Internet Archive 的借阅状态复杂，本阶段采用保守策略：没有明确开放文件即只展示外链。当前 run 只建立可回滚的待审来源记录，不执行最终下载；未来显式取得步骤仍须复用逐跳 endpoint 校验。
