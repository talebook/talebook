元数据、评价与章评连接器

在现有插件运行时之上增加可追溯的数据适配层，用统一预览契约保护人工元数据，并让评分、章评与文件导入保持来源边界。

状态：ACTIVE创建日期：2026-08-17所属模块：webserver需求来源：TB-47

1. 原始诉求

“实现 Open Library、嵌入文件元数据、Calibre Provider Bridge、Hardcover/NeoDB 等评分、talebook-brs、多种评价文件与漫画领域评价；只补空或生成候选，锁定字段不被覆盖，评分保持原始尺度，章评与私密 annotation 分域。”

2. 目标与边界

目标

  • 连接器共用 test、preview、run、retry、rollback 和来源记录。
  • 元数据逐字段输出当前值、候选值、锁定状态与决策。
  • 评分保留来源、原尺度、样本数、来源时间和原链接。
  • BRS 多连接实例独立保存 endpoint/token 与游标。

非目标

  • 不跨来源计算综合评分。
  • 不批量保存外部评论全文，只保存短摘要和链接。
  • 不把外部章评写入个人 Annotation 表。
  • 不在 Provider 内直接覆盖 Calibre 人工字段。

3. 方案

输入

连接配置声明查询书籍、字段锁、文件内容或 BRS 映射。

适配

来源解析器转换为稳定 metadata/review 数据契约。

治理

运行时脱敏、重试、幂等 upsert、游标与回滚。

呈现

运行详情显示逐字段差异或来源评分，不暴露 token。

字段决策

条件决策行为
字段被人工锁定locked只展示候选，绝不自动应用。
当前值为空fill_empty标记为可补空候选。
当前值与来源相同unchanged不生成写入。
当前值非空且不同candidate等待人工选择，不静默覆盖。

来源契约

领域来源持久化边界
元数据Open Library、EPUB、Calibre Provider Bridgeentity_type=metadata，保存字段决策和合法来源链接。
评价Hardcover、NeoDB、Google/Open Library、Goodreads、StoryGraph、Bangumi、AniListentity_type=review，每个 connection/source 独立，不平均。
章评talebook-brsentity_type=review 且 review_kind=chapter_comment；禁止 Annotation 写入。

4. 影响范围、风险与回滚

  • 新增内置 Provider 与纯解析器，不新增数据库表；复用现有 source record 和 run 状态机。
  • Provider 网络响应差异通过结构化逐项错误保留，不因单条坏数据推进失败游标。
  • 文件正文不写 run item；评论只保留受限摘要。回滚把本 run 的 source record 标记为 rolled_back，并保护 local_modified。
  • 前端只扩展运行详情的安全预览列；窄屏使用可换行 definition list。
