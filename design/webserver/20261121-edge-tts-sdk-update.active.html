恢复 Edge 逐章语音生成

创建日期 2026-11-21 · 模块 webserver · 状态 ACTIVE · 来源 GitHub #1103

原始诉求

逐章生成有声书音频时返回 HTTP 403，UI 显示 clock_skew_adjustment。

目标与方案

将 Voicebook 固定到已验证的上游提交。该提交使用 Edge SDK 7.3.1。共享请求预算、重试和有声书 API 沿用原有行为，规格无需修改。

测试结果

从 GitHub 提交归档安装确认 Voicebook 0.8.0 使用 Edge SDK 7.3.1。真实 Edge 请求在 7.2.8 返回 403，7.3.1 生成 9,504 字节音频。Voicebook 的共享预算回归 14 项、Talebook 的 tests/test_audiobook_progress_v2.py 29 项通过。Windows 回归使用 UTF-8、短临时路径和独立 FFmpeg、FFprobe。
