私人图书馆重新启用时更新邀请凭证

创建日期 2026-11-21 · 模块 webserver · 状态 ACTIVE · 来源 GitHub #1085

原始诉求

管理员把图书馆从公开恢复为私人后，原浏览器和外部阅读器仍可能继续访问。

目标与边界

后台重新启用门禁或更换启用中的访问码时，之前签发的邀请凭证失效。没有更改的门禁继续接受七天内的凭证，已有部署的旧凭证在第一次变更前兼容。有效 OPDS 账号仍按既有认证规则处理。

方案

为邀请凭证增加配置版本。用现有设置保存流程持久化版本，仅在成功保存后生效。凭证签名和七天有效期沿用现有实现。失败的保存保留当前版本。影响规格：用户。

测试结果

修复前两个凭证撤销场景失败。修复后 tests/test_settings_persistence.py 全部 11 项通过。测试在 Windows 中替换了 Linux 专用的 fcntl 和 fchmod，覆盖真实设置持久化和凭证校验。Readest 实机未执行。
