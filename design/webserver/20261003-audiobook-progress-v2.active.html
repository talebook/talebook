有声书真实制作进度接入

TB-234 · 创建日期 2026-10-03 · 模块 webserver / app · 状态 ACTIVE

原始诉求

将 Voicebook 单本并发和真实进度接入 Talebook，保留快捷与高级模式，避免长时间等待无解释。依据 Mika 指定的 Voicebook f3109d00d191066d887b3a76c19d60460bc5b253 的 v2 契约；本任务只交付接入，战队后续全链路验收。

目标与边界

展示实际标题/正文语音片段完成量、阶段、活动请求、失败/重试、限速排队/冷却、下次请求时间和更新时间。片段比例不表示整书耗时。Talebook 完成结果校验及数据库提交后才标记任务完成。

设计决策已由任务和 v2 契约确定：使用现有 JSON 数据字段持久化，登记每次调用的独立尝试 ID，拒绝错误身份及旧序号；旧 CLI 版本使用原参数并提示详细进度不可用。无需新增数据库迁移、供应商调用或生产部署。

方案

登记调用

稳定 task_id、新 attempt_id、清空旧计数和错误。

接收 JSONL

校验 schema / 身份 / seq，覆盖绝对快照；持久化。

API 与页面

刷新恢复，真实计数，等待原因与请求倒计时，区分连接异常。

发布

退出成功后校验 manifest / 音频 / 时间轴，再提交数据库并完成。

默认 Edge 连接上限 1、请求间隔 5 秒；每次 generate 显式传相同预算参数和绝对 SQLite 路径，默认 AUDIOBOOK_PATH/rate-limits/edge-budget.sqlite3，不放入会被清理的 cache。Qwen 默认单本并发 2；可配置 1–32。不同 worker 参数由 Voicebook 共享文件拒绝；多主机仍需集中调度。

影响范围与风险

requirements.txt、webserver/settings.py、webserver/services/audiobook.py、任务 API、app/components/AudioJobsPage.vue 与两种语言文案、测试、spec/有声书.md、使用说明。保留旧章级计划作为辅助信息，v2 快照是全书真实计数来源。协议中断不推断成功，取消期间仍等待进程回收。SQLite 要求同机本地共享挂载，跨主机和真实供应商限制不由本接入保证。
