# 外部访问

## 1. 定义

外部访问是**不经过 Talebook 网页界面读取藏书的全部通道**。读者可以用官方客户端、任意 OPDS 阅读器、或者支持 WebDAV 的阅读 App 直接连上自己的实例。

三条通道方向一致：**把本站的藏书暴露给外部客户端**。这正是它们与书源类插件的分界——后者是从外部往站内取书。

**不是什么：**

- **不是从外部取书。** OPDS 源、WebDAV 源这类「从别人那里发现书」的能力属于 [外部书库源](插件/外部书库源.md)，虽然协议同名，方向相反。
- **不是网页阅读器。** 站内在线阅读属于 [阅读器](阅读器.md)。
- **不是播客。** 有声书的对外订阅通道属于 [有声书](有声书.md)。
- **不是 API 开放平台。** Talebook 没有对第三方开发者承诺稳定的通用 API。

## 2. 使用场景

- **读者想在手机上读**，不愿一直开着浏览器。
- **读者已经习惯某个 OPDS 阅读器**，希望把自己的书库加进去。
- **读者用静读天下**，希望阅读进度能在设备之间同步。
- **读者不知道自己的实例地址怎么填**，需要一个能照着抄的说明页。
- **管理员不想对外暴露目录服务**，希望能关掉。

## 3. 功能

- 提供官方跨平台客户端的下载入口与连接说明。
- 对外提供 OPDS 目录服务，支持导航、分类、搜索。
- 对外提供 WebDAV 挂载，可选每用户可写同步目录。
- 集中展示三种方式的访问地址与配置指引。
- 管理员可分别关闭 OPDS 与 WebDAV 服务。

## 4. 术语与界面用词

### 术语表

| 标准用词 | 英文 | 含义 | 示例 |
|---|---|---|---|
| 外部访问 | external access | 不经过网页界面读取藏书的通道 | 在手机 App 里填上实例地址，直接翻自己的书库 |
| Moke | Moke | Talebook 官方跨平台阅读客户端，直连实例 | 下载 Moke，填入站点地址与账号即可阅读 |
| OPDS 目录服务 | OPDS service | 本站对外发布的书目订阅目录 | 在阅读器里添加一个 OPDS 源，指向本站的目录地址 |

| 同步目录 | sync folder | WebDAV 下每位用户可写的私有目录 | 阅读 App 把进度文件写进这个目录实现跨设备同步 |

## 5. 行为逻辑

### 5.1 三条通道的差异

| 通道 | 读者看到的 | 服务开关位置 | 可写 |
|---|---|---|---|
| Moke 官方客户端 | 完整的阅读体验 | 无独立开关，走常规接口 | 否 |
| OPDS 目录服务 | 可订阅的书目目录 | **插件中心的 OPDS 卡片** | 否 |
| WebDAV 挂载 | 文件式的书库 | **系统设置** | 可选 |

**两个协议的开关位置不同，这是必须知道的一处不对称。** OPDS 的服务开关长在 OPDS 插件的卡片上，因为同一个插件同时管两个方向；WebDAV 服务端与插件毫无关系，它的开关是一个普通的管理员设置项。停用 WebDAV 源插件**不会**关闭 WebDAV 挂载。

### 5.2 权限不打折

三条通道都**必须执行与网页界面相同的可见性判定**。具体地：

- 私藏书对无权读者不可见，见 [书籍](书籍.md)。
- 游客能做什么仍由站点的访客开关决定。
- 认证凭据**只在本协议内有效**，不能当作通用会话使用。
- 日志必须脱敏。

这三条是所有非网页通道的共同底线。协议可以使用标准 HTTP 状态码而不是本站的 JSON 错误信封，但**不能绕过权限**。

### 5.3 OPDS 目录服务

对外发布导航、分类、分类分组与搜索四类目录。服务关闭时对外不可用，但站点内部的 OPDS 导入能力不受影响——那是另一个方向。

展示范围与规模由一组配置控制：允许与排除哪些分类、单页条目上限、标签展示上限、未分组条目上限，以及可选的地址前缀（用于反向代理挂在子路径下）。

这些上限存在的原因是 OPDS 客户端通常一次性拉取整个目录，不设上限会在大书库上超时。

### 5.4 WebDAV 挂载

以文件系统语义暴露藏书，主要兼容静读天下一类的同步型阅读 App。服务开关在请求时检查，关闭后立即拒绝。

可选的**每用户同步目录**提供一个可写空间，让阅读 App 把进度、书签之类的文件写进去实现跨设备同步。默认**关闭**，目录名可配置。这是整个外部访问里唯一允许写入的地方，因此它按用户隔离。

### 5.5 官方客户端

Moke 是 Talebook 的官方跨平台阅读客户端，直接连接实例，走常规接口，**后端没有为它准备任何专用代码**。它在外部访问页提供下载入口与连接说明。

### 5.6 说明页

三种方式集中在一个说明页上，展示各自的访问地址与配置指引。地址需要按站点的实际对外地址生成——站点部署在反向代理之后时，对外地址取自代理转发的头部，而不是内部监听地址。

## 7. 实现对照

### 7.1 数据存储

| 概念 | 存储 | 说明 |
|---|---|---|
| 藏书内容 | Calibre 书库 | 三条通道共用同一份数据 |
| WebDAV 同步目录 | 文件系统 | 按用户隔离的可写目录 |
| 服务开关 | 站点配置 | 运行时写入 `auto.py` |

### 7.2 API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/opds/` | OPDS 目录根 |
| GET | `/opds/nav/<id>` | 导航 |
| GET | `/opds/category/<type>/<name>`、`/opds/categorygroup/<type>/<name>` | 分类与分类分组 |
| GET | `/opds/search/<query>` | 目录内搜索 |
| — | `/books/<path>` | WebDAV 挂载点，支持标准 WebDAV 方法 |
| POST | `/api/admin/plugins/opds-service` | 切换 OPDS 对外服务开关 |
| GET | `/api/welcome` | 返回 `opds_enabled`、`webdav_enabled` 供前端展示 |

### 7.3 关键定义

| 符号 | 值 | 含义 |
|---|---|---|
| `OPDS_ENABLED` | `True` | OPDS 对外服务开关，**由插件卡片切换** |
| `ENABLE_WEBDAV_SERVICE` | `True` | WebDAV 对外服务开关，**普通管理员设置项** |
| `WEBDAV_SYNC_FOLDER` | `False` | 每用户可写同步目录开关 |
| `WEBDAV_SYNC_FOLDER_NAME` | `reader` | 同步目录名 |
| `opds_will_display` / `opds_wont_display` | `["*"]` / `[]` | 分类展示白名单与黑名单 |
| `opds_max_items` | `50` | 单页条目上限 |
| `opds_max_tags_shown` | `10240` | 标签展示上限 |
| `opds_max_ungrouped_items` | `100` | 未分组条目上限 |
| `opds_url_prefix` | `""` | 反向代理子路径前缀 |
| Moke 发布地址 | `github.com/talebook/moke/releases` | 官方客户端下载 |

### 7.4 代码落点

| 行为 | 文件与函数 |
|---|---|
| OPDS 目录服务 | `webserver/handlers/opds.py`，开关检查在 `OPDS_ENABLED` |
| WebDAV 服务 | `webserver/webdav/handler.py`，开关在请求时检查；资源模型见 `webserver/webdav/dav_provider.py` |
| 路由注册顺序 | `webserver/handlers/__init__.py`：`webdav.routes()` **必须早于** `files.routes()`，否则静态兜底会拦截 `/books/*` |
| 对外地址推导 | `BaseHandler.set_hosts()`，信任反向代理转发头 |
| 说明页 | `app/pages/library/apps.vue` |
