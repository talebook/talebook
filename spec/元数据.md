# 元数据

## 1. 定义

元数据是一本书的**描述信息**——用来回答「这是什么书」的全部字段：书名、作者、出版社、标签、丛书、评分、ISBN、语言、出版日期、简介和封面。它是读者检索、浏览和判断一本书的唯一依据，也是书库能按维度聚合的基础。

元数据归 Calibre 书库管辖，Talebook 只在其之上补充**别名索引**，用于让同一实体的不同写法能被聚合。

**不是什么：**

- **不是书的文件本身。** 文件格式的上传、下载、转换、抽出属于 [书籍](书籍.md)，元数据只关心「按文件格式浏览」这一个维度。
- **不是获取元数据的来源。** 从豆瓣、百科等外部服务检索书籍信息的能力属于 [元数据源](插件/元数据源.md)；本篇只定义拿回来的信息如何落地。
- **不是内容形态分类。** 一本书是电子书还是漫画由媒体分类决定，属于 [书籍](书籍.md)。
- **不是读者与书的关系。** 收藏、书架、已读、进度属于 [阅读状态](阅读状态.md)。

## 2. 使用场景

- **读者想找齐一位作者的全部作品**，但书库里同一个人有「村上春树」和「Haruki Murakami」两种写法，散成两个作者页。
- **读者按标签、丛书或评分浏览**，想快速缩小到感兴趣的一批书。
- **上传者刚传完一本书**，只有文件名没有信息，希望系统自动补全书名、作者、简介和封面。
- **上传者对自动补全的结果不满意**，想手工改几个字段，或只换一张封面。
- **管理员发现书库里作者写法混乱**，想把重复写法合并成一个规范名。
- **读者用不完整的记忆搜索**，只记得译名或副标题，希望仍能命中。

## 3. 功能

- 查看一本书的全部元数据字段。
- 编辑书名、作者、出版社、标签、丛书、评分、ISBN、语言、出版日期、简介。
- 上传或替换封面。
- 维护书名别名。
- 按作者、出版社、标签、丛书、评分、文件格式浏览书库。
- 按任意别名搜索并命中完整书目。
- 从互联网检索候选元数据，整体套用、仅更新信息或仅更新封面。
- 新书入库时自动补全元数据（站点开关）。
- 维护作者别名并把别名下的书聚合到同一作者页（管理员）。
- 合并作者（管理员）。

## 4. 术语与界面用词

### 术语表

| 标准用词 | 英文 | 含义 | 示例 |
|---|---|---|---|
| 元数据 | metadata | 一本书的全部描述信息字段 | 《百年孤独》这本书的书名、作者「加西亚·马尔克斯」、出版社、ISBN、简介与封面 |
| 分类浏览 | category | 可用于聚合书籍的维度：作者、出版社、标签、丛书、评分、文件格式 | 点侧栏「作者」看到全部作者列表，再点进某位作者看他名下的书 |
| 丛书 | series | 一本书所属的系列。**标准用词是「丛书」**；书籍详情页当前显示「系列」，以「丛书」为准 | 《魔戒同盟》属于丛书「魔戒」 |
| 文件格式 | format | 作为浏览维度的格式名。作为文件操作对象时见 [书籍](书籍.md) | 按「EPUB」浏览，得到书库里所有有 EPUB 文件的书 |
| 别名 | alias | 同一书名或作者的其他写法，包括中英文名、译名与标点变体 | 作者「村上春树」的别名「Haruki Murakami」；书名《一九八四》的别名《1984》 |
| 规范名 | canonical name | 一组作者别名共同指向的展示名 | 「村上春树」「Haruki Murakami」「村上 春樹」三种写法的规范名是「村上春树」 |
| 别名组 | alias group | 归一化后指向同一规范名的全部作者写法 | 上面那三种写法构成一个别名组，规范名本身也在组内 |
| 作者合并 | author merge | 把别名组内各作者写法在书库中统一为规范名的管理员操作 | 合并后三个作者页收敛成一个，书库中相关书籍的作者字段都变成「村上春树」 |
| 排序名 | author sort | Calibre 用于排序的作者写法，不是可检索的别名 | 「村上春树」的排序名可能是「Murakami, Haruki」；用它搜不到书，它也不能当别名 |
| 自动补全 | auto fill | 新书入库时自动检索并填充元数据的站点行为 | 上传一个只有文件名的 `1984.epub`，入库后自动带上书名、作者与封面 |

## 5. 行为逻辑

### 5.1 字段规格

| 字段 | 可编辑 | 参与搜索 | 可浏览维度 | 说明 |
|---|---|---|---|---|
| 书名 | 是 | 是 | 否 | 搜索时书名命中的结果优先展示 |
| 书名别名 | 是 | 是 | 否 | Talebook 维护，详情页展示 |
| 作者 | 是 | 是 | 是 | 多值 |
| 作者别名 | 管理员 | 是 | 是 | 全局生效，跨书聚合 |
| 排序名 | 否 | 否 | 否 | 由 Calibre 维护，不可当别名使用 |
| 出版社 | 是 | 是 | 是 | 单值 |
| 标签 | 是 | 是 | 是 | 多值 |
| 丛书 | 是 | 是 | 是 | 单值 |
| 评分 | 是 | 是 | 是 | — |
| 文件格式 | 否 | 否 | 是 | 由实际存在的文件决定，不能直接编辑 |
| ISBN | 是 | 是 | 否 | 元数据检索时用于精确匹配 |
| 语言 | 是 | 是 | 否 | — |
| 出版日期 | 是 | 是 | 否 | — |
| 简介 | 是 | 是 | 否 | 缺省显示「暂无简介」 |
| 封面 | 是 | 否 | 否 | 缺省使用占位图 |

未填写的文字字段统一显示为「Unknown」，简介例外。

### 5.2 编辑权限

编辑一本书的元数据需要**同时满足**两个条件：拥有编辑权限，并且是这本书的收藏者。管理员不受所有者限制。两者任一不满足都返回「无权操作」。

编辑是**整体提交**：一次请求可以携带任意字段子集，未携带的字段保持不变。

**清空字段**通过专门的删除标记表达，而不是提交空字符串——空字符串无法与「不修改」区分。作者和标签这类多值字段**不支持清空**：一本书必须至少保留原有的作者与标签集合，提交删除标记对它们无效。

### 5.3 别名

别名解决同一实体不同写法导致搜索与作者页分裂的问题。

**归一化规则**（书名别名与作者别名一致）：

1. 压缩全部内部连续空白为单个空格，并去掉首尾空白。
2. 丢弃空值。
3. 按 Unicode casefold 折叠大小写后去重。

**限额**：单条别名最长 **500** 字符，单个书籍或作者最多 **50** 条别名。超出返回参数错误。

**书名别名**：归属某一本书，与书名重复的别名会被自动丢弃。删除书籍时一并清理。

**作者别名**：全局唯一。一个写法只能属于一个别名组，**规范名自身也必须在组内**。把已属于其他组的写法加入新组会返回参数错误，**不会静默搬组**。

别名**只扩展读取路径，不改写 Calibre 主字段**。维护别名不会修改任何一本书的作者字段。

### 5.4 作者聚合与合并

**聚合**是读取行为，随时生效：作者列表把别名组成员折叠显示为规范名，数量合并计算；作者详情页查询组内全部写法并对书籍去重。

**合并**是管理员的显式写操作，会真正修改书库：

1. 先保存别名组。
2. 把组内成员解析为书库中的作者记录。
3. 一次性把这些作者重命名为规范名。重命名到已存在的作者时复用目标作者，关联书籍的排序名与路径随之更新。

合并前必须展示**将被修改的书籍数量**，并明确提示**无法自动撤销**。

别名索引与书库不在同一个存储中，**没有跨存储事务**。书库调用失败时保留已经写入的别名聚合，并返回本次受影响的书籍。外部索引的书在合并期间不移动源文件。

### 5.5 分类浏览

六个浏览维度各有独立页面：作者、出版社、标签、丛书、评分、文件格式。列表页展示每个条目及其书籍数量。

- **作者维度**按别名组折叠：展示规范名与合并后的数量。
- **文件格式维度**根据书库中实际存在的文件实时统计，不依赖任何可编辑字段。
- 其余维度直接取书库分类。

列表支持**关键词过滤**与**分页**，默认每页 **100** 条，单页最多 **1000** 条。分页参数非法时返回「分页参数无效」，不静默回退。

进入某个条目的详情页时展示该维度下的全部书籍，并**始终应用私有书过滤**——别名与聚合不构成权限旁路。

### 5.6 搜索

搜索结果是三部分的**并集**：

1. 书库自身的全文检索结果（覆盖书名、简介、标签等字段）。
2. 书名别名命中的书。
3. 作者别名组对应的全部书。

**排序规则**：书名命中（含书名别名命中）的结果排在前面，同一优先级内按入库顺序从新到旧。原因是全文检索会把书名命中和简介、标签命中混在一起返回，读者期望书名命中优先。

关键词为空时返回「请输入搜索关键字」。

### 5.7 互联网同步

从互联网获取元数据是**用户显式触发**的检索 + 确认流程，不是自动覆盖。

1. 以当前书的书名、作者、ISBN 为线索，**并行**查询全部已启用的元数据源。
2. 每个来源最多取 **5** 条候选；整体查询超时 **30 秒**，超时的来源被取消但不影响已返回的结果。
3. 部分来源失败时仍返回成功结果，并给出失败摘要。
4. 用户从候选中选择后套用。

**三种套用方式**：

| 方式 | 行为 |
|---|---|
| 整体套用 | 文字字段与封面一并更新。候选封面获取失败时保留本地原封面，并明确告知 |
| 仅更新信息 | 丢弃候选封面，只改文字字段 |
| 仅更新封面 | 只替换封面。候选封面为空时报「获取到的封面数据为空」并中止 |

「仅更新信息」与「仅更新封面」**不能同时指定**。

整体套用时若候选和当前书都没有标签，系统会从站点的分类导航词表中挑出在书名、简介或作者中出现的词作为标签，最多补 **8** 个。

**自动补全**是站点级开关，默认**关闭**。开启后新书入库时自动执行上述检索并套用。另有独立开关控制是否保留原有封面，默认**保留**。

### 5.8 封面

封面可以通过上传本地图片或从互联网同步获得。上传只接受 JPEG、PNG、GIF。

封面对外是带缓存参数的图片地址，缓存参数取自书籍的时间戳。**任何改变封面的操作都必须同时刷新书籍时间戳**，否则读者会继续看到旧封面。「仅更新封面」这条路径尤其容易漏——它不修改任何文字字段，必须显式刷新。

同时提供原图与 60×80 缩略图两种地址。

## 6. 关联实体

- [书籍](书籍.md)——元数据描述的对象。文件格式的操作、媒体分类、可见范围与所有权在那里；本篇只管「按文件格式浏览」。
- [书库](书库.md)——书库的浏览与筛选建立在本篇定义的维度之上。
- [元数据源](插件/元数据源.md)——互联网同步的候选由它提供；启用哪些来源由插件状态决定。
- [用户](用户.md)——编辑权限与书籍所有权的判定规则在那里。
- [阅读状态](阅读状态.md)——评分字段是书的客观元数据，与读者个人的已读状态无关。

## 7. 实现对照

### 7.1 数据存储

| 概念 | 存储 | 表与字段 |
|---|---|---|
| 元数据主字段 | Calibre 书库 | 经 `BaseHandler.db` 读写，**不走 SQLAlchemy** |
| 书名别名 | Talebook 业务库 | `book_aliases`；`(book_id, normalized_name)` 唯一约束 `uq_book_alias_name` |
| 作者别名 | Talebook 业务库 | `author_aliases`；主键 `normalized_name`，指向 `canonical_name` 与 `canonical_normalized_name` |
| 封面缓存键 | Calibre 书库 | 书籍 `timestamp` 字段，出现在封面 URL 的 `t` 参数上 |

### 7.2 API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/book/<id>/edit` | 编辑元数据；以 multipart 提交 `cover` 时转入封面上传分支 |
| POST | `/api/book/<id>/refer` | 互联网同步；参数 `only_meta` / `only_cover`，二者互斥 |
| GET | `/api/(author\|publisher\|tag\|rating\|series\|format)` | 分类列表；参数 `page`、`page_size`、`q` |
| GET | `/api/(author\|publisher\|tag\|rating\|series\|format)/<name>` | 分类详情，返回该维度下的书籍 |
| GET | `/api/author/<name>/alias` | 读取作者别名组，公开 |
| POST | `/api/author/<name>/alias` | 保存别名组；可带 `merge` 触发合并，需管理员 |
| GET | `/api/search` | 搜索，参数 `name` |
| GET | `/get/cover/<id>.jpg?t=<ts>` | 封面原图 |
| GET | `/get/thumb_60x80/<id>.jpg?t=<ts>` | 封面缩略图 |

### 7.3 关键定义

| 符号 | 值 | 含义 |
|---|---|---|
| `MAX_ALIAS_LENGTH` | `500` | 单条别名最大字符数 |
| `MAX_ALIASES_PER_ITEM` | `50` | 单个书籍或作者的别名条数上限 |
| `BookRefer.SOURCE_RESULT_LIMIT` | `5` | 每个元数据源采纳的候选条数 |
| `BookRefer.REFER_TIMEOUT` | `30` | 并行检索的总超时秒数 |
| `BookEdit.KEYS` | `authors` `title` `comments` `tags` `publisher` `isbn` `series` `rating` `language` | 可编辑字段白名单；`pubdate` 与 `aliases` 单独处理 |
| `__DELETE__` | — | 清空字段的标记；对 `authors` 与 `tags` 无效 |
| `MetaList` 分页 | 默认 `100`，上限 `1000` | 分类列表每页条数 |
| `auto_fill_meta` | `False` | 新书自动补全总开关 |
| `auto_fill_keep_cover` | `True` | 自动补全时保留原有封面 |
| `BOOK_NAV` | — | 整体套用且双方都无标签时，用于补标签的分类词表，最多补 8 个 |
