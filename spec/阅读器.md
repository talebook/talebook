# 阅读器

## 1. 定义

阅读器是**在浏览器里打开一本书并让人读下去的那套界面**。Talebook 内置三种，分别服务三类内容：图文书阅读器、纯文本阅读器、漫画阅读器。

阅读器的核心产品承诺是：**读者只需要点「在线阅读」，不需要知道这本书有哪些格式**。用哪个格式、哪个阅读器，由服务端统一决定。

**不是什么：**

- **不是格式管理。** 上传、转换、删除格式属于 [书籍](书籍.md)。
- **不是进度存储。** 进度存在哪、有什么限额属于 [阅读状态](阅读状态.md)；阅读器只是生产和消费它。
- **不是听书。** 有声书播放器是独立的播放界面，属于 [有声书](有声书.md)。
- **不是外部客户端。** Moke、静读天下等在 Talebook 界面之外阅读，属于 [外部访问](外部访问.md)。

## 2. 使用场景

- **读者在书籍详情页点「在线阅读」**，期望直接开始读，不必先挑格式。
- **一本书同时有 EPUB 和 PDF**，读者期望得到体验更好的那个，而不是碰运气。
- **读者读到一半关掉浏览器**，第二天打开希望回到原处。
- **读者在读一本已经生成有声书的书**，想边听边读，听到哪里高亮到哪里。
- **读者点开一本漫画**，期望是翻页看图，不是看到一堆文件名。
- **游客没有账号**，站点允许的话也想直接读。

## 3. 功能

- 统一的在线阅读入口。
- 图文书阅读：分章导航、翻页、记忆位置。
- 纯文本阅读：长文排版与翻章。
- 漫画阅读：按页浏览、记忆页码。
- 音文同步：播放有声书时按句段高亮正文。
- 阅读辅助开关：读者可按需关掉章评、划线笔记、阅读笔记悬浮窗，以及禁用选中正文。
- 阅读进度自动保存与恢复。
- 未授权时给出明确原因，而不是空白页。

## 5. 行为逻辑

### 5.1 统一入口与格式优先级

**前端所有阅读按钮指向同一个地址**，格式选择只在服务端做。这条是硬约束：一旦允许前端根据格式清单自己决定跳哪里，同一本书从不同入口点进去就会得到不同结果。

格式优先级：

```
EPUB  →  PDF  →  TXT  →  MOBI / AZW / AZW3（转换为 EPUB 后阅读）
```

**核心可观察行为**：只要存在 EPUB 就打开图文书阅读器，**不触发 PDF 或 TXT 跳转，也不启动转换**。

优先级只作用于「在线打开与阅读」。下载、发送到设备、删除格式、抽出格式仍由读者明确选择，不被强制改成 EPUB。

PDF 阅读器取流时由统一入口显式请求内联响应；直接从详情页下载同一个 PDF 时仍作为附件交付。阅读用途不能改变文件接口的默认下载语义。

历史的纯文本阅读地址在存在 EPUB 时转到统一入口，防止旧书签绕过优先级；**只有 TXT 的书仍留在纯文本阅读器**。

### 5.2 漫画的分流

内容形态为漫画的书走漫画阅读器，与图文书阅读器是两条独立链路。判定依据是持久化的内容形态字段，见 [书籍](书籍.md)。

**漫画型 EPUB 例外**：它虽然被判定为漫画，但仍使用图文书阅读器——因为 EPUB 本身就能渲染。走漫画阅读器的只有图片压缩包。

漫画阅读器本体是**版本化的静态前端资源**，独立于后端模板分发。这样做是为了让阅读器能独立升级，不必跟随后端发版。

### 5.3 阅读权限

进入阅读器前依次判断：

1. **游客或演示账号**——只看站点的访客阅读开关，不通过则跳转登录页。演示账号**自身的权限位被忽略**，因为它默认全开，用于伪装管理员体验。
2. **有阅读权限的登录读者**——还要求账号已激活，未激活提示先激活邮箱。
3. **无阅读权限的登录读者**——直接拒绝。

在此之前，书籍本身的可见性判定必须已经通过，见 [书籍](书籍.md)。

### 5.4 进度

阅读器负责**生产**进度并在打开时**消费**它。进度的内部结构由阅读器定义，服务端只存取不解释；漫画进度是页码型，图文书进度由阅读器自定。

服务端只施加两条约束：单条进度有体积上限；漫画进度的页序号会被夹取到合法范围。详见 [阅读状态](阅读状态.md)。

**读到最后不会自动标记为读完。** 已读状态始终由读者显式设置。

### 5.5 音文同步

当一本书存在已发布的有声版本时，阅读页会带上该版本的标识，阅读器据此提供音文同步：按**句子或对白逻辑片段**高亮，**不承诺逐字卡拉 OK**。

文字阅读进度与收听进度**互相独立**，边听边读不会覆盖文字位置。

### 5.6 阅读会记一次取用

打开一次阅读器会记录一次阅读历史，并累加该书的下载计数。因此下载计数的语义是「取用次数」。演示模式下都不记录。

## 7. 实现对照

### 7.1 数据存储

| 概念 | 存储 | 说明 |
|---|---|---|
| 阅读进度 | `reading_state.progress` | 见 [阅读状态](阅读状态.md) |
| EPUB 解压产物 | 文件系统 | `extract_path`，默认 `/data/books/extract/` |
| 漫画页 | 原始压缩包 | 按需读取，不整体解压 |

### 7.2 API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/read/<id>` | **统一在线阅读入口** |
| GET | `/api/read/txt`、`/api/book/txt/init` | 纯文本正文与初始化 |
| GET | `/read-comic/<id>` | 漫画阅读器宿主页 |
| GET | `/api/book/<id>/comic/pages`、`/pages/<n>` | 漫画页清单与单页图片 |
| GET / POST | `/api/book/<id>/comic/progress` | 漫画进度 |
| GET | `/get/extract/<id>/<path>` | EPUB 解压资源 |

### 7.3 关键定义

| 符号 | 值 | 含义 |
|---|---|---|
| `EPUB_VIEWER` | `creader.html` | 图文书阅读器模板 |
| `CANDLE_READER_SERVER` | `https://brs.talebook.org` | 音文同步阅读器服务地址 |
| `ALLOW_GUEST_READ` | `True` | 游客在线阅读开关 |
| 格式优先级 | EPUB → PDF → TXT → MOBI/AZW/AZW3 转 EPUB | 仅作用于在线阅读 |
| `COMIC_PROGRESS_VERSION` | `1` | 漫画进度结构版本 |

### 7.4 代码落点

| 行为 | 文件与函数 |
|---|---|
| 统一入口与权限判定 | `webserver/handlers/book.py` 的 `BookRead.get()` |
| 图文书渲染 | 同文件的 `BookRead.render_epub()` |
| 纯文本阅读 | 同文件的 `TxtRead`、`BookTxtInit` |
| 漫画阅读 | `webserver/handlers/comic.py` 的 `ComicReaderHandler`、`ComicManifestHandler`、`ComicPageHandler`、`ComicProgressHandler` |
| EPUB 解压服务 | `webserver/handlers/files.py` 的 `EpubReader`；解压见 `webserver/services/extract.py` |
| 纯文本阅读页 | 前端路由 `app/pages/book/[bid]/readtxt.vue`；存在 EPUB 时跳转到统一入口 |
| 阅读历史与计数 | `BaseHandler.user_history()`、`count_increase()` |
| 阅读辅助开关（章评 / 划线笔记 / 阅读笔记悬浮窗 / 选中文本） | `webserver/resources/book/creader.html` 的阅读辅助偏好模块、注解可见性判断与 `rendition.themes` 的 `user-select` 覆盖 |
