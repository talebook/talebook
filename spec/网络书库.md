# 网络书库

## 1. 定义

网络书库是**读者在 Talebook 里搜索、试读并保存互联网在线书籍的入口**。它由在线书源驱动：搜索一个书名，Talebook 并行问过多个书源，把结果汇总给读者；读者可以直接在线读，也可以把整本保存进自己的书库。

它是一个**读者视角**的产品实体。书源本身的导入、体检与治理是管理员的事，见 [Legado](插件/Legado.md)。

**不是什么：**

- **不是本地藏书。** 在线书籍在保存之前不属于 [书库](书库.md)，没有格式文件，也没有阅读状态。
- **不是书源管理。** 导入书源、体检、启停属于 [Legado](插件/Legado.md)。
- **不是元数据检索。** 为已有的书补全信息属于 [元数据源](插件/元数据源.md)，虽然书源也能兼作元数据来源。
- **不是外部书库接入。** Kavita、Komga、OPDS 这类自托管书库属于 [外部书库源](插件/外部书库源.md)。

## 2. 使用场景

- **读者想看一本网文**，书库里没有，希望直接搜互联网。
- **读者不确定哪个书源可用**，希望系统优先用近期能用的源。
- **搜索很慢**，读者希望能看到进度、能中途停下。
- **读者点进一本书**，想先看目录和最新章节再决定读不读。
- **读者想先读两章试试**，不想立刻下载整本。
- **读者决定留下这本书**，希望保存成 EPUB 进自己的书库。
- **读者从详情页返回搜索结果**，希望上次的搜索还在。

## 3. 功能

- 按关键词搜索在线书籍，可选搜索范围。
- 查看搜索进度、中途停止、查看部分失败。
- 按书源分类浏览。
- 查看书籍详情：作者、完结状态、最新章节、简介、目录。
- 在线逐章阅读。
- 保存为 TXT 或 EPUB 到本地书库，带章节进度。
- 保存后记录来源与连载状态。
- 返回搜索页时恢复上次的搜索结果。

### 术语表

| 标准用词 | 英文 | 含义 | 示例 |
|---|---|---|---|
| 网络书库 | network library | 读者搜索与阅读互联网在线书籍的入口 | 侧栏「网络书库」，搜到的书还不在自己的书库里 |

| 近期可用 | recently healthy | 最近体检通过、按权重优先选用的书源 | 默认范围，避免每次都去问已经挂掉的站 |
| 部分失败 | partial failure | 一次搜索中有些书源失败但整体仍返回结果 | 10 个源里 3 个超时，其余 7 个的结果照常展示 |
| 连载状态 | serialize status | 在线书是连载中、已完结还是未知 | 保存后详情页显示「连载中 · 最新第 1203 章」 |
| 保存到本地 | save | 把在线书抓取为文件并入库 | 保存成 EPUB 后它变成书库里的一本正式书籍 |

## 5. 行为逻辑

### 5.1 搜索只由读者动作触发

搜索**不会自动发起**。打开页面、切换筛选、翻页都不触发搜索，必须由读者明确点击。这条是刻意的：每次搜索都会对几十个外部站点发起请求，自动触发会造成读者无感知的大量外部流量。

### 5.2 异步搜索

搜索是后台任务，不是一次同步请求——问几十个外部站点的耗时不可控。

1. 提交搜索后立即返回任务标识。
2. 前端轮询进度，展示已完成的源数与已得到的结果。
3. 读者可以随时**停止**。
4. 部分书源失败不影响整体，失败清单一并返回。

**命中的书源会提高权重**，从而更容易进入下一次的「近期可用」范围。这是一个自我优化的排序，不需要人工维护优先级。

三种搜索范围：近期可用（默认，按权重选源）、全部、手动选择。

### 5.3 结果缓存与返回恢复

搜索结果按关键词、范围、所选书源与页码缓存。读者点进详情再返回时，**上次的搜索结果仍在**，不必重搜。这条直接决定体验——否则每看一本书就要重新等一次几十秒的搜索。

### 5.4 浏览

书源规则里可以声明分类地址。网络书库据此提供分类浏览，按分类与页码翻页，不依赖搜索。

### 5.5 在线阅读

在线阅读逐章抓取，提供章节标题、正文与上一章 / 下一章导航。正文经过清理，去掉广告与导航残留。

在线阅读**不产生阅读状态**——这本书还不在书库里，没有可挂载的对象。

### 5.6 保存到本地

保存是后台任务：逐章抓取、清理、合成为 TXT 或 EPUB，然后走正常入库流程。过程中展示章节级进度，完成后给出本地书籍的直达入口。

保存成功后，系统记录这本书的**来源**与**连载状态**：

| 连载状态 | 含义 |
|---|---|
| 连载中 | 还在更新 |
| 已完结 | 不再更新 |
| 未知 | 书源没有提供或无法判断 |

连载状态可以被**人工覆盖**并打上标记，此后自动同步不再改写它——防止书源的错误判断反复冲掉人工修正。

入库之后它就是一本普通书籍，适用 [书籍](书籍.md) 与 [元数据](元数据.md) 的全部规则。

### 5.7 可见性

网络书库入口本身可以被站点开关关闭。它不改变任何本地书籍的可见性规则。

## 7. 实现对照

### 7.1 数据存储

| 概念 | 表与字段 | 说明 |
|---|---|---|
| 在线书源 | `book_sources`，`BookSourceModel` | 见 [Legado](插件/Legado.md) |
| 保存后的来源与连载状态 | `online_book_meta`，`OnlineBookMeta` | 主键即 Calibre `book_id` |
| 来源地址 | `source_url` / `origin_book_url` | 书源地址与原书详情页 |
| 连载状态 | `serialize_status` / `status_manual` / `last_chapter` | `serial` / `finished` / `unknown` |
| 搜索任务与结果缓存 | 内存 | 由搜索服务持有，不落库 |

### 7.2 API 接口

同一组处理器注册了两套前缀，`/api/book-sources/*` 与 `/api/network/*` 等价。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/book-sources` | 可用书源列表 |
| POST | `/api/book-sources/search` | 发起异步搜索 |
| GET | `/api/book-sources/search/status` | 搜索进度与部分失败 |
| GET | `/api/book-sources/categories`、`/browse` | 分类与分类浏览 |
| GET | `/api/book-sources/book`、`/toc`、`/content` | 在线书详情、目录、正文 |
| POST | `/api/book-sources/save` | 发起保存 |
| GET | `/api/book-sources/save/status` | 保存进度 |
| GET | `/api/network/status` | 网络书库总体状态 |
| GET | `/api/library/online` | 已保存的在线书列表 |

### 7.3 关键定义

| 符号 | 值 | 含义 |
|---|---|---|
| 搜索范围 | `top` / 全部 / 手选 | `top` 为默认，按权重选近期可用源 |
| `OnlineBookMeta.SERIAL` / `FINISHED` / `UNKNOWN` | `serial` / `finished` / `unknown` | 连载状态 |
| `status_manual` | 布尔 | 人工覆盖标记，置真后自动同步不改写 |
| `SHOW_NETWORK_LIBRARY` | `True` | 网络书库入口开关 |
