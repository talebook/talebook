# 划线笔记

## 1. 定义

划线笔记是**读者在书里留下的痕迹**：高亮、笔记、书签、章评。它是读者的个人创作物，而不是书的属性。

Talebook 对划线笔记只有一条根本立场：**本站保存的是唯一权威内容**。微信读书、BRS、Calibre 等外部系统都只是「来源」，它们那边的记录是本站记录的副本，只登记身份与同步状态，**永不保存正文**。

**不是什么：**

- **不是外部服务的缓存。** 本站是权威，不是镜像。
- **不是评价。** 外部评分、书评属于 [评价源](插件/评价源.md)；章评虽然形似书评，但因为是读者在本站产生的内容，归本篇。
- **不是阅读进度。** 读到哪里属于 [阅读状态](阅读状态.md)。
- **不是书的元数据。** 见 [元数据](元数据.md)。

## 2. 使用场景

- **读者在线阅读时划了一句话**，希望它留在书里，换设备也在。
- **读者想回顾自己所有的笔记**，不必逐本书翻。
- **读者觉得某条笔记值得分享**，希望同书的其他读者看得到。
- **读者在微信读书里积累了几年的划线**，想导进本站统一管理。
- **读者在本站写的公开笔记**，希望自动同步回外部服务。
- **读者导错了一批数据**，想撤销这一次导入。

## 3. 功能

- 在阅读器中创建高亮、笔记、书签、章评。
- 修改、删除自己的记录。
- 按书查看笔记；查看同书其他读者的公开笔记。
- 跨书汇总查看自己的全部笔记。
- 按来源筛选。
- 导出全部权威记录及其外部映射。
- 从外部服务导入。
- 公开记录自动同步到已注册的外部服务。
- 撤销某一批导入。

## 5. 行为逻辑

### 5.1 权威与副本

一条划线笔记由两部分组成：

- **权威记录**——正文、引文、位置、颜色、隐私、作者，全部存在本站。
- **外部副本**——每个来源一条，只存外部 id、位置串、内容指纹、远端时间与同步状态。

一条权威记录可以有多个外部副本，但**每条记录在同一个来源连接下只能有一个副本**，且外部身份不能被重复绑定。

章评也是一种笔记类型，**不另建内容表**，因此本站不存在独立的「章评」接口。

### 5.2 可见性

| 记录 | 谁能看 | 谁能改 |
|---|---|---|
| 私有 | 仅作者 | 仅作者 |
| 公开 | 对该书有阅读权限的**登录**读者 | 仅作者 |

三条硬约束：

1. **私有是默认值**，新建记录不指定隐私时按私有处理。
2. **公开记录也要先通过书籍可见性校验**——私藏书上的公开笔记不会泄漏给无权读者。
3. **管理员没有读取他人私有正文的旁路。** 这与「管理员可访问全部私藏图书」是两条独立规则，不要互相推导。

### 5.3 幂等与冲突

同一条笔记可能从本站和多个来源反复到达，因此需要明确的身份与冲突规则：

**身份判定**：携带完整外部身份（来源名 + 连接 + 外部 id）时按外部映射查找；本站创建则按「作者 + 书 + 客户端 id」查找。

**冲突保护**：

- 来源送来的更新如果比已知的远端时间更旧且内容指纹不同，视为**陈旧事件丢弃**，不回滚权威内容。
- 读者在本站改过正文后会打上修改时间戳；此后来源导入**只刷新该来源的映射**，不覆盖正文，并明确返回「已受冲突保护」。

**删除的分寸**：按来源清理删除的是**映射**，不是正文。权威记录只能由作者本人单条删除。

### 5.4 异步扇出

读者新建或修改**公开**记录后：

1. 先提交本站的权威事务。
2. 再把记录放进后台队列。
3. 后台为每个已注册的来源写入器建一条待同步映射，逐个调用。
4. 成功记录外部 id、指纹与远端时间；失败写入错误摘要，**其余来源继续执行**，互不阻断。

三条边界：

- **私有记录不入队**，永不外发。
- 从某来源导入的记录**不会再扇回该来源**，避免回环；但仍可扇出到其他来源。
- 外部写入不在数据库事务内，允许短暂不一致。待同步与失败状态就是用来观察和后续重试的。

### 5.5 导入与回滚

从外部服务导入是一次可审计的运行，属于插件运行模型，见 [插件平台](插件/插件平台.md)。导入结果可以整批**回滚**——回滚撤销的是这一批导入带来的记录与映射。

上传的导出文件属于私有输入，**不进入运行日志**，防止个人数据经运行接口泄漏。

## 7. 实现对照

### 7.1 数据存储

| 概念 | 表与字段 | 说明 |
|---|---|---|
| 权威记录 | `annotations` | 唯一约束 `(reader_id, book_id, client_id)`；`reader_id` 级联删除 |
| 正文与位置 | `annotation_type` `content` `quote_text` `color` `author_name` `cfi` `chapter` | `cfi` **可空**，保留章节级定位 |
| 隐私 | `is_private` | 默认 `true` |
| 本地修改时间 | `user_modified_at` | 冲突保护的依据 |
| 外部副本 | `annotation_sources` | 唯一约束 `(annotation_id, source_name, source_connection_id)` 与 `(source_name, source_connection_id, source_annotation_id)` |
| 外部身份与状态 | `source_*` 前缀字段 | 统一前缀，避免被误认为本站权威属性 |

### 7.2 API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET / POST | `/api/book/<book_id>/annotations` | 按书读取；按客户端 id 或外部身份幂等写入 |
| PUT / DELETE | `/api/book/<book_id>/annotations/<id>` | 仅作者可改删 |
| GET / DELETE | `/api/annotations` | 跨书管理自己的记录；来源筛选字段均为 `source_*`，DELETE 只解除映射 |
| GET | `/api/annotations/export` | 导出权威记录及其外部映射 |

`/api/*/chapter-comments` **不存在**，章评走同一组接口。

### 7.3 关键定义

| 符号 | 值 | 含义 |
|---|---|---|
| 笔记类型 | `highlight` `note` `bookmark` `chapter_comment` | 四类 |
| `is_private` 默认 | `true` | 安全默认值 |
| 同步状态 | `pending` `synced` `failed` | 外部副本状态 |
| 冲突返回 | `conflict_protected=true` | 本地已修改，来源不覆盖 |
| `ENTITY_TYPES` 中的 | `annotation` | 插件运行的实体类型之一 |
