# Talebook 领域规格 · 索引

这里是 Talebook 的**领域规格文档**，描述产品是什么、按什么规则运转。

## 这份文档的定位

- **唯一一份。** 领域定义不在别处重复。
- **总是最新。** 改变产品行为的改动必须在同一次提交里更新对应篇目。
- **无时态。** 只写当下的产品应然，不写变更历史、不写未实现、不写已废弃。那些属于 `design/` 。

与仓库其他文字资产的分工：

| 目录 | 回答的问题 | 时态 |
|---|---|---|
| `spec/` | 产品**是什么** | 无时态 |
| `design/` | 某次改动**怎么做**：论证与验证 | 有时态，WIP / ACTIVE / SUPERSEDED |
| `document/` | 使用者**怎么用** | 跟随版本 |
| `research/` | 外部系统**怎么做的** | 快照 |

## 每篇的结构

固定七节，顺序是「先建立直觉，再交付词汇，最后进入细节」：

1. **定义** —— 是什么，以及不是什么
2. **使用场景** —— 谁、在什么情况下、要达成什么
3. **功能** —— 概述清单
4. **术语与界面用词** —— 术语表（含示例）与操作按钮用词表
5. **行为逻辑** —— 详细产品设计，全篇最重
6. **关联实体** —— 与其他篇的关系
7. **实现对照** —— 数据存储、API 接口、关键定义、代码落点、界面文案五张子表，**唯一允许出现实现细节的地方**

正文使用产品语言。表名、字段名、路由与常量只出现在第 7 节。

## 容易混淆的几组概念

| 看起来一样 | 实际区别 | 分别见 |
|---|---|---|
| 书架 / 收藏 | 打算读 vs 喜欢，两个独立开关 | [阅读状态](阅读状态.md) |
| 元数据 / 元数据源 | 字段本身 vs 获取字段的外部来源 | [元数据](元数据.md)、[元数据源](插件/元数据源.md) |
| OPDS 对外 / OPDS 取书 | 暴露本站藏书 vs 从别处取书，方向相反 | [外部访问](外部访问.md)、[外部书库源](插件/外部书库源.md) |
| 网络书库 / Legado | 读者视角 vs 管理员视角 | [网络书库](网络书库.md)、[Legado](插件/Legado.md) |
| 划线笔记 / 评价 | 站内产生的内容 vs 外部的评分书评 | [划线笔记](划线笔记.md)、[评价源](插件/评价源.md) |
| 阅读进度 / 收听进度 | 两套独立数据，互不覆盖 | [阅读状态](阅读状态.md)、[有声书](有声书.md) |
| 启用 / 已配置 / 健康 | 插件的三个独立状态 | [插件平台](插件/插件平台.md) |
