# 系统设置

## 1. 定义

系统设置是**管理员对一个 Talebook 实例的全部可调项**，以及第一次把实例跑起来的初始化流程。它决定这个站点对外呈现成什么样：叫什么名字、谁能进来、游客能做什么、开哪些对外服务、用什么主题。

设置的核心特征是**分层覆盖**：仓库里的默认值打底，管理员在界面上保存的值覆盖它，本地开发文件再覆盖一层。管理员改设置**不需要改代码，也不需要重启**（数据库迁移等少数项例外）。

**不是什么：**

- **不是插件配置。** 插件的启停、连接与凭据属于 [插件平台](插件/插件平台.md)；OPDS 对外服务开关就长在插件卡片上，是个例外。
- **不是用户的个人偏好。** 设备、推送邮箱属于 [用户](用户.md)。
- **不是部署配置。** 端口、卷挂载、反向代理属于运维，不在本篇。

## 2. 使用场景

- **部署者第一次打开站点**，需要建管理员账号、填站点名称。
- **管理员想把站点改成私人模式**，只有知道邀请码的人能进。
- **管理员想让游客能看不能下**。
- **管理员配好了邮箱**，想先测一下能不能发出去。
- **管理员想换个界面主题**。
- **站点书变多了**，想从 SQLite 迁到 MySQL。
- **出问题了**，管理员想看日志。

## 3. 功能

- 首次安装向导：建管理员、设站点名称。
- 站点信息：名称、页头页脚、侧栏自定义内容。
- 访问控制：注册开关、邀请模式、游客四项权限、默认权限。
- 演示模式开关。
- 邮件服务配置与发信测试。
- 社交登录配置。
- 元数据源选择与自动补全策略。
- 导入目录、允许目录与自动监控。
- 对外服务开关：OPDS、WebDAV 及同步目录。
- 主题安装与启用。
- SSL 证书管理与热更新。
- 数据库连接测试与迁移。
- 系统日志查看与下载。
- 版本更新检查。

## 5. 行为逻辑

### 5.1 配置的三层叠加

```
仓库默认值  →  管理员在界面保存的值  →  本地开发覆盖（可选）
```

后者覆盖前者。管理员保存的值写入运行时配置文件，**不修改仓库代码**，因此升级不会丢配置。

**保存必须保留内部配置。** 界面上没有展示的配置项（例如插件加密密钥）在保存时必须原样保留，不能因为表单里没有就被清空。这条是保存逻辑的硬约束。

### 5.2 安装

全新实例处于**未安装**状态，所有页面被引导到安装向导。安装需要：管理员用户名与密码、邮箱、站点名称，可选邀请码。

校验规则与注册一致，见 [用户](用户.md)。

**安装只能执行一次**，已安装的实例再次提交直接拒绝。安装态下前端必须保留安全状态并合并重复跳转，避免循环。

### 5.3 访问控制

四组独立的开关，互不推导：

| 组 | 控制什么 | 默认 |
|---|---|---|
| 注册 | 陌生人能否自助创建账号 | 关闭 |
| 邀请模式 | 未持邀请码能否进站 | 关闭 |
| 游客权限 | 未登录者的阅读、下载、推送、上传 | 前三项开，上传关 |
| 默认权限 | 新账号的初始能力权限 | 空（即全部按默认允许） |

自托管私人书库的默认姿态是封闭：注册默认关闭，账号由部署者创建。

### 5.4 对外服务开关

| 服务 | 开关位置 |
|---|---|
| OPDS 目录服务 | **插件中心的 OPDS 卡片** |
| WebDAV 挂载 | 系统设置 |
| WebDAV 同步目录 | 系统设置，默认关闭 |
| 网络书库入口 | 系统设置 |
| 侧栏系统区块 | 系统设置 |

OPDS 是唯一一个开关不在系统设置里的对外服务，见 [外部访问](外部访问.md)。

### 5.5 邮件

邮件用于账号激活、密码重置与推送到 Kindle 邮箱。配置包含服务器、加密方式、账号与密码，并提供**发信测试**——邮件配置错误通常要等到用户注册失败才暴露，测试按钮把这个反馈提前。

推送邮件的标题与正文是可配置模板，支持站点名、书名与站点地址的占位替换。

### 5.6 主题

主题是可安装的界面外观包。同一时刻**只有一个启用**。主题记录名称、版本、作者、描述与组件清单。

站点另有若干与主题无关的外观自定义项：页头提示、页脚、页脚附加内容、侧栏附加内容。

### 5.7 数据库

Talebook 自身的业务数据支持从 SQLite 迁移到 MySQL / MariaDB；**Calibre 的书目数据始终使用 SQLite**，不参与迁移。迁移前可先测试连接，迁移完成后**需要重启服务**才生效。

业务表结构在启动时自动补齐缺失的整表，新增表不需要手写迁移。

### 5.8 SSL 证书

支持配置证书与私钥路径，并在证书更新后**热更新**，失败时回滚到原证书。热更新以非 root 身份完成——容器内不应为了换证书而提权。

### 5.9 日志与更新

管理员可以在线查看系统日志并下载。站点会检查上游版本更新并在后台提示。

## 7. 实现对照

### 7.1 数据存储

| 概念 | 存储 | 说明 |
|---|---|---|
| 默认配置 | `webserver/settings.py` | 提交到仓库 |
| 运行时配置 | `<settings_path>/auto.py` | 管理员保存时写入，默认 `/data/books/settings/` |
| 本地覆盖 | `manual.py` | 可选，不提交 |
| 已安装主题 | `installed_themes`，`InstalledTheme` 模型 | `name` 唯一；同时只有一个 `active` |
| 业务数据库 | `user_database` | 默认 `sqlite:////data/books/calibre-webserver.db` |

### 7.2 API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/welcome` | 站点信息与安装状态 |
| GET / POST | `/api/admin/install` | 安装状态与执行安装 |
| GET / POST | `/api/admin/settings` | 读取与保存设置 |
| POST | `/api/admin/testmail` | 发信测试 |
| POST | `/api/admin/testdb`、`/api/admin/migratedb` | 数据库连接测试与迁移 |
| GET / POST | `/api/admin/ssl` | SSL 证书管理 |
| GET | `/api/admin/update` | 版本更新检查 |
| GET | `/api/admin/log`、`/api/admin/log/download` | 系统日志 |
| GET / POST | `/api/themes`、`/api/themes/activate`、`/api/themes/active` | 主题 |

### 7.3 关键定义

| 符号 | 值 | 含义 |
|---|---|---|
| `installed` | `False` | 未安装标记 |

| `settings_path` | `/data/books/settings/` | 运行时配置目录 |
| `user_database` | `sqlite:////data/books/calibre-webserver.db` | 业务数据库 |
| `cookie_expire` | `7 * 86400` | 会话有效期 |
| `ALLOW_REGISTER` | `False` | 注册开关 |
| `INVITE_MODE` / `INVITE_CODE` | `False` / `love` | 邀请门禁 |
| `ALLOW_GUEST_READ` / `PUSH` / `DOWNLOAD` / `UPLOAD` | `True` / `True` / `True` / `False` | 游客四项 |
| `DEFAULT_USER_PERMISSION` | `''` | 新账号初始权限 |
| `DEMO_MODE` / `DEMO_USERNAME` | `False` / `demo` | 演示模式 |
| `OPDS_ENABLED` | `True` | OPDS 对外服务，**由插件卡片切换** |
| `ENABLE_WEBDAV_SERVICE` | `True` | WebDAV 对外服务 |
| `WEBDAV_SYNC_FOLDER` / `_NAME` | `False` / `reader` | 每用户同步目录 |
