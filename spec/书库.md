# 书库

## 1. 定义

书库是**一个 Talebook 实例所管理的全部藏书**，以及把书送进来、找出来、清出去的全部手段。它是站点最核心的容器：所有书籍、元数据、阅读状态最终都挂在这一个书库上。

一个实例只有一个书库。书库的书目与文件由 Calibre 管理，Talebook 在其之上叠加导入流程、可见性过滤与浏览筛选。

**不是什么：**

- **不是单本书。** 一本书自身的字段与文件属于 [书籍](书籍.md)。
- **不是外部内容。** 书源提供的在线书籍在保存到本地之前不属于书库，见 [网络书库](网络书库.md)。
- **不是个人清单。** 收藏、书架是读者与书的关系，属于 [阅读状态](阅读状态.md)。
- **不支持多书库。** 没有「切换书库」的概念。

## 2. 使用场景

- **部署者第一次装好站点**，需要把已有的一堆电子书文件批量导进来。
- **读者想在几千本书里找到一本**，靠关键词或按维度逐层筛。
- **上传者从浏览器传一本大文件**，网络不稳，希望断了能续。
- **管理员把一批新书放进服务器目录**，希望系统自动发现并入库。
- **管理员误删了书**，想找回来。
- **读者只想看自己传的私藏书**。

## 3. 功能

- 浏览全部藏书，按维度筛选与排序。
- 关键词搜索。
- 最近上架、热门榜单、随机推荐等入口。
- 网页上传单本或多本书，大文件分片续传。
- 扫描服务器目录，批量查重与导入。
- 自动监控指定目录，有新文件时自动导入。
- 从外部 OPDS 服务器批量导入。
- 查看、恢复与清空回收站。
- 查看仅自己可见的私藏书。

## 5. 行为逻辑

### 5.1 可见性过滤

书库的每一个列表入口——浏览、搜索、分类、榜单——都**必须应用可见性过滤**：

- 管理员看到全部书。
- 登录读者看到公开书，加上自己收藏的私藏书。
- 游客只看到公开书。

过滤是**集合相减**而不是逐条判断：先取出当前访问者无权查看的私藏书集合，再从结果中排除。判断规则见 [书籍](书籍.md)。

### 5.2 上传

上传接受格式白名单内的文件。大文件走**分片上传**：初始化、逐片提交、最后合并。分片存在的原因是反向代理与浏览器都对单请求体积有限制，整本上传会在网络抖动时前功尽弃。

文件写入临时目录后立即做媒体分析，确定它是有效的电子书还是漫画容器，损坏或伪装的文件在此被拒绝。

游客能否上传由站点开关控制，默认**关闭**。

### 5.3 扫描与导入

扫描与导入是**两个分开的步骤**，中间留给人确认。这样设计是因为批量入库不可逆——直接扫完就导，一次误操作会污染整个书库。

**扫描**遍历导入目录，为每个文件登记一条候选记录，并计算内容指纹用于查重。候选记录有自己的状态：

| 状态 | 含义 |
|---|---|
| 新发现 | 刚扫描到，尚未判定 |
| 待导入 | 判定为新书，可以入库 |
| 已存在 | 书库中已有同一内容，跳过 |
| 丢弃 | 不是有效书籍或被排除 |
| 排队中 / 导入中 | 已提交导入 |
| 已导入 | 成功写入书库 |
| 失败 | 导入出错，保留错误信息 |

内容指纹**全局唯一**，同一个文件不会被登记两次。

**导入**把选中的候选写入书库，并按导入方式处理原文件：复制或移动。

**允许目录白名单**是硬约束：扫描路径必须落在白名单内，否则拒绝。这条防的是通过配置把扫描指向系统任意目录。

**自动监控**开启后，后台按固定间隔检查导入目录，发现新文件即走同一条扫描与导入链路。它不绕过白名单，也不绕过查重。

### 5.4 从 OPDS 导入

管理员可以登记外部 OPDS 服务器，浏览其目录并批量导入书籍。导入是异步的，可查询进度、查看失败清单并重试失败项。这与读者侧使用 OPDS 客户端订阅本站是**方向相反**的两件事，见 [外部访问](外部访问.md)。

### 5.5 浏览与筛选

书库列表支持按元数据维度筛选与排序。维度定义见 [元数据](元数据.md)；排序规则统一：评分、日期、丛书、入库时间默认从新到旧或从高到低，其余字段升序，不认识的排序字段回退为按入库顺序倒序。

分类维度可能有上百个取值，因此筛选入口支持搜索与分页，不一次性铺开。

### 5.6 回收站

删除书籍不立即销毁文件，而是移入回收站。回收站可以查看、统计占用空间并清空。**清空不可恢复**，界面必须明确提示。

回收站与上传临时目录都做**路径安全校验**：目标必须是绝对路径、不能是根目录、不能是符号链接指向别处，否则拒绝清理。这条防的是配置错误导致的误删。

### 5.7 计数

书库为每本书维护访问量、游客访问量与下载量，用于热门榜单。计数是**全站聚合**，与读者个人的阅读状态无关。演示模式下不写入计数。

## 7. 实现对照

### 7.1 数据存储

| 概念 | 存储 | 表与字段 |
|---|---|---|
| 书目与文件 | Calibre 书库 | 目录由 `with_library` 指定，默认 `/data/books/library/` |
| 扫描候选 | Talebook 业务库 | `scanfiles`，`ScanFile` 模型；`hash` 唯一 |
| 书籍扩展属性与计数 | Talebook 业务库 | `items`，`Item` 模型 |
| 外部 OPDS 源 | Talebook 业务库 | `opds_sources`，`OpdsSource` 模型 |
| 回收站 | 文件系统 | `<with_library>/.caltrash` 与 `upload_path` |

### 7.2 API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/library` | 书库浏览 |
| GET | `/api/search` | 关键词搜索 |
| GET | `/api/recent`、`/api/hot`、`/api/index` | 最近、热门、首页聚合 |
| GET | `/api/scopedbooks` | 当前读者的私藏书 |
| POST | `/api/book/upload` | 整本上传 |
| POST | `/api/book/upload/chunk`、`/api/book/upload/complete` | 分片上传与合并 |
| GET / POST | `/api/admin/scan/list`、`/run`、`/status`、`/mark`、`/delete` | 扫描 |
| GET / POST | `/api/admin/import/settings`、`/directory/check`、`/directory/list`、`/watch/status`、`/run`、`/status` | 导入与自动监控 |
| GET / POST | `/api/admin/opds/browse`、`/import`、`/import/status`、`/import/failed`、`/import/retry` | OPDS 批量导入 |
| GET / POST | `/api/admin/trash`、`/trash/size`、`/trash/clear` | 回收站 |

### 7.3 关键定义

| 符号 | 值 | 含义 |
|---|---|---|
| `SUPPORTED_EBOOK_FORMATS` | `azw3` `epub` `mobi` `pdf` `txt` `azw` `cbz` `zip` `cbr` `rar` | 上传与扫描共用的格式白名单 |
| `scan_upload_path` | `/data/books/imports/` | 默认扫描目录 |
| `import_allowed_roots` | `["/data/books/imports/"]` | 允许扫描的目录白名单 |
| `import_mode` | `copy` | 导入时复制而非移动 |
| `import_auto_watch_enabled` | `False` | 自动监控总开关 |
| `import_watch_interval_seconds` | `30` | 自动监控轮询间隔 |
| `import_scan_batch_size` | `500` | 单批扫描的文件数 |
| `ALLOW_GUEST_UPLOAD` | `False` | 游客上传开关 |
| `TrashManager.TRASH_PATH` | `<with_library>/.caltrash` | 回收站目录 |
| `ScanFile` 状态 | `new` `ready` `drop` `exist` `queued` `importing` `imported` `indexed` `downloading` `failed` `delete_failed` | 候选文件状态机 |
