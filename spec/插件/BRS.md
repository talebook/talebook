# BRS

## 1. 定义

BRS 是**一个独立部署的章评服务器**，Talebook 通过插件连接它：导入公开章评供读者阅读，并把本站的公开笔记同步回去。

它是当前唯一提供划线笔记类能力的内置插件，也是「本站是权威、外部只是来源」这条立场的参照实现。

**不是什么：**

- **不是笔记的权威存储。** 本站的笔记表才是权威，BRS 那边是副本，见 [划线笔记](../划线笔记.md)。
- **不是评价服务。** 外部评分与书评见 [评价源](评价源.md)。
- **不是 Talebook 自带的服务。** 它需要单独部署一个实例。

## 2. 使用场景

- **读者读到某一章**，想看看别人在这一章留了什么。
- **读者写了一条自认为有价值的公开笔记**，希望它能被更多人看到。
- **读者不希望自己的私密笔记外流**。
- **读者换了一个 BRS 实例**，希望重新指向新地址。

## 3. 功能

- 连接一个 BRS 实例。
- 导入公开章评。
- 把本站的公开笔记同步到 BRS。
- 连接归属读者本人。

## 4. 术语与界面用词

### 术语表

| 标准用词 | 英文 | 含义 | 示例 |
|---|---|---|---|
| BRS | BRS | 独立部署的章评服务器 | 默认实例地址是官方的那一台 |
| 章评 | chapter review | 针对某一章的评论 | 读到第 7 章时看到的其他读者留言 |
| 公开笔记 | public annotation | 本站中设为公开的笔记 | 只有公开的才会被同步出去 |
| 外部副本 | replica | 本站记录在 BRS 中的对应记录与同步状态 | 本站这条笔记在 BRS 的 id 与最后同步时间 |

### 操作按钮用词

| 界面用词 | 位置 | 行为 |
|---|---|---|
| BRS | 插件中心、侧栏 | 进入专属页 |
| 连接 | BRS 页 | 填写实例地址与凭据 |
| 导入章评 | BRS 页 | 拉取公开章评 |

## 5. 行为逻辑

### 5.1 两个方向

BRS 插件同时做两件事：

| 方向 | 能力 | 说明 |
|---|---|---|
| 拉入 | 章评 | 导入 BRS 上的公开章评 |
| 推出 | 笔记同步 | 把本站的公开笔记写到 BRS |

两个方向共享同一条连接，但规则不同：拉入是读者显式发起的运行，推出是**公开笔记变更后的自动异步扇出**。

### 5.2 私有笔记永不外发

这是最重要的一条：**只有公开笔记会被同步到 BRS，私有笔记永不入队**。笔记默认是私有的，读者必须显式设为公开才会外发。

从 BRS 导入的记录**不会再扇回 BRS**，避免回环；但仍会扇出到其他已注册来源。

### 5.3 本站仍是权威

导入的章评在本站成为权威记录，类型为章评。BRS 那边只登记外部身份与同步状态，**本站不保存「BRS 的章评」这种二等记录**。

冲突规则完全由 [划线笔记](../划线笔记.md) 定义：陈旧事件丢弃，本地修改受冲突保护，按来源清理只解除映射而不删正文。

### 5.4 连接归属读者

连接属于读者本人，每位读者可以指向不同的 BRS 实例。

### 5.5 与阅读器的关系

音文同步阅读器的默认服务地址与 BRS 的官方实例同域，但那是**两个不同的服务**，不要因为地址相似而混淆：一个渲染音文同步，一个存章评。见 [阅读器](../阅读器.md)。

## 7. 实现对照

### 7.1 数据存储

| 概念 | 存储 | 说明 |
|---|---|---|
| 连接与凭据 | `plugin_connections` / `plugin_secrets` | 所有者为用户 |
| 导入的章评 | `annotations` | 类型为 `chapter_comment` |
| 外部副本 | `annotation_sources` | `source_name` 标识 BRS |
| 运行记录 | `plugin_runs` / `plugin_run_items` | 导入审计 |

### 7.2 API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET / POST | `/api/plugins/connections` | 读者维护自己的连接 |
| POST | `/api/plugins/connections/<id>/(test\|preview\|run\|retry\|rollback)` | 五种动作 |
| GET / POST | `/api/book/<id>/annotations` | 导入后的章评按笔记接口读取 |

### 7.3 关键定义

| 符号 | 值 | 含义 |
|---|---|---|
| 插件 ID | `talebook.annotation.brs` | 稳定身份 |
| 分类 | `["annotations"]` | 单一分类 |
| 能力 | `annotations.chapter_reviews` `annotations.push` | 拉入与推出 |
| 连接归属 | `["user"]` | 读者本人 |
| `manage_route` | `/plugins/brs` | 专属管理页 |
| 笔记类型 | `chapter_comment` | 章评在本站的类型 |

### 7.4 代码落点

| 行为 | 文件与函数 |
|---|---|
| 插件实现 | `webserver/plugins/annotation/brs.py` |
| 注册 | `webserver/plugins/register.py` 的 `ANNOTATION_PROVIDERS` |
| 能力接口 | `webserver/plugins/runtime/interfaces.py` 的 `AnnotationProvider`、`ReviewProvider` |
| 异步扇出 | `webserver/services/annotation_sync.py` |
| 写入器 | `webserver/services/annotation_writer.py` |
| 前端页面 | `app/pages/plugins/brs.vue` |

### 7.5 界面文案

| i18n 分组 | 覆盖 |
|---|---|
| `brs.*` | BRS 专属页与连接配置 |
| `annotations.*` | 笔记页的来源筛选 |
