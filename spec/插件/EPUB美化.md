# EPUB美化

## 1. 定义

EPUB美化是**为书库中的 EPUB 重新整理目录、章节标题与正文排版，并生成新书的书籍工具**。它提供十二套排版预设、四种目录形式，以及字体、背景和段落等选项。

**不是什么：**

- 不覆盖原书；美化结果始终另存为新书。
- 不负责格式转换，只处理已有 EPUB 格式的书籍。
- 不做中文繁简转换或正文批量查找替换，见 [繁简转换](繁简转换.md) 与 [正文查找替换](正文查找替换.md)。

## 2. 使用场景

- 管理员为《红楼梦》选择古籍排版，生成竖排、右翻的阅读版本。
- 管理员希望整理一本小说的目录、章节标题与段落间距，同时保留原始版本。
- 读者先分析所选书籍的章节与目录结构，再由管理员执行美化。

## 3. 功能

- 分析 EPUB 的正文、目录、标题、标注与对话结构。
- 提供十二套预设和四种目录形式，包括竖排右翻的古籍排版。
- 调整系统字体、页面底色、背景纹理、段落缩进与间距。
- 选择目录层级、分栏、对话处理、章节标题拆分和标注样式。
- 按选项清理多余空行、前导空白、目录空白与冗余字符编码声明。
- 另存美化版，保留原书，并记录工具运行结果。

## 5. 行为逻辑

### 5.1 选择与分析

仅处理拥有 EPUB 格式的书籍。登录后的读者可以取得排版选项，并分析自己有权查看的书籍；分析不修改书籍。不可见的私有书籍不能用于分析或美化。没有 EPUB 格式时返回失败，不自动发起格式转换。

### 5.2 美化选项

管理员选择预设、目录形式及其他排版选项后执行美化。使用背景纹理时，纹理接管底色，不与页面底色重复叠加。标注处理开启后才校验和使用标注样式。非法预设、目录形式、纹理或排版参数会使任务失败。

### 5.3 权限与输出

正式执行需要管理员权限，并由 [插件平台](插件平台.md) 检查书籍写入授权。处理结果只能另存为新书，原书文件保持不变。新书默认在标题后追加「（美化版）」，管理员可以自定后缀；新书的收集者为执行操作的管理员。

### 5.4 执行结果与清理

成功后返回新书及美化统计，并保留插件运行记录。处理失败时返回错误；无论成功或失败，都清理此次操作的临时工作目录。

## 7. 实现对照

### 7.1 数据存储

| 概念 | 存储 | 说明 |
|---|---|---|
| 输入与输出 | Calibre 书库中的 EPUB | 读取原书，结果作为新书入库 |
| 操作临时文件 | 临时工作目录 | 请求结束时清理 |
| 运行记录 | 插件平台运行记录 | 记录书籍、预设、另存方式与执行结果 |

### 7.2 API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/plugins/tools/epub-beautify/presets` | 登录后读取预设、目录形式与纹理选项 |
| POST | `/api/plugins/tools/epub-beautify/preview` | 分析可见书籍，需要书籍读取授权 |
| POST | `/api/plugins/tools/epub-beautify/run` | 管理员执行美化，需要书籍写入授权 |
| GET | `/api/plugins/tools/books` | 查询可处理书籍 |

### 7.3 关键定义

| 符号 | 值 | 含义 |
|---|---|---|
| 插件 ID | `talebook.tool.epub-beautify` | 内置插件的稳定身份 |
| 分类 / 能力 | `integrations` / `integrations.tool` | 书籍处理工具 |
| 权限 | `books.read`、`books.write` | 分析与美化所需授权 |
| `manage_route` | `/plugins/epub-beautify` | 专属管理页 |
| `output_mode` | `new` | 始终另存为新书 |
| `EPUB_BEAUTIFY_SUFFIX` | `（美化版）` | 新书默认标题后缀 |
| 执行超时 | 分析 120 秒，美化 600 秒 | 插件运行时的调用期限 |

### 7.4 代码落点

| 行为 | 文件与函数 |
|---|---|
| 插件注册、选项与参数校验 | `webserver/plugins/tool/epub_beautify/provider.py` 的 `EpubBeautifyTransformPlugin` |
| EPUB 结构分析与美化 | `webserver/plugins/tool/epub_beautify/beautify_lib.py` 的 `analyze_epub`、`beautify` |
| 样式与纹理选项 | `webserver/plugins/tool/epub_beautify/styles/` |
| 接口、权限与另存新书 | `webserver/handlers/plugin_booktools.py` 的 `UserEpubBeautifyPresets`、`UserEpubBeautifyPreview`、`UserEpubBeautifyRun` |
| 前端页面 | `app/pages/plugins/epub-beautify.vue` |
| 接口回归 | `tests/test_texttools.py` 的 EPUB 美化测试 |
