# EPUB美化

## 1. 定义

EPUB 美化是**为站内 EPUB 书籍整理目录、章节标题与排版，并将结果另存为新书的书籍工具**。它提供独立工具页，原书的格式文件不被覆盖。

**不是什么：**

- 不是格式转换；TXT、PDF、漫画与 Kindle 格式不能直接美化。
- 不是有声书生成，见 [有声书](../有声书.md)。
- 不是原书元数据编辑，也不提供写回原书模式。
- 不是外部书库或语音服务，不需要外部账号。

## 2. 使用场景

- 管理员想为《西游记》选择统一的章节标题和正文排版，同时保留原版。
- 读者想先分析一本 EPUB 的目录、标题与脚注结构，再决定使用哪套样式。
- 管理员希望古籍采用竖排右翻样式，或为书籍选择目录形式和背景纹理。

## 3. 功能

- 搜索并选择已有 EPUB 书籍。
- 分析目录、正文标题、脚注引用与对白段落，不写入书库。
- 选择 12 套排版预设、4 种目录形式及内置背景纹理。
- 调整字体、配色、段落缩进或间距、目录深度和双栏目录；可选择清理、对白、标题拆分与脚注标记选项。
- 生成并入库一本美化后的新书，可自定义书名后缀。

## 4. 术语与界面用词

### 术语表

| 标准用词 | 英文 | 含义 | 示例 |
|---|---|---|---|
| 排版预设 | preset | 一组正文、标题与目录的样式选项 | 为《西游记》选择一套古籍排版预设 |
| 分析 | analysis | 读取书籍结构并展示统计，不修改文件 | 读者查看《西游记》的目录条目与标题数量 |
| 目录形式 | toc style | 新书目录的呈现方式 | 管理员切换《西游记》的目录形式 |
| 另存为新书 | save as new | 将美化结果作为独立书籍入库 | 管理员得到《西游记（美化版）》，原书仍保留 |

| 界面用词 | 位置 | 行为 |
|---|---|---|

## 5. 行为逻辑

### 5.1 对象与权限

只处理书库中可见且实际包含 EPUB 的书籍。已登录读者可以取得选项和分析可见书籍；执行美化并入库需要管理员权限。不可见与不存在的书籍返回相同错误，不泄露私有书籍信息。

工具属于实例级连接，不依赖个人外部账号；执行仍要求工具已启用并具备读写书籍的授权，见 [插件平台](插件平台.md)。

### 5.2 分析与执行

分析展示原书结构，不生成新书，也不改变原书。管理员可根据分析选择样式；分析不是执行的强制前置步骤。

执行校验所选预设、目录形式、纹理、配色、段距及脚注标记。非法选项或缺少 EPUB 时返回错误。字体选择兼容总体开关与正文、标题、楷体、代码字体的细分设置。背景纹理接管页面底色，避免重复叠加底色。

### 5.3 新书与原书

美化结果始终另存为新书，不支持覆盖原书。书名沿用原书并附加后缀；未填写后缀时使用「（美化版）」。新书走正常入库流程，关联执行者，遵循 [书籍](../书籍.md) 的可见范围规则。运行结束清理临时处理目录。

## 7. 实现对照

### 7.1 数据存储

| 概念 | 存储 | 说明 |
|---|---|---|
| 原书与美化结果 | Calibre 书库 | 读取原 EPUB，结果作为新书入库 |
| 插件定义与连接 | `plugin_definitions` / `plugin_connections` | 实例级连接 |

### 7.2 API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/plugins/tools/books` | 搜索可处理的书籍 |
| GET | `/api/plugins/tools/epub-beautify/presets` | 已登录读者取得预设、目录形式和纹理 |
| POST | `/api/plugins/tools/epub-beautify/preview` | 已登录读者分析可见 EPUB |
| POST | `/api/plugins/tools/epub-beautify/run` | 管理员美化并另存为新书 |

### 7.3 关键定义

| 符号 | 值 | 含义 |
|---|---|---|
| 插件 ID | `talebook.tool.epub-beautify` | 稳定身份 |
| 分类 / 能力 | `["integrations"]` / `["integrations.tool"]` | 书籍工具 |
| 权限 / 连接归属 | `books.read` `books.write` / `["instance"]` | 读写授权，实例连接 |
| `manage_route` | `/plugins/epub-beautify` | 专属工具页 |
| 支持格式 / 输出模式 | EPUB / `new` | 只生成新书 |
