# 评价源

## 1. 定义

评价源是**从外部服务查询或导入书籍评分、书评与章评的插件**。它回答的是「别人怎么看这本书」，而不是「这本书是什么」。

本篇是一份**目录**：逐个列出内置的评价源。它们没有各自的管理界面，因此合并成一篇。

**不是什么：**

- **不是书的评分字段。** Calibre 书目里的评分是站内的客观元数据，属于 [元数据](../元数据.md)。
- **不是读者自己的笔记。** 站内产生的高亮、笔记与章评属于 [划线笔记](../划线笔记.md)，本站是权威。
- **不是元数据检索。** 见 [元数据源](元数据源.md)，尽管有的插件两者都做。

## 2. 使用场景

- **读者想知道一本书在站外的口碑**，不必离开 Talebook 去搜。
- **管理员想给漫画配上专门的评分来源**，而不是用通用书评站。
- **读者从 Goodreads 或 StoryGraph 导出了多年的评分记录**，想导进来。
- **导入错了一批**，需要撤销。

## 3. 功能

- 按书查询外部评分与书评。
- 保留外部原始的评分尺度与样本数。
- 从导出文件批量导入评价。
- 导入可回滚。

## 4. 术语与界面用词

### 术语表

| 标准用词 | 英文 | 含义 | 示例 |
|---|---|---|---|
| 评价 | review | 外部服务对一本书的评分或评论 | 某站给《三体》4.8 分，来自 12 万人 |
| 评分尺度 | rating scale | 原始评分的满分与刻度 | 一个站是 5 分制，另一个是 10 分制，**不归一化** |
| 样本数 | sample count | 参与评分的人数 | 4.8 分但只有 3 个人评，与 12 万人评价值不同 |
| 章评 | chapter review | 针对某一章的评论 | 读到某章时看到其他读者的吐槽 |
| 评价导入 | review import | 从导出文件批量写入评价 | 导入 Goodreads 的 CSV |

### 操作按钮用词

| 界面用词 | 位置 | 行为 |
|---|---|---|
| 评价 | 插件中心页签 | 查看评价类插件 |
| 查询评价 | 书籍相关入口 | 发起外部评价查询 |
| 导入 / 撤销导入 | 插件连接页 | 批量导入与回滚 |

## 5. 行为逻辑

### 5.1 内置来源目录

| 插件 ID | 名称 | 能力 | 说明 |
|---|---|---|---|
| `talebook.review.hardcover` | Hardcover | `reviews.lookup` | 保留原始评分尺度、样本数、时间与来源链接 |
| `talebook.review.neodb` | NeoDB 评价 | `reviews.lookup` | 同上 |
| `talebook.review.google-books` | Google Books 评价 | `reviews.lookup` | 同上 |
| `talebook.review.bangumi` | Bangumi 漫画评价 | `reviews.lookup` | 面向漫画 |
| `talebook.review.anilist` | AniList 漫画评价 | `reviews.lookup` | 面向漫画 |
| `talebook.review.file-import` | 评价文件导入 | `reviews.import` | 导入 Goodreads、StoryGraph 或显式字段映射的 CSV / JSON |

另有兼作评价源的插件：

| 插件 ID | 名称 | 主归属 |
|---|---|---|
| `talebook.combo.open-library` | Open Library | 同时提供 `metadata.lookup`，见 [元数据源](元数据源.md) |
| `talebook.annotation.brs` | talebook-brs 章评服务器 | 章评来源，见 [BRS](BRS.md) |

### 5.2 不归一化评分

不同来源的评分尺度、样本规模与统计口径都不同，**平台不做归一化**。每条评价保留原始尺度、样本数、时间与来源链接，由读者自行判断。

把 5 分制和 10 分制强行折算成同一个数字会产生虚假的可比性——这是刻意不做的事。

### 5.3 漫画与图书分开

Bangumi 与 AniList 面向漫画，其余面向图书。这与书籍的内容形态分类对应，见 [书籍](../书籍.md)。

### 5.4 文件导入

评价文件导入是唯一提供 `reviews.import` 的插件，支持主流阅读社区的导出格式，也支持显式字段映射以适配未知格式。

**上传的文件正文加密保存，且不进入运行日志。** 导出文件包含读者多年的阅读记录，属于高敏感个人数据；把它写进可通过接口读取的运行日志等于泄漏。

导入按插件的标准运行模型执行，支持预览与回滚，见 [插件平台](插件平台.md)。

## 7. 实现对照

### 7.1 数据存储

| 概念 | 存储 | 说明 |
|---|---|---|
| 插件定义与连接 | `plugin_definitions` / `plugin_connections` | 见 [插件平台](插件平台.md) |
| 导入运行与明细 | `plugin_runs` / `plugin_run_items` | 支持回滚 |
| 外部记录映射 | `plugin_source_records` | 回滚依据 |
| 导入文件正文 | `plugin_runs.input_data` | 加密保存，**不进公开序列化** |

### 7.2 API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/admin/plugins/<key>/reviews/lookup` | 管理端评价查询 |
| POST | `/api/plugins/connections/<id>/(preview\|run\|rollback)` | 导入、预览与回滚 |

### 7.3 关键定义

| 符号 | 值 | 含义 |
|---|---|---|
| 能力 | `reviews.lookup` / `reviews.import` | 查询与导入 |
| `ENTITY_TYPES` 中的 | `review` | 运行实体类型 |
| 领域对象 | `Review` | 承载单条外部评价：原始评分尺度、样本数、时间与来源链接 |

### 7.4 代码落点

| 行为 | 文件与函数 |
|---|---|
| 插件实现 | `webserver/plugins/review/` |
| 注册 | `webserver/plugins/register.py` 的 `REVIEW_PROVIDERS` |
| 能力接口 | `webserver/plugins/runtime/interfaces.py` 的 `ReviewProvider` |
| 领域对象 | `webserver/plugins/runtime/domains.py` 的 `Review` |
| 写入 | `webserver/services/plugin_writers.py` |
