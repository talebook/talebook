# 发送到设备

## 1. 定义

发送到设备是**把书库里的一个格式文件投递到读者阅读设备的能力**。投递有两条物理路径：局域网直传到设备，或通过邮件发到设备的接收邮箱。

本篇是一份**目录**：逐个列出内置的推送插件。它们没有各自的管理界面——全部指向共享的「我的设备」页——因此合并成一篇。

**不是什么：**

- **不是设备本身。** 设备的名称、类型、地址、邮箱是读者的个人资产，属于 [用户](../用户.md)。
- **不是下载。** 下载是读者自己取文件，见 [书籍](../书籍.md)。
- **不是同步。** 阅读进度的跨设备同步走 WebDAV，见 [外部访问](../外部访问.md)。

## 2. 使用场景

- **读者手上是 Kindle**，希望在网页上点一下书就出现在设备里。
- **读者用多看**，设备和服务器在同一个局域网里，希望不绕外网。
- **读者有好几台设备**，希望一次推给多台。
- **读者推的是 EPUB 但设备只认 MOBI**，希望先转再推。
- **管理员不想让游客用推送**。

## 3. 功能

- 把指定格式发送到一台或多台设备。
- 发送到读者配置的接收邮箱。
- 按设备类型自动选择投递方式。
- 批量多设备推送。
- 推送邮件的标题与正文模板可配置。

## 5. 行为逻辑

### 5.1 内置推送插件目录

全部七个插件的能力相同（`integrations.push`），管理入口全部指向「我的设备」页，连接归属**读者本人**。

| 插件 ID | 名称 | 设备类型 | 投递方式 |
|---|---|---|---|
| `talebook.push.kindle` | Kindle 邮箱推送 | `kindle` | 通过站点的邮件服务发到 Kindle 邮箱 |
| `talebook.push.duokan` | 多看阅读 | `duokan` | WiFi 传书，局域网直传 |
| `talebook.push.boox` | 文石 BOOX | `boox` | 推送到设备的推送库 |
| `talebook.push.hanwang` | 汉王电纸书 | `hanwang` | WiFi 传书，局域网直传 |
| `talebook.push.ireader` | 掌阅 iReader | `ireader` | 推送到设备 |
| `talebook.push.dangdang` | 当当阅读器 | `dangdang` | 推送到设备 |
| `talebook.push.purelibro` | PureLibro | `purelibro` | 推送到设备 |

### 5.2 设备类型是分派键

读者添加设备时选择类型，投递时**按设备类型查找对应的推送插件**。设备类型取自插件 ID 的最后一段，因此新增一个推送插件就自动多一种设备类型，不需要额外注册表。

设备数据本身（名称、地址、端口、协议、邮箱）存在读者的设备列表里，**推送插件只读它**，不拥有它。

### 5.3 两条投递路径

| 路径 | 依赖 | 失败常见原因 |
|---|---|---|
| 局域网直传 | 设备与服务器在同一网络，设备已开启接收 | 设备休眠、IP 变了、未开启传书模式 |
| 邮箱投递 | 站点已配置可用的邮件服务 | 邮件服务未配置、发件人未被设备白名单接受 |

每种设备有默认端口，读者通常不需要改。邮箱投递依赖 [系统设置](../系统设置.md) 里的邮件配置；配错时的典型症状是推送静默失败，因此设置页提供发信测试。

### 5.4 权限

推送是八个能力权限之一。游客能否推送由站点的访客开关单独控制，**默认允许**。

推送的是书籍的格式文件，因此仍受书籍可见性约束——推不了看不到的书。

### 5.5 格式与转换

推送使用书库里已有的格式文件。设备不支持的格式需要**先转换再推送**，转换是书籍的能力，见 [书籍](../书籍.md)。推送本身不隐式转换。

### 5.6 批量推送

一次操作可以选择多台设备。每台设备独立投递，**一台失败不影响其余**，结果逐台反馈。

### 5.7 邮件模板

推送邮件的标题与正文是站点级模板，支持站点名称、书名与站点地址的占位替换。

## 7. 实现对照

### 7.1 数据存储

| 概念 | 表与字段 | 说明 |
|---|---|---|
| 设备 | `devices`，`Device` 模型 | `name` `device_type` `ip` `port` `schema` `mailbox`，外键指向 `readers.id` |
| 推送邮箱 | `Reader.extra["kindle_email"]` | 与设备列表并存的独立邮箱 |
| 插件连接 | `plugin_connections` | 所有者为用户 |

### 7.2 API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET / POST | `/api/user/devices` | 设备增删改查 |
| POST | `/api/book/<id>/send_to_device` | 投递到设备 |
| POST | `/api/book/<id>/mailto` | 投递到推送邮箱 |
| GET / POST | `/api/admin/plugins/preferences` | 共享设备设置 |

### 7.3 关键定义

| 符号 | 值 | 含义 |
|---|---|---|
| 能力 | `integrations.push` | 七个插件共同声明 |
| 分类 | `["integrations"]` | manifest 分类 |
| 连接归属 | `["user"]` | 设备属于读者本人 |
| `Device.device_type` 默认 | `duokan` | 新设备默认类型 |
| `Device.port` / `schema` 默认 | `12121` / `http` | 局域网投递地址 |
| `PUSH_PROVIDERS_BY_DEVICE` | 以 `ui.device_type` 为键 | 分派表 |
| `manage_route` | `/me/devices` | 七个插件共享的管理页 |
| `ALLOW_GUEST_PUSH` | `True` | 游客推送开关 |
| `push_title` / `push_content` | 模板串 | 支持 `%(site_title)s` `%(title)s` `%(site_url)s` |

### 7.4 代码落点

| 行为 | 文件与函数 |
|---|---|
| 插件实现 | `webserver/plugins/push/`，共同基类在 `base.py` |
| 设备类型默认值 | `base.py` 中取插件 ID 的最后一段 |
| 分派表 | `webserver/plugins/register.py` 的 `PUSH_PROVIDERS_BY_DEVICE` |
| 能力接口 | `webserver/plugins/runtime/interfaces.py` 的 `PushProvider`，领域对象 `PushReceipt` |
| 投递入口 | `webserver/handlers/book.py` 的 `BookSendToDevice`、`BookSendToMail` |
| 邮件服务 | `webserver/services/mail.py` |
