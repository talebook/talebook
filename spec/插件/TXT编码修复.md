# TXT编码修复

## 1. 定义

TXT编码修复是**检测 TXT 电子书的字符编码并把它修复为 UTF-8 的书籍工具**。它不仅识别常见编码，还能识别并**反向恢复乱码**——即已经被错误解码过一次、存成了看似正常但内容是乱码的文件。

它是三个书籍工具中唯一支持**自动触发**的：新书入库时可以自动检测并修复。

**不是什么：**

- **不是繁简转换。** 见 [繁简转换](繁简转换.md)。
- **不是正文内容修改。** 见 [正文查找替换](正文查找替换.md)。
- **不是格式转换。** 见 [书籍](../书籍.md)。

## 2. 使用场景

- **从网上下的 TXT 打开全是问号或方块**，读者想修好。
- **文件在别的软件里被错误转码过一次**，成了「锟斤拷」型乱码。
- **管理员常年批量导入 TXT**，希望入库时自动修。
- **有些文件根本救不回来**，希望系统明确告知而不是产出更糟的结果。

## 3. 功能

- 检测 TXT 文件的原始编码并给出置信度。
- 识别乱码并尝试反向恢复。
- 修复为 UTF-8，写回原书或另存为新书。
- 新书入库时自动触发（可配置）。
- 明确报告无法恢复的情况。

## 4. 术语与界面用词

### 术语表

| 标准用词 | 英文 | 含义 | 示例 |
|---|---|---|---|
| 编码检测 | encoding detection | 判断文件的原始字符编码 | 判定这个文件是 GBK 而不是 UTF-8 |
| 置信度 | confidence | 编码判定的把握程度 | 高置信度可直接修，低置信度需人工确认 |
| 乱码 | mojibake | 用错误编码解码后又保存下来的文本 | 「一二三」变成一串看不懂的字符 |
| 反转恢复 | reversal | 沿着错误的解码链反推回原始字节再正确解码 | 把被 GBK 解成 Latin-1 的内容还原 |
| 不可恢复 | unrecoverable | 信息已丢失，无法还原 | 明确告知失败，不产出假结果 |
| 自动触发 | auto trigger | 新书入库时自动执行 | 导入的 TXT 自动修好再入库 |

| 界面用词 | 位置 | 行为 |
|---|---|---|
| TXT编码修复 | 插件中心、侧栏 | 进入工具页 |

## 5. 行为逻辑

### 5.1 分析先于执行

工具采用**两段式**：先分析，再执行。分析返回判定的编码、置信度、是否乱码、是否不可恢复，**不产生任何写入**。

### 5.2 多路判定

编码判定不依赖单一手段，而是综合几条线索：字节序标记、候选编码打分、统计式检测的投票结果，以及乱码反转链的尝试。

单一手段不可靠——中文编码之间的字节分布高度重叠，统计检测经常在 GBK 与 Big5 之间摇摆，因此需要多路交叉验证。

### 5.3 明确拒绝不可恢复的情况

当判定为不可恢复，或者内容是乱码但找不到可用的反转链时，工具**明确报告失败而不产出结果**。

这条是刻意的：编码修复一旦猜错，产出的是「看起来像正常文本但内容全错」的文件，比原来的乱码更难发现。宁可失败也不产出假结果。

### 5.4 落地方式

修复结果写回原书或另存为新书，与其他书籍工具一致。

### 5.5 自动触发

它是三个工具中唯一声明支持自动触发的。开启后，新导入的 TXT 会自动走一次检测与修复。触发策略在插件配置中设置。

自动触发**不改变判定标准**：不可恢复的文件仍然只报告不修改。

### 5.6 支持格式

只处理 TXT。EPUB 内部已有编码声明，不属于本工具范围。

## 7. 实现对照

### 7.1 数据存储

| 概念 | 存储 | 说明 |
|---|---|---|
| 处理对象 | Calibre 书库的 TXT 文件 | 直接读写 |
| 触发配置 | `plugin_installations.config` | 含 `trigger` 配置项 |

### 7.2 API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/plugins/tools/txt-fixer/analyze` | 分析编码 |
| POST | `/api/plugins/tools/txt-fixer/run` | 执行修复 |
| GET | `/api/plugins/tools/books` | 可处理的书籍列表 |

### 7.3 关键定义

| 符号 | 值 | 含义 |
|---|---|---|
| 插件 ID | `talebook.tool.txt-fixer` | 稳定身份 |
| 分类 / 能力 | `["integrations"]` / `["integrations.tool"]` | 书籍工具 |
| 权限 | `books.read` `books.write` | 声明式授权 |
| 连接归属 | `["instance"]` | 无外部账号 |
| `manage_route` | `/plugins/txt-fixer` | 专属管理页 |
| `supports_auto_trigger` | `true` | **三个工具中唯一支持** |
| 分析报告字段 | `encoding` `confidence` `mojibake` `garbage` `unrecoverable` | 判定结果 |
| 支持格式 | TXT | 其余不处理 |

### 7.4 代码落点

| 行为 | 文件与函数 |
|---|---|
| 插件实现 | `webserver/plugins/tool/txt_fixer/` |
| 检测与修复算法 | 同目录 `transform.py`：字节序标记、候选编码打分、统计检测投票、乱码反转链 |
| Provider 与触发配置 | 同目录 `provider.py` |
| 接口 | `webserver/handlers/plugin_booktools.py` 的 `UserTxtFixerAnalyze`、`UserTxtFixerRun` |
| 前端页面 | `app/pages/plugins/txt-fixer.vue` |
