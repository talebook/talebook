# 插件平台

## 1. 定义

插件平台是**Talebook 接入外部世界的统一机制**。任何需要和站外服务打交道的能力——查元数据、搜在线书、导笔记、推书到设备——都以插件的形式接入，共用同一套启停、配置、凭据、授权、执行与审计模型。

平台的核心结论可以压成一句：**插件是产品与生命周期单元，能力是业务发现边界，Provider 是实现角色，连接是配置与凭据的所有权边界，运行是审计边界。** 这五个概念对应五组不同的数据，混用任意两个都会写出错误的代码。

**不是什么：**

- **不是可下载的第三方扩展。** 当前全部插件内置随版本发布，没有插件市场，没有上传安装。
- **不是通用脚本入口。** 不存在「执行任意动作」的万能接口，能标准化的行为必须走类型化能力。
- **不是站点设置。** 插件启停在插件中心，站点设置见 [系统设置](../系统设置.md)。唯一的交叉是 OPDS 对外服务开关长在 OPDS 插件卡片上。

## 2. 使用场景

- **管理员想给站点加豆瓣元数据补全**，需要知道开哪个开关。
- **管理员不想让某个境外服务被调用**，需要能停用它。
- **读者想接入自己的微信读书账号**，但不希望管理员看到自己的凭据。
- **一次导入出了问题**，需要知道导了多少条、失败在哪、能不能撤销。
- **某个外部服务挂了**，希望不要拖垮整站。
- **开发者要加一个新来源**，需要知道该实现哪个接口。

## 3. 功能

- 管理员启停内置插件，配置实例级连接与凭据。
- 读者配置属于自己的连接与凭据。
- 按能力发现可用连接并调用。
- 五种标准动作：测试、预览、执行、重试、回滚。
- 完整的运行记录与逐条明细。
- 凭据加密存储，公开接口永不返回密文。
- 权限声明与授权记录。
- 连接健康状态。
- 外部请求限流与超时保护。

## 4. 术语与界面用词

### 术语表

| 标准用词 | 英文 | 含义 | 示例 |
|---|---|---|---|
| 插件 | plugin | 有独立身份、版本和实例级启停状态的产品能力单元 | 「豆瓣」是一个插件，「微信读书」是另一个 |
| 插件 ID | plugin id | 跨版本稳定的全局身份，改展示名不改 ID | `talebook.meta.douban-v2`；界面名改成「豆瓣读书」也不影响 |
| 能力 | capability | 平台能发现并调用的一类标准业务契约 | 元数据检索业务只问「谁提供 `metadata.lookup`」，不认识具体插件 |
| Provider | provider | 一个插件对一组能力的具体实现角色 | 微信读书用一个 Provider 实现了八种能力 |
| 综合插件 | combo | 同时提供多个业务类别能力、无法归入单一类别的插件 | 微信读书同时做搜索、书架、统计、元数据与笔记导入 |
| 额外功能 | extra feature | 无法表达为标准能力、但仍显式声明并授权的专属功能 | 微信读书的社区与推荐 |
| 插件定义 | definition | 某个插件版本声明的身份、能力、权限与配置契约 | 一份经过校验的 manifest |
| 启用状态 | activation | 管理员决定该插件是否可供本实例使用 | 停用豆瓣后，元数据检索不再调它 |
| 连接 | connection | 插件与一个所有者之间的配置绑定 | 「我的微信读书账号」是一条用户连接 |
| 实例连接 | instance connection | 管理员维护、全站共享的连接 | 管理员配的 Legado 书源库 |
| 用户连接 | user connection | 某位读者维护、只代表他自己的连接 | 每位读者各自的微信读书凭据 |
| 运行 | run | 一次经过授权的插件调用及其可审计结果 | 「昨天 14:03 的那次导入，拉了 512 条，写入 480 条」 |
| 连接健康 | health | 连接最近一次调用反映的可用性 | 凭据过期后健康变为异常，但插件仍是启用状态 |

|---|---|---|
| 插件 | 侧栏导航、管理后台 | 进入插件中心 |

| 预览 | 连接配置 | 试跑但不写入 |

## 5. 行为逻辑

### 5.1 五个概念不能互相推导

必须避免的等同关系：

- **插件 ≠ Provider。** 一个综合插件可以由**一个** Provider 实现多种能力。
- **启用 ≠ 已配置 ≠ 健康。** 三者是三张表上的三个独立状态。插件启用了但没配凭据，或配了但凭据过期，都是常见状态。
- **代码目录分组 ≠ 协议分类。** 目录用 `combo`/`source`/`meta`/`review`/`annotation`/`tool`/`push`，manifest 分类用 `metadata`/`reviews`/`annotations`/`sources`/`integrations`，且分类是**多值**的。
- **用户连接 ≠ 租户配置。** 所有权主体是具体的读者，不是组织。
- **额外功能 ≠ 通用执行入口。**

### 5.2 启用与安装

**内置插件没有「安装」这个产品动作。** 全部注册插件在首次访问时一次性物化，只在物化那一刻读取各插件声明的初始启用状态。管理员的职责是**启停与全局策略**，不是安装。

每个插件在全实例只有**一份安装记录**，被所有能力入口复用。

### 5.3 连接与所有权

连接只有两种所有者：**实例**（管理员维护、全站共享）与**用户**（读者各自维护）。插件在 manifest 里声明自己支持哪一种。

**管理员不能管理其他读者的连接。** 这是隐私边界——微信读书凭据代表读者的个人账号。

连接的**查询键是角色标识**，不是名称。名称是可以随时修改、可以国际化的展示文案，**绝不能拿来定位连接**。

停用插件时连接**继续保留**，重新启用后不必重配。

### 5.4 凭据

凭据加密存储，使用独立的加密密钥。公开序列化**故意不返回密文**，只给掩码与最后轮换时间。

密钥为空时，运行时只接受**非默认**的会话密钥作为兼容密钥材料——用默认值加密等于没加密。

### 5.5 五种动作

| 动作 | 语义 |
|---|---|
| 测试 | 只验证连通性与凭据，不读写业务数据 |
| 预览 | 试跑并返回将要发生什么，不写入 |
| 执行 | 正式运行并写入 |
| 重试 | 基于上次运行重跑 |
| 回滚 | 撤销某次运行的写入 |

**预览先于执行**是平台的基本姿态：批量写入不可逆，读者和管理员应当先看到将要发生什么。

### 5.6 运行与审计

每次动作都产生一条持久的运行记录，带状态机与计数：拉取、写入、更新、跳过、失败、冲突。终态有四种：成功、失败、部分成功、已回滚。

逐条明细单独记录，可以定位到某一条外部记录为什么失败。

**私有输入不进公开接口。** 例如读者上传的导出文件属于可重试的私有输入，故意从运行的公开序列化中排除，防止个人数据经运行接口泄漏。

### 5.7 稳定性隔离

外部服务不可靠，因此平台施加三层保护：

- **专用线程池**执行外部 I/O，不占用请求线程。
- **按插件与目标主机排队**，防止单个上游打满并发拖垮整站。
- **超时与重试**统一由运行时施加，插件自己不需要实现。

### 5.8 契约校验

插件声明的每个能力都必须是平台已知的，并且必须实现对应接口。声明未知能力或未实现接口的插件会被**拒绝加载**，而不是运行时报错。

manifest 的字段集合是封闭的：必填字段缺一不可，可选字段受类型约束，**未知键一律拒绝**——防止协议被悄悄扩写。

## 7. 实现对照

### 7.1 数据存储

| 概念 | 表 | 关键约束 |
|---|---|---|
| 插件定义 | `plugin_definitions` | `(plugin_key, version)` 唯一，保存完整 manifest |
| 安装与启用 | `plugin_installations` | `plugin_key` **全实例唯一** |
| 授权 | `plugin_permissions` | `(installation_id, permission, scope)` 唯一 |
| 连接 | `plugin_connections` | `(installation_id, owner_type, owner_id, role)` 唯一；`role` 是查询键 |
| 凭据 | `plugin_secrets` | 密文与密钥标识；公开序列化不含密文 |
| 运行 | `plugin_runs` | 状态机、计数、游标、私有输入 |
| 运行明细 | `plugin_run_items` | `(run_id, external_id)` 唯一 |
| 外部记录映射 | `plugin_source_records` | `(connection_id, entity_type, external_id)` 唯一 |
| 书籍匹配候选 | `plugin_entity_matches` | `(connection_id, source_type, external_id)` 唯一 |

### 7.3 关键定义

| 符号 | 值 | 含义 |
|---|---|---|
| `PROTOCOL_VERSION` | `talebook.plugin/v1` | 协议版本 |
| `CATEGORIES` | `metadata` `reviews` `annotations` `sources` `integrations` | manifest 分类，**多值** |
| `RUNTIME_KINDS` | `builtin` `file` `http` `managed_process` | 运行形态；当前全部为 `builtin` |
| `ACTIONS` | `test` `preview` `run` `retry` `rollback` | 五种动作 |
| `CONNECTION_OWNERS` | `instance` `user` | 连接所有者 |
| `ENTITY_TYPES` | `metadata` `annotation` `review` `book_source` | 运行实体类型 |
| `TERMINAL_STATUSES` | `succeeded` `failed` `partial` `rolled_back` | 运行终态 |
| `DEFAULT_COUNTS` | `fetched` `written` `updated` `skipped` `failed` `conflicts` | 计数字段 |
| `REQUIRED_MANIFEST_FIELDS` | 16 项 | 必填字段，缺一不可 |
| `OPTIONAL_MANIFEST_FIELDS` | `description` `ui` `download_mode` `extra_features` | 可选字段；其余未知键拒绝 |
| `PLUGIN_ID_RE` | `^[a-z0-9]+(?:[.-][a-z0-9]+)+$` | 插件 ID 格式 |
| `CAPABILITY_RE` | `^[a-z][a-z0-9_]*\.[a-z][a-z0-9_]*$` | 能力名为「域.动作」两段式 |
| `DEFAULT_CONNECTION_ROLE` / `BUILTIN_CONNECTION_ROLE` | `default` / `builtin` | 连接角色 |
| `_PLUGIN_IO_EXECUTOR` | `max_workers=16` | 外部 I/O 线程池 |
| `PLUGIN_SECRET_KEY` | `""` | 凭据加密密钥 |
