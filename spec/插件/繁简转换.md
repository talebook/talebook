# 繁简转换

## 1. 定义

繁简转换是**把书籍正文在简体中文与繁体中文之间转换的书籍工具**。它不只做字形替换，还支持地区词汇差异（例如「软件」与「軟體」），并覆盖八个转换方向。

**不是什么：**

- **不是翻译。** 只在中文的字形与地区用词之间转换。
- **不是编码修复。** 见 [TXT编码修复](TXT编码修复.md)。
- **不是正文内容修改。** 见 [正文查找替换](正文查找替换.md)。

## 2. 使用场景

- **读者下到一本繁体书**，看着费劲，想转成简体。
- **读者偏好台湾用词**，希望不只是字形转换，词汇也要地道。
- **书里有大量网络用语**，标准词表转不准，希望用增强词表。
- **读者想保留原书**，把转换结果另存。

## 3. 功能

- 八个方向的繁简转换。
- 可选增强词表。
- 作用于 EPUB 与 TXT。
- 写回原书或另存为新书。
- 转换后同步调整书籍的语言标识。

## 4. 术语与界面用词

### 术语表

| 标准用词 | 英文 | 含义 | 示例 |
|---|---|---|---|
| 转换方向 | direction | 源与目标的字形及地区组合 | `s2twp` 是简体转台湾正体并替换台湾用词 |
| 地区用词 | regional phrases | 同一事物在不同地区的不同说法 | 简体「软件」对应台湾「軟體」 |
| 增强词表 | extra phrases | 覆盖标准词表未收录用语的补充词表 | 处理网络用语与新词 |
| 语言标识 | language tag | 书籍元数据中的语言字段 | 转成繁体后语言标识从 `zh` 变成 `zht` |

### 操作按钮用词

| 界面用词 | 位置 | 行为 |
|---|---|---|
| 繁简转换 | 插件中心、侧栏 | 进入工具页 |
| 转换方向 | 工具页 | 选择八个方向之一 |
| 执行 | 工具页 | 正式转换 |

## 5. 行为逻辑

### 5.1 八个方向

方向同时表达**字形**与**地区用词**两个维度，因此不是简单的「简转繁 / 繁转简」两个选项：

| 方向 | 含义 |
|---|---|
| `t2s` | 繁体转简体 |
| `tw2s` | 台湾正体转简体 |
| `tw2sp` | 台湾正体转简体，并转换地区用词 |
| `s2t` | 简体转繁体 |
| `s2tw` | 简体转台湾正体 |
| `s2twp` | 简体转台湾正体，并转换地区用词 |
| `t2tw` | 繁体转台湾正体 |
| `tw2t` | 台湾正体转繁体 |

带 `p` 的方向额外做**地区用词替换**，不带的只做字形转换。传入列表之外的方向直接拒绝。

### 5.2 增强词表的适用范围

可选的增强词表**只在转向简体的方向上生效**（`t2s` 与 `tw2s`）。其他方向不适用，勾选无效。

### 5.3 语言标识同步

转换后书籍的语言标识随之更新：转向简体标为简体中文，转向繁体或台湾正体标为繁体中文。**内容变了元数据就要跟着变**，否则按语言筛选会得到错误结果。

这是本工具唯一会触及元数据的地方，规则见 [元数据](../元数据.md)。

### 5.4 落地方式

结果写回原书或另存为新书，与其他书籍工具一致。另存为新书在「同时保留简繁两个版本」时很有用。

### 5.5 支持格式

只处理 EPUB 与 TXT。

## 7. 实现对照

### 7.1 数据存储

| 概念 | 存储 | 说明 |
|---|---|---|
| 处理对象 | Calibre 书库的 EPUB / TXT | 直接读写 |
| 语言字段 | Calibre 书库 | 转换后同步更新 |

### 7.2 API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/plugins/tools/zh-converter/run` | 执行转换 |
| GET | `/api/plugins/tools/books` | 可处理的书籍列表 |

### 7.3 关键定义

| 符号 | 值 | 含义 |
|---|---|---|
| 插件 ID | `talebook.tool.zh-converter` | 稳定身份 |
| 分类 / 能力 | `["integrations"]` / `["integrations.tool"]` | 书籍工具 |
| `ZH_DIRECTIONS` | `t2s` `tw2s` `tw2sp` `s2t` `s2tw` `s2twp` `t2tw` `tw2t` | 八个方向，其余拒绝 |
| 语言映射 | `t2s` → `zh`；`s2t` / `s2tw` / `s2twp` → `zht` | 转换后的语言标识 |
| 增强词表 | `use_a5`，仅 `t2s` / `tw2s` 生效 | 补充词表开关 |
| 权限 | `books.read` `books.write` | 声明式授权 |
| 连接归属 | `["instance"]` | 无外部账号 |
| `manage_route` | `/plugins/zh-converter` | 专属管理页 |
