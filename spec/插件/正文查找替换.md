# 正文查找替换

## 1. 定义

正文查找替换是**对书库中书籍的正文执行批量查找替换的书籍工具**。支持普通文本与正则，作用于 EPUB 与 TXT，结果可以写回原书，也可以另存为一本新书。

它属于「书籍工具」这一类能力：不与外部服务通信，**只处理站内已有的文件**。

**不是什么：**

- **不是元数据编辑。** 改书名、作者见 [元数据](../元数据.md)。
- **不是格式转换。** 见 [书籍](../书籍.md)。
- **不是编码修复。** 见 [TXT编码修复](TXT编码修复.md)。
- **不是繁简转换。** 见 [繁简转换](繁简转换.md)。

## 2. 使用场景

- **一本书正文里夹满了来源站的广告行**，读者想一次清掉。
- **书里的章节标题格式混乱**，希望用正则统一。
- **读者不确定替换规则对不对**，想先看看会改成什么样。
- **读者不敢直接改原书**，希望结果另存为新书。

## 3. 功能

- 选择书库中的一本书。
- 输入查找与替换内容，可选正则。
- 预览替换结果。
- 执行替换，写回原书或另存为新书。

## 4. 术语与界面用词

### 术语表

| 标准用词 | 英文 | 含义 | 示例 |
|---|---|---|---|
| 书籍工具 | book tool | 对站内书籍文件执行预览或转换处理的能力 | 查找替换、编码修复、繁简转换三件套 |
| 预览 | preview | 试跑并展示将要发生的改动，不写入 | 看到「将替换 37 处」及前后对照 |
| 写回原书 | write back | 把结果覆盖到原书的对应格式 | 原书的 TXT 被替换后的内容取代 |
| 另存为新书 | save as new | 把结果作为一本新书入库 | 原书保留，新书是清理过的版本 |

### 操作按钮用词

| 界面用词 | 位置 | 行为 |
|---|---|---|
| 正文查找替换 | 插件中心、侧栏 | 进入工具页 |
| 预览 | 工具页 | 试跑不写入 |
| 执行 | 工具页 | 正式替换 |

## 5. 行为逻辑

### 5.1 预览先于执行

工具采用**两段式**：先预览，再执行。预览返回将要发生的改动数量与样例，**不产生任何写入**。

这是书籍工具类能力的共同姿态——批量修改正文不可逆，读者应当先看到结果。

### 5.2 两种落地方式

| 方式 | 结果 |
|---|---|
| 写回原书 | 覆盖原书的对应格式文件 |
| 另存为新书 | 原书不动，结果作为新书入库 |

另存为新书走正常入库链路，因此新书同样有自己的元数据与可见范围。

### 5.3 支持的格式

只处理 EPUB 与 TXT——这两种是可解析的文本容器。PDF、漫画容器与 Kindle 格式不在范围内。

### 5.4 权限

工具声明的权限是读写书籍。实际操作仍受书籍所有权约束：改一本书需要编辑权限且是书主，管理员例外，见 [书籍](../书籍.md)。

连接归属是**实例**——工具本身没有外部账号，不需要按读者隔离配置。

## 7. 实现对照

### 7.1 数据存储

| 概念 | 存储 | 说明 |
|---|---|---|
| 处理对象 | Calibre 书库的格式文件 | 直接读写 |
| 插件定义与连接 | `plugin_definitions` / `plugin_connections` | 所有者为实例 |

### 7.2 API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/plugins/tools/books` | 可处理的书籍列表 |
| POST | `/api/plugins/tools/text-replace/preview` | 预览 |
| POST | `/api/plugins/tools/text-replace/run` | 执行 |
| GET / POST | `/api/plugins/tools/book-actions` | 管理端的书籍工具动作 |

### 7.3 关键定义

| 符号 | 值 | 含义 |
|---|---|---|
| 插件 ID | `talebook.tool.text-replace` | 稳定身份 |
| 名称 | 正文查找替换 | **不叫「文本替换」** |
| 分类 / 能力 | `["integrations"]` / `["integrations.tool"]` | 书籍工具 |
| 权限 | `books.read` `books.write` | 声明式授权 |
| 连接归属 | `["instance"]` | 无外部账号 |
| `manage_route` | `/plugins/text-replace` | 专属管理页 |
| 支持格式 | EPUB、TXT | 其余不处理 |

### 7.4 代码落点

| 行为 | 文件与函数 |
|---|---|
| 插件实现 | `webserver/plugins/tool/text_replace/` |
| 共同基类与 manifest 工厂 | `webserver/plugins/tool/base.py` 的 `_manifest()` |
| EPUB 处理 | `webserver/plugins/tool/epub.py` |
| 能力接口 | `webserver/plugins/runtime/interfaces.py` 的 `TransformProvider`，领域对象 `ToolInput` / `ToolReport` / `ToolOutput` |
| 接口 | `webserver/handlers/plugin_booktools.py` 的 `UserTextReplacePreview`、`UserTextReplaceRun` |
| 前端页面 | `app/pages/plugins/text-replace.vue` |
