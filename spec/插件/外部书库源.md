# 外部书库源

## 1. 定义

外部书库源是**从站外发现并取得书籍文件的插件**。它们把别处的书搬进本站：别人的自托管书库、公版电子书站、一个 WebDAV 目录，或者服务器上的一个本地文件夹。

本篇是一份**目录**：逐个列出内置的书库源。它们没有各自的管理界面，因此合并成一篇。

方向是理解这一篇的关键：**从外部往站内取书**。同名协议的相反方向——把本站藏书暴露给外部客户端——见 [外部访问](../外部访问.md)。

**不是什么：**

- **不是对外服务。** OPDS 目录服务与 WebDAV 挂载是本站对外暴露藏书，见 [外部访问](../外部访问.md)。
- **不是在线书源。** 抓取网文站正文的规则引擎见 [Legado](Legado.md) 与 [网络书库](../网络书库.md)。
- **不是元数据检索。** 见 [元数据源](元数据源.md)。

## 2. 使用场景

- **朋友有一台 Komga**，读者想从那里把书搬过来。
- **管理员想批量收一批公版书**，希望有合法开放的来源。
- **服务器上有一个目录在持续收到新文件**，希望自动发现。
- **书放在网盘的 WebDAV 目录里**，希望不用手工下载再上传。
- **管理员担心误入侵权内容**，希望来源只提供明确开放的文件。

## 3. 功能

- 浏览外部书库的目录结构。
- 按关键词搜索外部书库。
- 取得书籍文件进入待审。
- 增量发现：只处理新出现的内容。
- 按连接配置地址与凭据。

## 4. 术语与界面用词

### 术语表

| 标准用词 | 英文 | 含义 | 示例 |
|---|---|---|---|
| 外部书库源 | external source | 从站外发现并取得书籍文件的插件 | 连上朋友的 Komga，把他的书搬过来 |
| 发现 | discover | 列出外部有哪些可取得的内容 | 扫一遍 WebDAV 目录，列出新增的 EPUB |
| 取得 | acquire | 把外部文件下载进本站待审 | 选中 20 本，下载进导入目录 |
| 增量发现 | incremental discovery | 只处理上次之后新出现的内容 | 第二次扫描只报新增的 3 本，不重复报旧的 |
| 连接预设 | connection preset | 为某个已知产品预置好协议参数的连接模板 | Kavita 与 Komga 都走 OPDS，但各自有预设 |
| 待审 | pending review | 取得后尚未正式入库的状态 | 下载完先进导入目录，确认后才入库 |

### 5.2 OPDS 预设的共性

Kavita、Komga、BookLore 三者都是自托管书库产品，对外都讲 OPDS。它们**不是三套独立实现**，而是在通用 OPDS 适配之上的连接预设——预置好各自的地址形态与认证方式，让管理员不必手填协议细节。

### 5.3 增量发现

WebDAV 与 Watch Folder 面向「持续有新文件进来」的场景，因此按增量工作：

- **WebDAV** 按扩展名筛选后记录已见条目。
- **Watch Folder** 用内容指纹判重，文件改名不会被当成新书。

增量状态保存在连接的游标上，见 [插件平台](插件平台.md)。

Watch Folder 受**允许目录白名单**约束，不能指向任意路径，见 [书库](../书库.md)。

### 5.4 合法性边界

公版书来源刻意选择了明确授权的站点。Internet Archive 适配**只让明确开放的文件进入待审**——该站同时托管受限借阅内容，不加区分地取用会引入侵权风险。

番茄小说下载器**依赖外部下载器与上游在线服务**，不是自包含实现，可用性由上游决定。

### 5.5 取得后进待审

取得的文件进入导入待审流程，不直接入库，与本地扫描共用同一条链路与同一套查重、媒体分析规则，见 [书库](../书库.md)。这保证了无论书从哪来，入库标准一致。

## 7. 实现对照

### 7.1 数据存储

| 概念 | 存储 | 说明 |
|---|---|---|
| 外部 OPDS 源 | `opds_sources`，`OpdsSource` 模型 | 管理员保存的 OPDS 服务器 |
| 连接与游标 | `plugin_connections` | `cursor` 字段承载增量状态 |
| 发现与取得记录 | `plugin_runs` / `plugin_run_items` / `plugin_source_records` | 见 [插件平台](插件平台.md) |

### 7.2 API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/admin/plugins/<key>/source/search` | 管理端按插件搜索 |
| POST | `/api/admin/plugins/connections/<id>/(test\|preview\|run)` | 测试、预览与执行 |
| GET / POST | `/api/admin/opds/browse`、`/import`、`/import/status`、`/import/failed`、`/import/retry` | OPDS 批量导入 |
| GET / POST | `/api/admin/opds/sources` | 外部 OPDS 源管理 |

### 7.3 关键定义

| 符号 | 值 | 含义 |
|---|---|---|
| 能力 | `sources.browse` `sources.search` `sources.acquire` | 书源能力命名空间 |
| `download_mode` | `single_book` 等 | 取得粒度 |
| `ENTITY_TYPES` 中的 | `book_source` | 运行实体类型 |
| `import_allowed_roots` | `["/data/books/imports/"]` | Watch Folder 的目录白名单 |
| `OPDS_ENABLED` | `True` | **由 OPDS 插件卡片切换的对外服务开关**，不是书源能力 |
