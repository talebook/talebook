# Legado

## 1. 定义

Legado 是**在线书源的管理与规则引擎**。它接受兼容 Legado 3.0 格式的书源 JSON，按规则从各个小说站抓取搜索结果、目录与正文，并维护这些书源的健康状态。

本篇是**管理员视角**：导入书源、体检、启停、治理规则边界。读者视角的搜索、试读与保存见 [网络书库](../网络书库.md)。

**不是什么：**

- **不是读者的搜索入口。** 见 [网络书库](../网络书库.md)。
- **不是外部书库接入。** Kavita、Komga、WebDAV 这类见 [外部书库源](外部书库源.md)。
- **不是 Legado 客户端的服务端实现。** 本站只复用它的书源规则格式，不提供其同步或客户端协议。
- **不追求与 Android 客户端功能对等。** 见下文的规则支持边界。

## 2. 使用场景

- **管理员拿到一份书源订阅地址**，想批量导进来。
- **管理员从别处复制了一段书源 JSON**，或有一个本地文件。
- **用了一阵子后一半书源失效了**，希望系统能自己发现并停用。
- **某个书源规则可疑**，管理员想单独测一下。
- **书源越攒越多**，管理员想按分组和状态筛选、批量启停。
- **管理员想导出自己整理好的书源**，备份或分享。

## 3. 功能

- 从订阅地址、JSON 文本、本地文件或内置示例导入书源。
- 导出书源。
- 分页浏览、按名称搜索、按有效性筛选。
- 批量启停与删除。
- 单个书源测试。
- 后台全量体检并自动停用失效源。
- 一键清理失效书源。
- 兼作网文元数据来源。

## 5. 行为逻辑

### 5.1 书源的存储形态

每个书源保存**完整的原始 JSON**，同时抽取出若干索引字段用于检索与排序：名称、地址、分组、类型、权重、备注。索引字段是**从原始 JSON 同步出来的派生数据**，不独立编辑——改规则就改 JSON。

**书源地址是去重键。** 导入时按地址更新已有记录，不产生重复。地址长度有上限，这是为了让它能建索引。

### 5.2 导入

支持四种导入方式：订阅地址、JSON 文本、本地 JSON 文件、内置示例。JSON 可以是**单个对象或数组**，两种都接受。

大体积 JSON 是常态——一份订阅可能有几千个书源，因此导入按流式处理，不整体载入内存。

**新导入的书源先进入「待检查」状态**，而不是直接可用。它还没被验证过，直接投入搜索会拖慢每一次查询。

### 5.3 体检与自动停用

体检是后台批量任务，可查询进度。每个书源得到一个状态与说明：

| 状态 | 含义 |
|---|---|
| 通过 | 可用 |
| 失败 | 不可用，**自动停用** |
| 待检查 | 刚导入，尚未验证 |
| 未知 | 无法判定 |

**失败即自动停用**是刻意的：小说站挂掉是常态，失效源留在搜索池里只会让每次搜索都多等一个超时。

体检还会给书源打上标签，说明失败原因的类别（例如域名解析失败）。

### 5.4 权重自调整

搜索命中的书源权重上升，从而更容易进入「近期可用」范围。这是一个自我优化的排序，**不需要管理员维护优先级**。

### 5.5 规则支持的精确边界

Talebook 的引擎**刻意不与 Android 客户端功能对等**。目标是服务端可安全执行的子集：

**支持**：字段尾部与地址顶层的**受限纯计算** JavaScript 片段，在沙箱中执行，**不提供网络访问与浏览器副作用**。

**不支持**：内联脚本块、双花括号脚本、客户端的网络请求扩展、页面渲染内核、设备环境访问。

不支持的理由写在设计目标里：服务端不应承接**服务端请求伪造、登录态劫持与浏览器内核**的风险。一个能任意联网的书源规则等于把服务器交给了规则作者。

引擎规模也是刻意不对等的——规则解析、地址处理与脚本扩展的实现量都远小于客户端，因为覆盖的是真实使用中高价值的那部分规则语法，而不是全量复刻。

### 5.6 并发与重试

抓取面向不可靠的外部站点，因此引擎内置并发控制与失败重试，并按目标主机排队，避免对单站造成压力或被封禁。

### 5.7 兼作元数据来源

Legado 除了书源能力，还声明了元数据检索能力，用于给网文补全书名、作者、简介与封面——常规书目站查不到网文。见 [元数据源](元数据源.md)。

## 7. 实现对照

### 7.1 数据存储

| 概念 | 表与字段 | 说明 |
|---|---|---|
| 书源 | `book_sources`，`BookSourceModel` | `raw` 保存完整 Legado JSON |
| 索引字段 | `name` `url` `group` `source_type` `weight` `comment` | 由 `apply_raw()` 从 JSON 同步 |
| 体检状态 | `check_status` `check_message` `check_tags` `last_check_time` `last_check_ok` | 空字符串表示未体检 |
| 启用 | `enabled` | 体检失败自动置假 |

### 7.2 API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/admin/booksource/list` | 分页、搜索、按有效性筛选 |
| GET / POST / PUT / DELETE | `/api/admin/booksource` | 单个书源增删改查 |
| POST | `/api/admin/booksource/import` | 导入 |
| GET | `/api/admin/booksource/export` | 导出 |
| POST | `/api/admin/booksource/seed` | 导入内置示例 |
| POST | `/api/admin/booksource/toggle` | 批量启停 |
| POST | `/api/admin/booksource/test` | 单源测试 |
| POST | `/api/admin/booksource/check` | 发起全量体检 |
| GET | `/api/admin/booksource/check/status` | 体检进度 |
| POST | `/api/admin/booksource/clean-invalid` | 清理失效 |

### 7.3 关键定义

| 符号 | 值 | 含义 |
|---|---|---|
| 插件 ID | `talebook.source.legado` | 稳定身份 |
| 能力 | `sources.browse` `sources.search` `sources.acquire` `metadata.lookup` | 兼作元数据源 |
| 连接归属 | `["instance"]` | 管理员维护，全站共享 |
| `manage_route` | `/plugins/legado` | 专属管理页 |
| `BookSourceModel.url` 长度 | `767` | `767 × 4 = 3068 ≤ 3072`，MySQL utf8mb4 索引上限 |
| `check_status` | `ok` `failed` `pending` `unknown` | 空表示未体检 |
| `BOOKSOURCE_METADATA_TOP_K` | `10` | 兼作元数据源时取前 N 个书源 |
| `BOOKSOURCE_METADATA_WORKERS` | `6` | 元数据检索并发 |
| 受限脚本 | 仅字段尾部与地址顶层的纯计算片段 | 无网络、无浏览器副作用 |
