# 微信读书

## 1. 定义

微信读书是**把读者的微信读书账号接进 Talebook 的综合插件**。它一个插件覆盖八种能力：搜索、书架、阅读统计、笔记导入、社区、推荐、元数据检索——因此归不进任何单一类别，是平台上「综合插件」的典型样本。

它的连接**只属于读者本人**：每位读者用自己的凭据，管理员看不到也管不了别人的连接。

**不是什么：**

- **不是书籍下载来源。** 它不把微信读书的书搬进本站书库。
- **不是笔记的权威存储。** 导入的划线在本站成为权威记录，见 [划线笔记](../划线笔记.md)。
- **不是实例级配置。** 没有全站共享的微信读书账号。

## 2. 使用场景

- **读者在微信读书里积累了几年的划线**，想导进本站统一管理和备份。
- **读者想在 Talebook 里看到自己微信读书的书架与阅读时长**。
- **读者导错了一批笔记**，想撤销这次导入。
- **读者担心凭据泄漏**，想确认管理员看不到。
- **读者在本站写的公开笔记**，希望能同步回去。

## 3. 功能

- 以读者自己的凭据连接微信读书。
- 搜索微信读书内容。
- 浏览书架、阅读统计、社区与推荐。
- 导入划线笔记到本站。
- 兼作元数据检索来源。
- 导入可预览、可重试、可回滚。

## 5. 行为逻辑

### 5.1 凭据只属于读者

连接归属是**用户**，不存在实例级共享连接。理由很直接：凭据代表读者的个人微信读书账号，共享等于共享账号。

凭据加密存储，接口**永不返回密文**，只给掩码。管理员在管理端看不到、也不能操作其他读者的连接。

### 5.2 八种能力，一个 Provider

一个 Provider 实现八种能力，这正是「插件不等于 Provider」的例证：

| 能力 | 用途 |
|---|---|
| 搜索 | 搜微信读书内容 |
| 书目 | 读取书籍信息 |
| 书架 | 读取读者的书架 |
| 统计 | 读取阅读时长等数据 |
| 社区 | 社区内容 |
| 推荐 | 推荐内容 |
| 元数据检索 | 兼作元数据来源 |
| 划线导入 | 导入笔记 |

前六项属于**额外功能**——它们没有对应的平台标准能力，因此必须在 manifest 中显式声明并单独授权，而不是塞进一个万能接口。

### 5.3 划线导入

导入走平台的标准运行模型：预览、执行、重试、回滚。

导入的划线在本站成为**权威记录**，并登记一条指向微信读书的外部副本。此后的规则完全由 [划线笔记](../划线笔记.md) 定义：

- 私有记录不外发。
- 从微信读书导入的记录**不会再扇回微信读书**，避免回环。
- 本站改过正文的记录受冲突保护，后续导入不覆盖它。
- 陈旧事件被丢弃。

### 5.4 失败与重试

外部服务不稳定，因此连接配置里包含重试次数与退避时间。运行时另有统一的超时与主机级排队，见 [插件平台](插件平台.md)。

凭据过期时连接健康变为异常，但插件仍是启用状态——**启用、已配置、健康是三个独立状态**。

### 5.5 数据留存

该插件的数据策略声明为**保存完整正文、由用户控制留存**——导入的划线正文确实落在本站。读者可以删除自己的记录，见 [划线笔记](../划线笔记.md)。

## 7. 实现对照

### 7.1 数据存储

| 概念 | 存储 | 说明 |
|---|---|---|
| 连接与凭据 | `plugin_connections` / `plugin_secrets` | 所有者为用户；密文不出接口 |
| 导入运行 | `plugin_runs` / `plugin_run_items` | 支持回滚 |
| 外部记录映射 | `plugin_source_records` | 回滚依据 |
| 导入的划线 | `annotations` / `annotation_sources` | 本站为权威，外部只存映射 |

### 7.2 API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET / POST | `/api/plugins/connections` | 读者维护自己的连接 |
| POST | `/api/plugins/connections/<id>/(test\|preview\|run\|retry\|rollback)` | 五种动作 |
| POST | `/api/plugins/<key>/features/<feature>` | 额外功能调用，`<key>` 为 `talebook.combo.weread` |
| GET | `/api/plugins/runs`、`/runs/<id>` | 个人运行记录 |

### 7.3 关键定义

| 符号 | 值 | 含义 |
|---|---|---|
| 插件 ID | `talebook.combo.weread` | 稳定身份 |
| 分类 | `["integrations", "metadata", "annotations"]` | **多值分类**的典型 |
| 能力 | `integrations.search` `integrations.books` `integrations.shelf` `integrations.statistics` `integrations.community` `integrations.recommendations` `metadata.lookup` `annotations.import` | 八种 |
| 连接归属 | `["user"]` | **不存在实例级共享连接** |
| 动作 | `test` `preview` `run` `retry` `rollback` | 全部五种 |
| 权限 | `books.read` `books.write` `profile.read` `annotations.write` | 声明式授权 |
| 数据策略 | 保存完整正文，留存由用户控制 | manifest 声明 |
| `manage_route` | `/plugins/weread` | 专属管理页 |
| 配置项 | `max_retries`（0–5）、`backoff_seconds` | 重试策略 |
