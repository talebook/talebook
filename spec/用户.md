# 用户

## 1. 定义

用户是**一个能登录 Talebook 并拥有自己数据的账号**。它承载三类互相独立的东西：身份（谁）、能力权限（能做什么）、个人资产（设备、消息、阅读数据）。

Talebook 是自托管的私人书库，因此用户体系的默认姿态是**封闭**：注册默认关闭，账号由部署者创建。

**不是什么：**

- **不是读者与书的关系。** 收藏、书架、进度属于 [阅读状态](阅读状态.md)。
- **不是书籍所有权本身。** 谁拥有一本书记录在书籍的收藏者字段上，见 [书籍](书籍.md)；本篇只定义权限规则。
- **不是外部账号。** 微信读书、BRS 等外部服务的账号是插件连接，见 [插件平台](插件/插件平台.md)。

## 2. 使用场景

- **部署者第一次访问站点**，需要创建管理员账号并完成初始化。
- **管理员想让家人也能用**，给他开一个账号，但不允许下载。
- **访客没有账号**，想先随便看看有哪些书。
- **部署者要把站点公开演示**，但不能让任何人改数据。
- **读者忘了密码**，需要重置。
- **读者有一台 Kindle 和一台多看**，想把书直接推过去。

## 3. 功能

- 登录、登出、注册（站点开关）。
- 邮箱激活。
- 重置密码、修改个人资料。
- 社交账号登录（QQ、GitHub）。
- 邀请码访问控制。
- 管理员批量管理用户与权限。
- 管理自己的阅读设备。
- 查看站内消息。
- 演示模式下的共享只读账号。

## 4. 术语与界面用词

### 术语表

| 标准用词 | 英文 | 含义 | 示例 |
|---|---|---|---|
| 用户 | reader | 一个账号 | 管理员为家人开的账号「alice」 |
| 管理员 | admin | 拥有全站管理权的账号 | 能看到全部私藏书、管理其他用户与站点设置 |
| 游客 | guest | 未登录的访问者 | 没登录也能浏览公开书，能否阅读下载由站点开关决定 |
| 能力权限 | permission | 八个可独立开关的能力位 | 给家人账号关掉「下载」，他仍能在线阅读 |
| 默认权限 | default permission | 权限位未显式设置时的取值 | 权限为空的账号按默认全部允许处理 |
| 邀请模式 | invite mode | 访问站点前需先输入邀请码 | 私人站点开启后，陌生人打不开首页 |
| 激活 | activation | 通过邮件链接确认账号可用 | 注册后收到邮件，点链接才能在线阅读 |
| 演示模式 | demo mode | 单账号只读体验模式 | 公开演示站的 demo 账号可以点遍所有界面，但改不动数据 |
| 设备 | device | 用户用来接收书籍的阅读硬件或邮箱 | 一台多看（局域网 IP + 端口）和一个 Kindle 邮箱 |

### 操作按钮用词

| 界面用词 | 位置 | 行为 |
|---|---|---|
| 登录 / 退出 | 头部、登录页 | 建立或结束会话 |
| 注册 | 登录页 | 创建账号，站点关闭时不展示 |
| 我的账户 | 个人页 | 管理资料与密码 |
| 我的设备 | 个人页 | 管理接收书籍的设备 |
| 用户管理 | 管理后台 | 增删账号、调整权限 |

## 5. 行为逻辑

### 5.1 三层权限，互不推导

| 层 | 表达什么 | 取值 |
|---|---|---|
| 身份 | 你是谁 | 游客 / 登录用户 / 管理员 |
| 能力权限 | 你能做什么 | 八个开关 |
| 资源所有权 | 这东西是不是你的 | 书籍的收藏者 |

三层**不能互相推导**：管理员是身份层的超级用户，能力权限是按账号的可撤销开关，所有权只对私藏可见性和书籍写操作生效。判断一个操作是否允许，必须明确它落在哪一层——大多数写操作同时要求「有能力权限」**且**「是所有者或管理员」。

### 5.2 八个能力开关

| 能力 | 说明 |
|---|---|
| 登录 | 能否建立会话 |
| 浏览 | 能否看到书目 |
| 阅读 | 能否在线阅读 |
| 下载 | 能否下载文件 |
| 上传 | 能否上传书籍 |
| 编辑 | 能否修改元数据 |
| 删除 | 能否删除书籍 |
| 推送 | 能否发送到设备 |

权限以「显式允许 / 显式禁止 / 未设置」三态存储，而不是布尔值。**未设置时采用默认允许**——因此「权限为空」等于「全部按默认放行」，不等于「什么都不能做」。这条最容易误读：新建账号如果不配权限，它是全开的。

站点有一个默认权限配置，决定新账号的初始权限。

### 5.3 游客

游客能做什么由四个站点开关控制，与能力权限体系**平行**：在线阅读、下载、推送默认允许，上传默认禁止。

游客永远看不到私藏书。

### 5.4 邀请模式

开启后，未持邀请码的访问者无法进入站点。通过验证后凭证有效期 **7 天**。这是给「私人图书馆」场景的整站门禁，与账号体系无关。

### 5.5 注册与激活

注册默认**关闭**。开启后：

- 用户名长度 2–20，只能是小写字母开头的字母、数字与下划线。
- 密码长度 8–20。
- 邮箱必须合法。

注册后账号处于**未激活**状态，系统发送激活邮件；未激活的账号即使有阅读权限也不能在线阅读，提示先激活。

### 5.6 密码

密码有两代算法并存，靠存储标记区分。**登录时用正确的旧密码会自动升级到新算法**，密码错误则不升级——这样存量账号无需强制重置就能完成迁移。

激活码始终使用旧算法计算，与密码算法无关，因此账号升级后已发出的激活链接仍然有效。

### 5.7 个人扩展数据的容量上限

用户的个人扩展数据（推送邮箱、登录 IP、各类历史）整体存在一个字段里，**上限 32 KB**。接近上限时系统按比例截断各类历史记录。

由此产生一条必须知道的口径：**阅读历史等记录是有损的**，不能当审计使用。详见 [阅读状态](阅读状态.md)。

### 5.8 设备

设备是用户自己维护的投递目标，一个账号可以有多台。每台设备记录名称、类型、局域网地址与端口、接收邮箱。

设备**只是数据**。实际怎么投递由推送插件按设备类型决定，见 [发送到设备](插件/发送到设备.md)。另有一个独立于设备列表的推送邮箱，存在用户扩展数据里。

### 5.9 演示模式

演示模式为公开演示站提供一个**共享只读账号**：

- 开启后只有配置的演示账号与数据库中真实的管理员可以登录。
- 演示账号首次登录自动开户，可以进入管理界面体验交互，但**改不动业务数据**。
- 演示账号与游客的阅读、下载权限**统一对齐站点访客开关**，忽略该账号自身的权限位——因为它默认权限全开，用于伪装管理员体验。
- 真实管理员不受任何限制，可以持续维护演示站。

演示模式下被抑制的写入：登录时间与登录 IP、站内消息、阅读历史、访问与下载计数、阅读状态。

### 5.10 站内消息

消息是系统给用户的通知，带已读标记。读取即清空。演示模式下既不写入也不返回。

## 7. 实现对照

### 7.1 数据存储

| 概念 | 表与字段 | 说明 |
|---|---|---|
| 账号 | `readers`，`Reader` 模型 | 同时承载本地账号与社交账号 |
| 能力权限 | `Reader.permission` | 字符串，小写为允许、大写为禁止、缺失为默认 |
| 管理员 / 激活 | `Reader.admin` / `Reader.active` | 布尔 |
| 个人扩展数据 | `Reader.extra` | JSON，含 `kindle_email`、`login_ip`、各类 `*_history` |
| 设备 | `devices`，`Device` 模型 | 外键指向 `readers.id` |
| 消息 | `messages`，`Message` 模型 | `unread` 标记，`data` 存正文 |

### 7.2 API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/welcome` | 站点与安装状态，前端据此判断是否跳安装 |
| GET | `/api/user/info` | 当前登录用户信息 |
| POST | `/api/user/sign_in`、`/sign_up`、`/sign_out` | 登录、注册、登出 |
| POST | `/api/user/update`、`/api/user/reset` | 修改资料、重置密码 |
| GET | `/api/active/<username>/<code>` | 邮件激活链接 |
| POST | `/api/user/active/send` | 重发激活邮件 |
| GET | `/api/user/messages` | 站内消息 |
| GET / POST | `/api/user/devices` | 设备管理 |
| GET / POST | `/api/admin/users`、`/api/admin/users/batch` | 管理员用户管理 |

### 7.3 关键定义

| 符号 | 值 | 含义 |
|---|---|---|
| 能力字符集 | `delprsuv` | 删除、编辑、登录、推送、阅读、保存、上传、浏览 |
| `Reader.RE_USERNAME` | `[a-z][a-z0-9_]*` | 用户名格式 |
| 用户名长度 | 2–20 | 注册校验 |
| 密码长度 | 8–20 | 注册校验 |
| `Reader.SQLITE_MAX_LENGTH` | `32 * 1024` | 扩展数据字节上限 |
| `Reader.OVERSIZE_SHRINK_RATE` | `0.8` | 超限时的截断比率 |
| 密码算法标记 | `salt == "__bcrypt__"` | 标记使用新算法 |
| 邀请凭证有效期 | `7 * 86400` | 秒 |
| `cookie_expire` | `7 * 86400` | 会话有效期 |
| `ALLOW_REGISTER` | `False` | 注册开关 |
| `DEFAULT_USER_PERMISSION` | `''` | 新账号初始权限，空即全部默认允许 |
| `ALLOW_GUEST_READ` / `PUSH` / `DOWNLOAD` | `True` | 游客开关 |
| `ALLOW_GUEST_UPLOAD` | `False` | 游客上传开关 |
| `INVITE_MODE` / `INVITE_CODE` | `False` / `love` | 邀请门禁 |
| `DEMO_MODE` / `DEMO_USERNAME` | `False` / `demo` | 演示模式 |
| `Device.device_type` 默认 | `duokan` | 设备类型 |
| `Device.port` / `schema` 默认 | `12121` / `http` | 局域网投递地址 |
