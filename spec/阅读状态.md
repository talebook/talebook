# 阅读状态

## 1. 定义

阅读状态是**一位读者与一本书之间的关系**——他有没有收藏它、有没有把它放进书架、读到什么程度、读到哪一页。它是每个读者的私有数据，同一本书对不同读者呈现不同的阅读状态。

阅读状态由四组**彼此独立、互不覆盖**的语义构成：收藏、书架、已读状态、阅读进度。一本书可以同时是「已收藏 + 在书架上 + 已读完」。

**不是什么：**

- **不是书的属性。** 评分、标签这类描述书本身的信息属于 [元数据](元数据.md)，对所有读者相同。
- **不是站点访问统计。** 访问量与下载量是全站聚合计数，属于 [书籍](书籍.md)。
- **不是收听进度。** 有声书的播放位置独立存储，属于 [有声书](有声书.md)。
- **不是阅读器本身。** 怎么打开、用哪个阅读器渲染属于 [阅读器](阅读器.md)；本篇只管读到哪里这件事被如何记录。
- **不是分组清单。** 书架是一个开关，不是可命名的多个清单。

## 2. 使用场景

- **读者刷书库时看到一本感兴趣的书**，还不想立刻读，先放进书架。
- **读者想快速看出哪些书读过**，不必点进详情。
- **读者在手机上读到一半，换到电脑继续**，希望从上次的位置接着读。
- **读者想回顾今年读完了多少本书**。
- **读者想找回几天前翻过但忘了书名的书**。
- **读者读完一本书**，希望它离开「在读」列表，进入「读完」。

## 3. 功能

- 收藏与取消收藏，查看收藏列表。
- 加入书架与移出书架，查看书架列表。
- 在未读、在读、读完三态之间切换。
- 查看在读列表与读完列表。
- 自动记录并恢复阅读进度。
- 查看个人阅读统计：累计与本月的在读、读完数量。
- 查看阅读历史。
- 在书籍卡片与列表上直接看到已读状态角标。

## 4. 术语与界面用词

### 术语表

| 标准用词 | 英文 | 含义 | 示例 |
|---|---|---|---|
| 阅读状态 | reading state | 一位读者与一本书关系的总和 | 读者甲对《三体》：已收藏、在书架上、在读、读到第 7 章；同一本书对读者乙可能是「未读」 |
| 收藏 | favorite | 读者标记为喜欢的书 | 读完《三体》觉得好，点收藏，之后从「我的收藏」随时找回 |
| 书架 | shelf | 读者打算读的书。**产品上叫「书架」，不叫「待读」** | 刷书库时看到《人类简史》，现在没空，先加入书架，周末再读 |
| 已读状态 | read state | 未读、在读、读完三态之一 | 打开书前是「未读」，点「设为在读」变「在读」，读完点「标记读完」变「已读」 |
| 阅读进度 | progress | 读者在书内的位置 | 图文书记住停在第三章某段；漫画记住停在第 42 页、完成度 35% |
| 阅读历史 | history | 读者近期访问过的书的记录 | 「前几天翻过一本讲宋代生活的书，忘了书名」——去阅读历史里翻回来 |

### 操作按钮用词

| 界面用词 | 位置 | 行为 |
|---|---|---|
| 我的书架 | 侧栏导航、个人页 | 进入书架列表 |
| 加入书架 / 移出书架 | 书籍详情 | 切换书架状态 |
| 收藏 / 取消收藏 | 书籍详情、书籍卡片 | 切换收藏状态 |
| 未读 / 在读 / 已读 | 书籍卡片角标、状态选择 | 展示当前已读状态 |
| 设为在读 | 书籍详情 | 已读状态置为在读 |
| 标记读完 | 书籍详情 | 已读状态置为读完 |
| 取消阅读 | 书籍详情 | 已读状态回到未读 |

「已读」与「读完」指同一个状态：角标等紧凑位置用「已读」，动作与完成提示用「读完」。

## 5. 行为逻辑

### 5.1 四组语义互不覆盖

收藏、书架、已读状态、阅读进度各自独立，修改任何一个都不影响其余三个。它们共同挂在「读者 + 书」这一对关系上，读者第一次对一本书做任何操作时该关系才被创建。

每一组都带自己的时间戳，在该组被修改时刷新。

### 5.2 收藏与书架

两者都是**开关**，只有「是」和「否」。切换时记录切换时间。

**书架就是产品命名。** 它在界面和接口上一律叫「书架」，不使用「待读」「想看」等说法。当前一位读者对一本书只能表达一种「打算读」的意图；如果将来产品需要「书架」和「待读」同时存在，必须引入独立的状态，**不能靠名称区分同一个开关**。

书架为空时提示「书架上还没有书，快去加入吧！」。

### 5.3 已读状态

三态且仅三态：

| 状态 | 含义 | 界面用词 |
|---|---|---|
| 未读 | 默认状态 | 未读 |
| 在读 | 读者正在读 | 在读 |
| 读完 | 读者已读完 | 已读 / 读完 |

状态是**读者显式设置的**，系统不因为读者打开过一本书就自动改成在读。提交三态之外的值返回「阅读状态参数错误」。

每次状态变更刷新变更时间。这个时间是**最后一次变更的时间**，不是「开始读的时间」，也不是「读完的时间」——把一本读完的书改回在读，它的时间随之更新。

在读列表与读完列表分别按该时间从新到旧排列。

### 5.4 阅读进度

进度是一个**结构化位置**，由阅读器决定内容，系统不解释其语义，只负责存取和限额。

不同阅读器写入不同形态的进度，靠进度内的类型标记区分：

- **图文书**由阅读器写入其自有的位置表示。
- **漫画**写入页码型进度：当前页标识、页序号、完成百分比、是否读到最后一页。页序号会被**夹取到合法范围**，超出末页按末页处理。

进度上限 **8 KB**，超出返回「阅读进度数据过大」。这条限制存在的原因是进度按书按人存储，无节制的进度体积会拖垮列表查询与备份。

**进度不改变已读状态。** 读到最后一页也不会自动标记为读完——是否读完由读者决定。

**文字阅读进度与有声书收听进度完全独立。** 边听边读不会覆盖文字位置；读者要显式操作才能把收听位置转为阅读位置。

### 5.5 阅读统计

统计只覆盖当前登录读者，四个数字：

- 累计在读、累计读完。
- 本月在读、本月读完——按已读状态的**最后变更时间**落在当前自然月计算。

由此产生一条必须知道的口径：一本书改了状态就会离开原来月份的统计，**月度数字不是「当月新增」的严格累计**。

统计页同时展示本月读完与当前在读的书目，各最多 **12** 本，按状态变更时间从新到旧。

### 5.6 阅读历史

历史按行为类型分别记录，每条包含书籍标识、书名和时间。

**去重**：新记录写入前只检查最近 **12** 条，更早的重复不会被发现。这是为查询成本做的取舍，因此历史中可能出现同一本书的多条远距离记录。

**容量**：每类历史最多 **60** 条。历史存放在读者的扩展数据中，而扩展数据整体有 **32 KB** 上限；接近上限时系统会按比例截断各类历史。

由此产生一条必须知道的口径：**阅读历史是有损的，不能当作完整审计记录使用。**

**不记录历史的情况**：未登录访问者，以及演示模式下的受限账号。

### 5.7 列表上的状态展示

书库、搜索结果、分类页等任何书籍列表在返回时都会附带当前读者对每本书的阅读状态，前端据此渲染已读角标与收藏、书架按钮的选中态。读者未登录时全部按默认值（未收藏、不在书架、未读）呈现。

### 5.8 演示模式

演示模式下的受限账号可以浏览和阅读，但**不写入任何阅读状态、历史与计数**，以免共享账号互相污染数据。

## 6. 关联实体

- [书籍](书籍.md)——阅读状态挂在书上；站点级的访问与下载计数在那里。
- [用户](用户.md)——阅读状态的归属主体；演示模式的受限规则在那里。
- [阅读器](阅读器.md)——进度的生产者与消费者，进度的内部结构由它定义。
- [有声书](有声书.md)——收听进度独立存储，与本篇的阅读进度互不覆盖。
- [元数据](元数据.md)——书的评分是客观元数据，与读者的已读状态无关。
- [书库](书库.md)——书架、收藏、在读、读完都是书库的一种筛选视图。

## 7. 实现对照

### 7.1 数据存储

| 概念 | 表与字段 | 说明 |
|---|---|---|
| 阅读状态 | `reading_state`，`ReadingState` 模型 | 复合主键 `(book_id, reader_id)` |
| 收藏 | `favorite` / `favorite_date` | `set_favorite()` / `is_favorite()` |
| 书架 | `wants` / `wants_date` | `set_wants()` / `is_wants()`。**字段名 `wants` 是历史包袱，产品用词为「书架」** |
| 已读状态 | `read_state` / `read_date` | `set_read_state()` 只接受 `[0, 1, 2]` |
| 阅读进度 | `progress` / `progress_update_time` | JSON；图文书与漫画共用，靠内部 `kind` 区分 |
| 在线读 / 下载标记 | `online_read` / `download` | 布尔位 |
| 阅读历史 | `Reader.extra` 的 `*_history` 键 | 不是独立表，随读者扩展数据存储 |

### 7.2 API 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/favorites` | 收藏列表 |
| POST | `/api/book/<id>/favorite` | 切换收藏 |
| GET | `/api/shelf` | 书架列表 |
| POST | `/api/book/<id>/shelf` | 切换书架 |
| GET | `/api/reading` | 在读列表 |
| GET | `/api/read-done` | 读完列表 |
| POST | `/api/book/<id>/readstate` | 设置已读状态 |
| GET / POST | `/api/book/<id>/progress` | 读写阅读进度 |
| GET / POST | `/api/book/<id>/comic/progress` | 漫画进度，写入同一张表 |
| GET | `/api/reading/stats` | 个人阅读统计 |

旧接口 `/api/wants`、`/api/case` 及其单书形式**已不再注册**。

### 7.3 关键定义

| 符号 | 值 | 含义 |
|---|---|---|
| `READ_STATE_UNREAD` | `0` | 未读 |
| `READ_STATE_READING` | `1` | 在读 |
| `READ_STATE_FINISHED` | `2` | 读完 |
| `BookReadingProgress.MAX_PROGRESS_BYTES` | `8 * 1024` | 单条进度的字节上限 |
| `COMIC_PROGRESS_VERSION` | `1` | 漫画进度结构版本，不匹配则整条丢弃 |
| `ITEM_COUNT_LIMIT` | `60` | 每类阅读历史的条数上限 |
| 历史去重窗口 | `history[:12]` | 只在最近 12 条内查重 |
| `Reader.SQLITE_MAX_LENGTH` | `32 * 1024` | 读者扩展数据总字节上限 |
| `Reader.OVERSIZE_SHRINK_RATE` | `0.8` | 超限时各类历史的截断比率 |
| 统计书目条数 | `limit(12)` | 统计页展示的本月读完与当前在读书目条数 |
