# 书籍

## 1. 定义

书籍是**书库里可以被单独管理、阅读和交付的一个条目**。它由三部分构成：Calibre 书库中的书目记录、一组格式文件，以及 Talebook 为它补充的扩展属性（收藏者、可见范围、内容形态、访问计数）。

同一本书可以有多个格式文件（EPUB、PDF、TXT 各一份），它们共享同一条书目记录和同一套元数据。

**作品**是比书籍更高一层的聚合：作者与书名相同的书籍属于同一部作品，它们之间的差异（版次、出版社、译者、格式组合）都是**版本**差异。作品本身不承载文件，只承载「这些书是同一部作品的不同版本」这一判断。

**不是什么：**

- **不是描述信息。** 书名、作者、封面等字段的产品准则属于 [元数据](元数据.md)；本篇只管书作为对象与文件的部分。
- **不是读者与书的关系。** 收藏、书架、进度属于 [阅读状态](阅读状态.md)。
- **不是阅读体验。** 用哪个阅读器打开、怎么翻页属于 [阅读器](阅读器.md)。
- **不是有声版本。** 由文字书生成的有声书是独立的衍生媒体，属于 [有声书](有声书.md)。
- **不是作品。** 书籍是版本层，作品是它上面的聚合层；作品不直接拥有文件，也不出现在下载与阅读入口上。

## 2. 使用场景

- **读者看到一本书**，想知道它有哪些格式可下载、能不能在线读。
- **读者手上是 Kindle**，书库里只有 EPUB，想转成 MOBI 再推送。
- **上传者传了一本私密的书**，不希望其他人看到。
- **上传者传错了格式**，想单独删掉某个格式而保留这本书。
- **管理员发现一本书里混进了不相干的格式**，想把它抽出来独立成书。
- **管理员要删掉一本书**，但担心误删。
- **读者找到《三体》的一个版本**，想知道书库里还有没有别的版次或出版社。
- **管理员发现同一部作品被拆成了多条记录**，想把它们归到同一部作品下。

## 3. 功能

- 查看一本书的详情：元数据、可用格式、可见范围、收藏者。
- 下载指定格式。
- 在线阅读（入口与格式选择见 [阅读器](阅读器.md)）。
- 转换格式，或转为 PDF。
- 为已有的书上传新格式。
- 删除单个格式。
- 把某个格式抽出为一本新书。
- 切换公开与私藏。
- 设置或锁定内容形态分类。
- 删除书籍（进回收站）。
- 发送到设备或邮箱（见 [发送到设备](插件/发送到设备.md)）。
- 查看同一部作品的其他版本，并跳转到其中任意一个版本。
- 把多本书合并到同一部作品下。

可用的格式由文件本身决定：EPUB、MOBI、AZW、AZW3、PDF、TXT、CBZ、ZIP、CBR、RAR 可以下载；DOCX、FB2、HTMLZ 可以入库、下载与转换，但**不能在线阅读**。

## 4. 术语与界面用词

### 术语表

| 标准用词 | 英文 | 含义 | 示例 |
|---|---|---|---|
| 书籍 | book | 书库中的一个条目，含书目记录与全部格式文件 | 《三体》是一本书，它同时有 EPUB 和 TXT 两个格式 |
| 格式 | format | 一本书的一个文件副本 | 同一本《三体》下的 EPUB、MOBI、TXT 三个格式 |
| 收藏者 | collector | 把这本书放进书库的人，书籍所有权的唯一依据 | 读者甲上传的书，收藏者是甲；只有甲和管理员能编辑它 |
| 可见范围 | scope | 公开或私藏 | 把一本私人笔记设为私藏，其他读者在书库里看不到它 |
| 私藏 | private | 仅收藏者与管理员可见 | 个人页「私有书籍」列出的就是自己的私藏 |
| 内容形态 | media type | 电子书、漫画或未识别 | 一个 CBZ 图片压缩包被识别为漫画，走漫画阅读器 |
| 形态锁定 | media type locked | 管理员固定分类，不再被自动分析覆盖 | 某本漫画型 EPUB 被误判，管理员改成电子书并锁定 |
| 抽出格式 | separate | 把某个格式独立成一本新书 | 一本书里混进了另一部作品的 PDF，抽出为独立条目 |
| 作品 | work | 作者与书名相同的书籍的聚合，不承载文件 | 《三体》与《三体（重庆出版社·2008）》属于同一部作品 |
| 版本 | edition | 同一部作品下的一次出版，由版次、出版社、译者等差异区分 | 同一部《三体》的 2008 年初版与 2012 年修订版是两个版本 |
| 版本键 | edition key | 判定两个版本是否相同的归一化标识 | 两个版本键相同的书被视为同一版本，不再重复列出 |
| 作品键 | work key | 判定两本书是否属于同一部作品的归一化标识 | 书名与作者归一化后相同，作品键就相同 |
| 归一化 | normalize | 把书名、作者转成可比较的规范形式 | 「三體」与「三体」、「刘慈欣」与「刘慈欣 」归一化后相同 |
| 其他版本 | other versions | 同一部作品下除当前书之外的版本 | 在《三体》详情页看到另一个出版社的版本 |
| 合并 | merge | 把多本书归到同一部作品下 | 管理员把被拆开的两条《三体》记录合并 |

## 5. 行为逻辑

### 5.1 所有权

每本书有且只有一个**收藏者**，在入库时确定。收藏者是**书籍写权限的唯一依据**：

- 编辑元数据、删除书籍、切换可见范围、保存封面，都要求操作者**拥有对应能力权限，并且是收藏者**。
- 管理员不受收藏者限制。

能力权限的定义见 [用户](用户.md)。两个条件是**且**的关系：有编辑权限但不是书主，同样不能改。

### 5.2 可见范围

可见范围只有两个值，表达的是**私藏**而不是细粒度授权：

| 值 | 谁能看到 |
|---|---|
| 公开 | 全部访问者，包括游客（受站点访客开关约束） |
| 私藏 | 收藏者本人与管理员 |

判定有两条路径，**两条都必须存在**：

- **单本判定**：管理员直接通过；没有扩展记录或不是私藏的直接通过；否则要求当前读者是收藏者。
- **列表判定**：先算出当前访问者无权查看的私藏书集合，再从列表结果中排除。列表场景不能逐条调用单本判定，那会产生成百上千次查询。

任何返回书籍的接口——包括不要求登录的只读接口、媒体流、OPDS、WebDAV——**都必须经过其中一条**。可见范围没有例外通道。

### 5.3 格式

一本书的格式集合由实际存在的文件决定，不是一个可编辑字段。

**格式操作**：

- **下载**单个格式，并累加下载计数。
- **下载人机验证**由管理员独立开启，默认关闭。开启后首次下载本书需完成验证，凭证在当前身份、当前书籍、下载场景下有效 30 分钟；直接下载链接和 OPDS 下载同样检查凭证。
- **下载响应**默认作为附件交付，包括 PDF；浏览器不应把详情页的下载操作退化为内联预览。
- **上传新格式**为已有的书补一个文件；同一格式已存在时拒绝。
- **删除格式**只删该文件，书目记录与其他格式保留。
- **抽出格式为新书**把选中格式移到一条新的书目记录下，原书保留其余格式。
- **转换格式**是后台异步任务，有超时上限；转换结果作为新格式回写同一本书。

在线阅读能用哪个格式、优先用哪个，由 [阅读器](阅读器.md) 统一决定，**不由前端根据格式清单自行判断**。
PDF 在线阅读复用同一文件接口，但由统一阅读入口显式声明内联用途；该声明不改变普通下载和 OPDS 的附件语义。

### 5.4 内容形态

内容形态是**持久化的判断结果**，在文件入库时由媒体分析得出，只有三个值：

| 值 | 判定依据 |
|---|---|
| 漫画 | 图片压缩包通过结构、签名与资源预算校验；或 EPUB 每页恰好对应一张图片且正文极短 |
| 电子书 | 通过格式校验的其他电子书 |
| 未识别 | PDF，以及尚未重新分析的既有书籍 |

判定刻意保守：**不单凭扩展名**，不单凭 EPUB 的排版元数据，PDF 不做内容识别。分析只读取目录结构、受限的标记文本和极少量图片头，并对条目数、展开体积、压缩比、路径与单条目体积设上限——不可信压缩包不能拖垮服务。

管理员可以手工修正分类并**锁定**，锁定后自动分析不再覆盖。

### 5.5 作品与版本

作品是书籍之上的聚合层，**不改变书籍本身的任何行为**：书籍的 id、格式、可见范围、收藏者、阅读进度、书架、划线笔记全部继续挂在书籍上。作品只回答「哪些书是同一部作品的不同版本」。

**归组依据**是归一化后的书名与作者：

- 书名与作者归一化后相同，就属于同一部作品。归一化包括繁简统一、大小写与全半角统一、去除首尾与多余空白、去除标点差异。
- 其余差异（版次、出版社、译者、格式组合）都归入**版本**，不拆成不同作品。
- 同一版次的多个格式（如 EPUB 与 MOBI）合并为**一个版本**，版本内再列格式。

**版本后缀提取而非删除**：书名里的版本信息（如「全集」「修订版」「第 2 版」）会被**提取**出来参与版本键，而不是从书名里删掉。这样《三体全集》与《三体》不会被当成同一版本。

**空版本键不自动合并**：如果一本书提取不出任何版本信息，它的版本键为空，**不参与自动合并**，避免把不相干的书误归为同一版本。这类书需要管理员手工确认。

**合并可回滚**：把多本书合并到同一部作品下是可撤销的操作，合并前会保留原状，误合并可以恢复。

**权限**：查看其他版本要求对该版本有可见权限——私藏版本不会因为与公开版本同属一部作品而暴露。合并操作要求管理员权限。

内容形态决定用哪个阅读器，但**不影响下载**：漫画容器照常可下载。

### 5.6 删除

删除书籍把文件移入回收站，不立即销毁，见 [书库](书库.md)。删除同时需要清理该书在 Talebook 侧的关联数据（别名、扩展属性）。

私藏书的删除是**永久性的**——它不会再被其他读者看到，因此界面要按不可恢复处理提示。

图书管理支持一次删除所选多本书，与逐本删除遵循相同的权限、回收站和源文件处理规则。接口逐本报告成功与失败；部分失败时已成功的删除仍然生效，界面保留失败项供重试。未接通删除服务不能报告成功。

### 5.7 计数

每本书维护三个全站计数：访问量、游客访问量、下载量。**在线阅读一次也计入下载量**，因此下载量的语义是「取用次数」而不是「文件下载次数」。演示模式下不计数。

这些是站点聚合数据，与读者个人的阅读状态无关。

## 7. 实现对照

### 7.1 数据存储

| 概念 | 存储 | 表与字段 |
|---|---|---|
| 书目与格式文件 | Calibre 书库 | 经 `BaseHandler.db` 读写 |
| 扩展属性 | Talebook 业务库 | `items`，`Item` 模型，主键即 Calibre 的 `book_id` |
| 收藏者 | `Item.collector_id` | 外键指向 `readers.id`，默认 `1` |
| 可见范围 | `Item.scope` | `public` / `private`，默认 `public` |
| 内容形态 | `Item.media_type` / `media_type_locked` | `unknown` / `ebook` / `comic` |
| 计数 | `Item.count_visit` / `count_guest` / `count_download` | 全站聚合 |
| 外部索引书路径 | `Item.src_path` | 书文件不在 Calibre 目录内时的源路径 |

### 7.3 关键定义

| 符号 | 值 | 含义 |
|---|---|---|
