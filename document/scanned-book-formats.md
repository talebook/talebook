# 扫描版书籍管理

Talebook 支持上传或目录导入 `.djvu` 和 `.uvz` 文件（扩展名不区分大小写），保存原始文件并提供下载。它们不支持在线阅读或格式转换；若同一本书还有 EPUB、PDF 等可读格式，可继续阅读这些格式。

文件名去掉最后一个扩展名后作为书名，例如 `古籍.卷一.DJVU` 对应 `古籍.卷一`，作者初始为“佚名”。当前不支持自定义文件名正则。可在入库后编辑书名、作者和其他元数据。

同名候选只有一本时，新格式会并入该书，已有相同格式不会覆盖；有多本同名书时会独立建档，避免混淆版本。网页上传只合并有编辑权限且拥有的书籍（管理员可管理其他书籍）。

启用现有“自动填充元数据”设置并配置可用的元数据插件后，导入会调用网络补全服务获取元数据及封面。匹配依赖数据源，古籍或绝版文献可能没有结果；可手动维护。已有完整元数据会遵循现有补全策略。

DJVU 校验容器签名及长度；UVZ 按 ZIP 容器检查目录、路径、加密标志和资源限制，可包含 PDG 等私有页面格式。Talebook 不解压或解码这些页面，因此导入成功不代表已验证本地阅读器能打开。UVZ 沿用现有压缩包限制，包括不接受 ZIP64、分卷、加密、空包或超预算容器。
